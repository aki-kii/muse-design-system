# 章完了パネル（Chapter Complete Panel）

**出自:** 学習ノート。別のアプリで要るときは、まず下の「組み合わせ」の汎用部品で組みます（[昇格のルール](../decisions/0002-component-admission.md)）。

## 概要

学習プレイヤーで章の最後のページを終えたときに出す完了画面です。★と「章名 クリア！」を大きく出し、次の章へ進むか、パスに戻るかを選ばせます。同じ形を、ノートの終わり・今日の復習の終わり・セッションの終わりにも使います。

## 組み合わせ

- ★ と大きな見出し
- [ボタン](../components/button.md)のプライマリとセカンダリ（次へ／戻る）
- ノートの終わりのバリアントの数（ページ数・XP など）

## 使うとき

- 章を指定して開いた学習プレイヤーで、その章の最後のページから「次へ」を押したとき
- ノート全体・今日の復習・時間で区切るセッションが終わったとき（バリアント参照）

## 使わないとき

- 1問ごとの正誤 → [結果バナー](result-banner.md)
- 章の途中の区切り（「ここまでが1セクション」）→ 問題カードと同じカードに見出しだけを出す
- 章をまたいでめくり続けている途中（このときは画面上部に短い祝福の帯を 2.4 秒だけ出し、パネルは出さない）

## バリアント

| バリアント | 見出し | ボタン |
| --- | --- | --- |
| 章のクリア | 「章名 クリア！」 | 次の章へ（プライマリ）＋パスに戻る（セカンダリ）。次の章がなければ「パスに戻る」だけをプライマリで |
| ノートの終わり | 「このノートはおしまい！」＋ページ数・獲得 XP・ベストコンボ・正答数 | 閉じる |
| 復習の終わり | 「今日の復習はおしまい」 | 閉じる（セッションの中では「講義へ」） |
| セッションの終わり | 「今日の分はおしまい」 | 単語を続ける（セカンダリ）＋ホームへ（プライマリ） |

## 状態

| 状態 | 見た目 |
| --- | --- |
| 出たとき | 紙吹雪が 1.1 秒で落ちる |
| 表示中 | ボタンを押すまで残る |

## 仕様

構成は次のとおりです。

1. 紙吹雪（飾り）
2. ★
3. 見出し
4. 補足（バリアントによる）
5. ボタン（縦に並べる。セッションの終わりだけ2列）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | [セクションカード](../components/section-card.md)と同じ | `--surface` `--border` `--shadow-card` `--radius-card` |
| 内側の余白 | 24px、中央揃え | |
| ★ | 64px / 800、金色。文字ではなく飾りの記号として扱う（64px はこのパターンだけの値） | `--gold` |
| 見出し | 24px / 800 | `--text-2xl` |
| 補足 | Small 段 | `--dim` |
| ボタン | 間隔 10px、見出しとの間隔 20px | [ボタン](../components/button.md) |

## アクセシビリティ

- 見出しを `<h2>` にする。パネルが出たら、見出しへフォーカスを移すか、パネルを `role="status"` にして読み上げで伝える。
- ★ と紙吹雪は `aria-hidden="true"` にする。
- ボタンは「次の章へ進む」「パスに戻る」のように行き先を `aria-label` に書く。
- 紙吹雪は `prefers-reduced-motion: reduce` のとき止める。
