# スライドステージ（Slide Stage）

**出自:** スライドエディタ。別のアプリで要るときは、まず下の「組み合わせ」の汎用部品で組みます（[昇格のルール](../decisions/0002-component-admission.md)）。

## 概要

スライドを1枚ずつ表示する領域です。画面全体の背景（DS のグレー）の上に、スライドだけを白い面として置きます。スライドを押すと前後のページへ移ります。

## 組み合わせ

- DS の部品は使わない。グレーの地に、[スライドの型](../patterns.md#e-スライドの型)で組んだ1枚を置く

## 使うとき

- スライドエディタで、[デッキヘッダー](deck-header.md)のすぐ下に置く
- 16:9 に近い比のコンテンツを、まわりの UI と分けて見せるとき

## 使わないとき

- 一覧の中の縮小表示 → [デッキカード](deck-card.md)のサムネイル、[ページプレビューカード](page-preview-card.md)
- 読み物の本文 → [セクションカード](../components/section-card.md)。ステージは「そのまま見せる」場所で、DS の文字の段は使わない

## バリアント

なし（1種類だけ）。中に入るスライドの形は[スライドの型](../patterns.md#e-スライドの型)で決めます。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | グレーの地の中央に白いスライド | |
| ページ切り替え | 新しいスライドが不透明度 0.25 から 0.28 秒で現れる | 前後に移ったとき |
| 最初・最後のページ | 見た目は同じ。端より先には移らない | |
| フォーカス | フォーカスの輪 | キーボードで選ばれたとき |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| ステージの地 | 画面全体の背景と同じ。ダークでは黒になる（スライドエディタの現行） | `--bg` |
| ステージの大きさ | 幅いっぱい、比 980:552、高さは画面の 58% まで | |
| スライドの面 | デッキ自身の地の色（多くは白）。ダークでも変えない。中央に置き、ステージに収まる最大の大きさ。比 980:552 | デッキ側の色。DS のトークンにしない |
| スライドの中の寸法 | スライドの幅に対する割合（`cqw`）で決める。表示の大きさが変わっても組みが崩れない | |
| 移り方 | スライドの右半分を押すと次へ、左半分で前へ。キーボードの ← → でも移る | |

スライドの中の文字や色は、デッキ自身の見た目のまま表示します。DS のトークンで塗り替えません（デッキ側の色。[色](../foundations/color.md#中身側の色)）。

## アクセシビリティ

- スライドは `role="button"` にし、`aria-label` を「スライド n / 全体（右半分タップで次へ、左半分で前へ）」にする。
- ← → キーで移れるようにする。入力欄にフォーカスがあるときと、[シートモーダル](../components/sheet-modal.md)を開いているときは移らない。
- ページが変わったことは[ページカウンタ行](page-counter-row.md)の「n / 全体」で文として伝える。
- 現れる動きは `prefers-reduced-motion: reduce` のとき止める。
