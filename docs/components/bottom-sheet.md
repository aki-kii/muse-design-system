# ボトムシート（Bottom Sheet）

## 概要

画面の下からせり上がる板です。上に見出しと閉じる × を置き、中に1つの作業だけを入れます。今の画面を離れずに、短い入力や選択をさせるときに使います。広い画面（640px 以上）では中央に浮くパネルになります。

参考元: [Material Design 3 の Bottom sheets](https://m3.material.io/components/bottom-sheets/overview)、[Apple HIG の Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)。

## 使うとき

- 今の画面の文脈（どの項目を見ているか）を保ったまま、短い入力や選択をさせるとき（例: メモを追加する、並び順を選ぶ）
- 一覧を一時的に開いて、選んだら閉じるとき（例: 項目を選ぶ、保留中のものを見る）

## 使わないとき

- はい・いいえだけの確認 → [確認ダイアログ](confirm-dialog.md)
- 外部に触る操作の確認 → [承認カード](approval-card.md)
- 何画面も続く手続き（シートの中で画面を移らない）
- 1件の中身をじっくり見せる → [一覧から詳細へ](../patterns/list-to-detail.md)

## バリアント

| バリアント | 中身 | 例 |
| --- | --- | --- |
| 入力 | 見出し → 入力や選択（[入力バー](memo-input-bar.md)の3行、[選択肢ボタン](choice-button.md)など）→ 全幅の確定ボタン | メモを追加 |
| 削除 | 見出し → 何を消すか → 理由などの入力（任意）→ 赤い全幅の確定ボタン | 項目を削除 |
| 一覧 | 見出し → [状態付きリスト項目](status-list-item.md)などの一覧。ないときは[空の状態](empty-state.md)の小。確定ボタンは置かない | 保留中の項目 |
| 上から出す | 同じ板を画面の上端から出す。上の角は四角、下の2つの角を 20px | 画面の上にある切り替えボタンから開く選択 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 閉じている | なし | |
| 開いている | 幕の上に、下端に付いた板 | |
| 送信できない | 全幅ボタンが不透明度 0.4 で押せない | 入力が空 |
| フォーカス | フォーカスの輪 | |

幕を押すか × を押すと閉じます。全幅ボタンを押すと、その作業を確定して閉じます。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 幕 | 黒の 40%。キーボードと一緒に出る入力のシートは黒の 70% | `--scrim` `--scrim-strong` |
| 板 | 白、最大幅 512px、高さは画面の 88% まで（はみ出すとスクロール）。影は付けず、幕との明るさの差で浮かせる | `--surface` |
| 板の角丸 | 上の2つの角だけ 20px。640px 以上では4つの角 | `--radius-card` |
| 内側の余白 | 16px 16px 24px | |
| 見出しの行 | 16px / 600 の見出し＋右端に 32px の丸い ×（[アイコンボタン](icon-button.md)の丸）、下に 16px | `--text` |
| 全幅ボタン | 高さ 48px 以上、14px / 600、上に 16px | 角丸 `--radius-row` |
| 全幅ボタンの色 | 確定はブルー、削除は赤、取り消しは `--fill` に 1px の枠。色の面の文字は面に合わせる | `--accent` `--accent-ink` `--danger` `--danger-ink` `--fill` `--border` |
| 一覧の行 | `--fill` の面、1px の枠、内側 12px 16px、行同士 8px。題 14px / 500、補足 12px | `--fill` `--border` `--radius-row` `--dim` |

全幅ボタンは角丸 12px で、[ボタン](button.md)のピルと形が違います。シートの下に並ぶ「確定」はフォームの一部として扱い、入力欄と同じ 12px にします。削除の確定は赤い面にしてよいものとします（[決定記録 0005](../decisions/0005-states-and-exceptions.md)）。

## アクセシビリティ

- 板は `role="dialog"` と `aria-modal="true"` にし、見出しをダイアログの名前に結び付ける（`aria-labelledby`）。
- 開いたらシートの中の最初の入力（なければ ×）にフォーカスを移し、シートの外へフォーカスが出ないようにする。Esc で閉じ、開いたボタンにフォーカスを戻す。
- × は `aria-label="閉じる"` にする。
- 赤い全幅ボタンは色だけでなく文（「削除する」）で何が起きるかを書く。
