単語カード（Word Card）

意味を隠して思い出す。復習では意味の4択になる

デモ

新しい単語（意味を開いて判定する）

単語の復習（意味の4択。選ぶと約 1.1 秒後に次へ）

🔊 を押すと英文を読み上げます（端末が音声合成に対応しているとき）。

アプリ固有の複合体。 学習ノートでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（昇格のルール）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

概要#

単語を1枚ずつ見せるフラッシュカードです。初めての単語は意味を隠して思い出させ、タップで開いてから本人が「もう知ってた／覚える」を選びます。一度間違えた単語の復習では、意味を4択から選ぶクイズになります。

組み合わせ#

  • フラッシュカード（表＝単語、裏＝意味、自己判定の2択）
  • 読み上げボタン（単語と例文の横）
  • 復習のバリアントでは選択肢ボタンの縦並び（クイズ選択肢と同じ判定の状態）

使うとき#

  • 英単語のように、語と意味の組を短い間隔で繰り返し覚えるとき
  • 時間で区切るセッションの単語の段階（時間で区切るセッションの型）

使わないとき#

  • 文章で答える問題、意味以外を問う問題 → 問題カード＋クイズ選択肢
  • 解説を読ませるページ（単語カードには解説を載せない）

バリアント#

バリアント出す条件流れ
新しい単語本人がまだ判定していない単語、または「もう知ってた」と判定した単語意味を隠す → 「タップして意味を見る」→ 意味を開く → 「もう知ってた」「覚える」を選ぶ → 次のカード
単語の復習前に「覚える」を選んだか、復習で間違えた単語。かつ近い単語が3つ以上ある例文の中の単語を ＿＿＿ で伏せる → 意味の4択＋「分からない」から選ぶ → 正誤を出して約 1.1 秒後に次のカード

近い単語が3つ未満のときは、復習でも「新しい単語」の流れにします。

状態#

状態見た目バリアント
意味を隠している破線枠のボタン「タップして意味を見る」と、その下に「意味を思い浮かべてから、タップして確かめよう」新しい単語
意味を開いた破線の --accent の枠に意味（20px / 700）。例文の和訳も出る。下に判定ボタン2つ新しい単語
選ぶ前意味の4択＋「分からない」単語の復習
選んだ後選択肢を押せなくし、クイズ選択肢の正解・不正解の状態で示す。下に「覚えてた！」「ちがうよ」「答えはこれだよ」のどれかと、間違えたときは「明日の復習でもう一度出すね。」単語の復習
おしまい「今日の分はおしまい」両方

仕様#

構成は次のとおりです。

  1. キッカー「新しい単語 3 / 8」または「単語の復習 1 / 8」
  2. 単語のカード（単語＋読み上げボタン）
  3. 例文（＋読み上げボタン）。開いた後だけ和訳を --dim の Small 段で出す
  4. 意味を開く部分（バリアントごとに上の表のとおり）
項目値トークン
キッカー13px / 700、字間 0.05em--accent-strong
単語のカード--surface の面、1px の枠、カードの影、内側の余白 28px 16px--surface --border --shadow-card
単語36〜52px（画面幅で変える）/ 800。このパターンだけの値
例文16px--text
「タップして意味を見る」破線 2px の枠、内側の余白 28px 16px、高さ 56px 以上、700--border --dim --radius-card
意味の枠破線 2px、内側の余白 16px--accent --radius-card
判定ボタン2列、間隔 10px。「もう知ってた」はセカンダリ、「覚える」はプライマリボタン
意味から伏せる語意味の文に単語そのものが入っていたら ＿＿＿ に置き換える

アクセシビリティ#

  • 1枚を <article> にする。単語には lang="en" を付ける。
  • 「タップして意味を見る」は <button> にし、aria-label="意味を見せる" を付ける。開いた後は、意味の枠へ読み上げが届くよう、判定ボタンの前に意味を置く。
  • 4択の各選択肢は aria-label="意味の選択肢: 〇〇" にする。選んだ後の結果の文は role="status" にする。
  • 次のカードへ自動で進む 1.1 秒の間は、結果の文を読み上げ終わらないことがある。当面は学習ノートの現行どおり自動で進め、設定は設けない。
  • カードが変わったら、画面の先頭へスクロールを戻す。
