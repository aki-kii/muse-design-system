# クイズ選択肢（Quiz Option）

## 概要

選択式の問題で、答えを1つ選ばせるための行です。答え合わせの前は「選択中」、答え合わせの後は「正解」「不正解」の状態を持ちます。押した瞬間には正誤を出さず、「答え合わせ」のボタンを押してから出します。

## 使うとき

- 選択式の問題（クイズ）、[単語カード](word-card.md)の復習の4択
- 選択肢が2〜4個で、それぞれ1〜2行に収まるとき

## 使わないとき

- 設定の選択や絞り込み → [チップ](chip-and-tag.md)や[スイッチ](input-and-switch.md)
- 自分の言葉で書かせる問題 → [入力欄](input-and-switch.md)の複数行
- 画面の移動 → [ボタン](button.md)

## バリアント

なし（1種類だけ）。単語カードの復習では、選んだ時点で答え合わせまで進みます（「答え合わせ」のボタンを使わない）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | `--surface` の面、1.5px の `--border` の枠 | 選ぶ前 |
| 選択中 | 枠 `--accent`、面 `--accent-soft` | 選んでから答え合わせまで。選び直せる |
| 正解 | 枠 `--ok`、面は薄い緑 | 答え合わせの後、正しい選択肢（選んでいなくても出す） |
| 不正解 | 枠 `--danger`、面は薄い赤 | 答え合わせの後、本人が選んだ誤りの選択肢 |
| 答え合わせ後のほか | 通常の見た目のまま押せない | 答え合わせの後 |
| フォーカス | フォーカスの輪 | キーボードで選ばれたとき |

正解と不正解の薄い面の色は、トークンがありません（[判断待ちの点](../open-questions.md#学習ノート由来の部品) 12）。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 高さ | 48px 以上 | `--size-tap-target` 以上 |
| 内側の余白 | 上下 14px、左右 16px | |
| 角丸 | 12px | `--radius-row` |
| 枠 | 1.5px | `--border` ほか上の表 |
| 文字 | 本文（16px）、行間 1.6、左揃え | `--text` |
| 選択肢同士の間隔 | 10px | |
| 問題文との間隔 | 16px | |

問題の下に「答え合わせ」のボタンを置き、何も選んでいない間は無効にします。

## アクセシビリティ

- 各選択肢は `<button>` にし、`aria-pressed` で選択中を示す。`aria-label` は「選択肢: 〇〇」にする。
- 答え合わせの後は `disabled` にする。
- 正誤は枠と面の色だけで示しているため、[結果バナー](result-banner.md)の文（「正解！」「惜しい！」）を必ず一緒に出す。選択肢そのものに色以外の印（✓ ✕ など）を付けるかは未定義（[判断待ちの点](../open-questions.md#学習ノート由来の部品) 15）。
