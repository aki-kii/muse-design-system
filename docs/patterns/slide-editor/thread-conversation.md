# スレッドの会話（Thread Conversation）

**アプリ固有の複合体。** スライドエディタでだけ使います。v0.6.0 で、[吹き出し](../../components/message-bubble.md)に足していたスライドエディタ固有の拡張（下書きの状態とアプリ側の値）をここに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。

## 概要

スライドの1ページに付けたメモのやり取り（スレッド）を開いたときの画面です。上端にスレッドの題、真ん中に吹き出しの列、下に入力バーを置きます。吹き出しごとに名前・時刻・下書きのメタ行を出し、長押しで操作を開きます。

## 組み合わせ

- 上端: [デッキヘッダー](deck-header.md)のスレッドの上端（[アイコンボタン](../../components/icon-button.md)＋題＋[完了トグル](../../components/done-toggle.md)）
- 会話: [吹き出し](../../components/message-bubble.md)のメタ行付き＋[長押しメニュー](../../components/long-press-menu.md)
- 下端: [タイピングストリップ](typing-strip.md)＋[入力バー](../../components/memo-input-bar.md)（下に固定）

## 使うとき

- [スレッドカード](thread-card.md)を押して、1つのスレッドを開いたとき

## 使わないとき

- スレッドの一覧 → [スレッドカード](thread-card.md)
- 会話を伴わない、1回で終わる依頼 → [依頼行](request-row.md)

## バリアント

なし（1種類だけ）。

## 状態

吹き出しの状態は[吹き出し](../../components/message-bubble.md)と同じです。スライドエディタでは次の状態を足します。

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 下書き | メタ行の最後に「下書き」（名前 ・ 時刻 ・ 下書き） | 修正依頼に出していない本人の発言 |
| 修正中 | 入力バーの上に[タイピングストリップ](typing-strip.md) | エージェントがこのスレッドを修正している |
| 解決済み | 上端の題に打ち消し線、完了トグルがオン | 本人が完了トグルを押した |

## 仕様

吹き出しの値は DS の値（本文 15px、内側 12px 16px、最大幅 84%、本人は `--bubble-user` の薄いブルー）を正とします。元のスライドエディタのモックは、静的ページ版 v0.3 の値で次のように作っていました。どちらに寄せるかは[判断待ちの点](../../open-questions.md#スライドエディタ由来の部品) 22 で決めます。

| 項目 | モックの値 | DS の値 |
| --- | --- | --- |
| 本人の吹き出し | 濃いブルー（`#0082FB`）に白い文字、メタ行は白の 75% | `--bubble-user` に `--bubble-user-ink` |
| 本文 | 14px | 15px |
| 内側の余白 | 8px 16px | 12px 16px |
| 最大幅 | 85% | 84% |

## アクセシビリティ

- 会話の列は `role="log"` にする。下書きであることはメタ行の文で伝える。
- 長押しメニューのキーボード操作は[長押しメニュー](../../components/long-press-menu.md)に従う。
