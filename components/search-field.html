検索フィールド（Search Field）

一覧を打った文字でその場で絞り込む。虫めがねと ✕

面（シート・カードの中）

概要#

一覧の中身を、打った文字でその場で絞り込むための入力欄です。虫めがねのアイコンと、打った文字を消す ✕ を持ちます。ラベルを持つ入力欄と違い、一覧の上に置いて見た目だけで用途が分かる形にします。

参考元: Carbon の Search、Material Design 3 の Search、Primer の TextInput（先頭にアイコンを置く形）。もらったのは「アイコン＋欄＋消す操作」の構成と、打つたびに絞り込む振る舞いだけで、見た目は Muse DS のトークンで作っています。

使うとき#

  • 10件を超える一覧から、名前で1つを探す（例: 絵文字を選ぶシート、種目の一覧、ノートの本棚）
  • 打つたびに結果が変わってよい、端末の中だけで済む絞り込み

使わないとき#

  • 選択肢が数個で、全部が見えている → チップの絞り込み、選択肢ボタン
  • 保存する値を入れる（名前・メモ・指示）→ 入力欄
  • 会話として送る → 入力バー
  • 画面の主な操作が検索ではない画面のヘッダーに、常に出しておかない。一覧を開いたときだけ出す

バリアント#

バリアント見た目用途
標準高さ 44px のピル。--surface の面に 1.5px の --border の枠--bg の上の一覧
面同じ形で枠なし、--bg の面シート・カードの中（--surface の上）

状態#

状態見た目条件
空虫めがね＋プレースホルダ（--faint）。✕ は出さない何も打っていない
入力中文字の右に ✕ のアイコンボタン（四角、--dim）1文字以上ある
フォーカス枠が --accent になり、外に --accent の 2px の輪（2px 離す）
結果なし欄はそのまま。下の一覧を空の状態の「見つからない」にする絞り込みの結果が0件
無効不透明度 0.4、打てない一覧の読み込み中

仕様#

項目値トークン
高さ44px--size-tap-target
角丸999px--radius-pill
左右の余白左 14px（アイコンの前）、右 4px（✕ の後）
虫めがね18px、線 2px、--dim
文字16px / 400、--text（16px 未満にしない。iOS で画面が拡大されるため）--text-base
✕36×36px の見た目、押せる範囲 44px--size-tap-target
一覧との間隔12px--space-card-gap

構成は次のとおりです。

  1. 虫めがねのアイコン（飾り）
  2. 欄（<input type="search">）
  3. ✕ のアイコンボタン（打った文字を消し、欄にフォーカスを戻す）

振る舞いは次のとおりです。

  • 打つたびに絞り込む。確定の操作（検索ボタン・Enter）は要らない。
  • 大文字・小文字、ひらがな・カタカナの違いは区別せずに探す。
  • 打った文字は、画面を閉じたら消す（残さない）。

アクセシビリティ#

  • ラベルを見せないので、欄に aria-label を付ける（例:「絵文字を検索」）。プレースホルダだけで名前にしない。
  • 包む要素を <search>（または role="search"）にする。
  • ✕ のアイコンボタンには aria-label="検索の文字を消す" を付ける。ブラウザの既定の消すボタンは隠して、二重にしない。
  • 結果の件数を role="status" の領域で伝える（例:「12件」）。打つたびに読み上げが重ならないよう、少し待ってから更新する。
