# デッキヘッダー（Deck Header）

**アプリ固有の複合体。** スライドエディタでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

スライドエディタの上端に置く1行です。左に「デッキ一覧へ戻る」の丸ボタン、中央にデッキ名、右に「再読み込み」の丸ボタンを並べます。デッキ名は見出しではなく、今どのデッキかを示す小さなメタ情報です。

## 組み合わせ

- [アイコンボタン](../../components/icon-button.md)の丸（一覧へ・再読み込み・戻る・削除）
- デッキ名またはスレッドの題（メタ情報の文字）
- スレッドの上端では[完了トグル](../../components/done-toggle.md)

## 使うとき

- スライドエディタで、[スライドステージ](slide-stage.md)の上に置く
- 一覧に戻る操作と、中身を取り直す操作だけがある画面の上端

## 使わないとき

- 主要な画面の行き来 → [ナビゲーション](../../components/navigation.md)
- 学習プレイヤーの上端 → [プレイヤートップバー](../learning-note/player-top-bar.md)
- 押せるものが3つ以上並ぶとき（丸ボタンの意味が覚えられなくなる）。メニューにまとめる

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| デッキの上端 | 一覧へ（4つの四角のアイコン）＋デッキ名＋再読み込み（回る矢印） | エディタ |
| スレッドの上端 | 戻る（←）＋スレッドの題と「nページ」＋[完了トグル](../../components/done-toggle.md)＋削除（ゴミ箱） | スレッドを開いたとき。ステージの下に出す |

丸ボタンはどちらも同じ形（下の「丸ボタン」）です。

## 状態

| 状態 | 見た目 | 対象 |
| --- | --- | --- |
| 通常 | 上の表のとおり | |
| 押下 | 押した操作へ移る | 丸ボタン |
| 再読み込み中 | 矢印のアイコンが 0.8 秒で1回転し続け、ボタンは不透明度 0.5 で押せない | 再読み込み |
| 解決済み | スレッドの題に打ち消し線、色は `--dim` | スレッドの上端 |
| フォーカス | フォーカスの輪 | 丸ボタン |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 行の高さ | 48px、左右 16px、要素の間 8px | |
| デッキ名 | 12px、1行で切る（…） | `--dim` `--text-xs` |
| スレッドの題 | 13px / 500、1行で切る。「nページ」は 11px | `--text`、ページは `--dim` |
| 丸ボタン | 見た目 32×32px の円、1px の枠、アイコン 16px | `--fill` `--border` `--dim` `--radius-pill` |
| 丸ボタンの押せる範囲 | 外側に 6px 広げて 44px | `--size-tap-target` |
| 回転 | 1回転 0.8 秒、一定の速さ | |

丸ボタンの 32px と、文字の 13px・11px は段にない値です（[判断待ちの点](../../open-questions.md#スライドエディタ由来の部品) 23）。

## アクセシビリティ

- 丸ボタンはアイコンだけなので `aria-label` を付ける（「デッキ一覧に戻る」「スライドを再読み込み」「スレッド一覧に戻る」「スレッドを削除」）。
- 再読み込み中は `disabled` にし、回転は `prefers-reduced-motion: reduce` のとき止める。止めても押せないことで状態が分かるよう、`aria-busy="true"` を付ける。
- デッキ名は見出し要素にしない（ページの見出しはデッキ一覧側）。
