# スライドエディタの複合体

スライドエディタ（スライドを見ながらページごとにメモを付け、エージェントに修正を頼むアプリ）でだけ使う、部品の組み合わせです。v0.5.0 で部品として足し、v0.6.0 でパターンに移しました。どれも「組み合わせ」の節に、使っている汎用の部品を書いています。

スライドエディタから足した部品のうち、中身に依存しないもの（シートモーダル、確認ダイアログ、作業中インジケータ、完了トグル、スピードダイヤルFAB、長押しメニュー、入力バー）は[コンポーネント](../../components/README.md)に残しています。

| 複合体 | 一言 | 組み合わせ |
| --- | --- | --- |
| [デッキカード](deck-card.md) | 表紙のサムネイル＋タイトル＋枚数・日付でデッキを並べる | メディアカード |
| [デッキヘッダー](deck-header.md) | 一覧へ戻る・再読み込みの丸ボタンとデッキ名の1行 | アイコンボタン、完了トグル |
| [スライドステージ](slide-stage.md) | グレーの地に白いスライドを1枚。左右を押して前後へ | スライドの型 |
| [ページカウンタ行](page-counter-row.md) | 「n / 全体」と、行き場のないメモへのリンク | 文字のリンク |
| [スレッドカード](thread-card.md) | ページに付けたやり取り。確認待ち・修正中・下書き・解決済み | 状態付きリスト項目 |
| [確認待ちバッジ](awaiting-badge.md) | ブルーの円＋吹き出し。本人が見る番の印 | 状態付きリスト項目の先頭の印 |
| [タイピングストリップ](typing-strip.md) | 入力バーの上に修正中や短い結果を出す帯 | 作業中インジケータ、入力バー |
| [依頼行](request-row.md) | ページの追加・削除の依頼と、その状態の1行 | 状態付きリスト項目、完了トグル |
| [ページプレビューカード](page-preview-card.md) | 前後のページの小さな枠で差し込む位置を見せる | スライドの比の枠 |
| [位置ラジオ](position-radio.md) | 前・後の2択を大きなボタンで選ぶ | 選択肢ボタン |
| [送信完了メッセージ](submit-message.md) | FAB の上に、何を何件出したかを出す | トースト |
| [スレッドの会話](thread-conversation.md) | スレッドを開いた画面。吹き出しのメタ行・下書き・長押し | 吹き出し、長押しメニュー、入力バー |

スライド1枚の組み方は、[スライドの型](../../patterns.md#e-スライドの型)にあります。
