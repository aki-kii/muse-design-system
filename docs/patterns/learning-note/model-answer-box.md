# 模範解答ボックス（Model Answer Box）

**アプリ固有の複合体。** 学習ノートでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

記述式の問題で、答え合わせの後に模範解答を見せる枠です。破線の枠で、本人の答え（入力欄）と見分けます。英文の模範解答には[読み上げボタン](speak-button.md)を付けます。

## 組み合わせ

- 破線の `--accent` の枠と見出し
- [読み上げボタン](speak-button.md)（見出しの横）

## 使うとき

- 自分の言葉で書く問題（思い出す問題・英文を書く問題）の答え合わせの後
- 前に答えた記述式の問題を開き直したとき

## 使わないとき

- 選択式の問題（正解の選択肢が[クイズ選択肢](quiz-option.md)の正解の状態で分かる）
- 解説そのものを見せる → 解説ページ、または[結果バナー](result-banner.md)の「解説を見返す」
- 答え合わせの前に出さない

## バリアント

なし（1種類だけ）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 非表示 | 出さない | 答え合わせの前 |
| 表示 | 本人の答えの入力欄の下に出る | 答え合わせの後、模範解答があるとき |

## 仕様

構成は次のとおりです。

1. 見出し「模範解答」＋読み上げボタン
2. 模範解答の文（括弧内の注記は除いて見せる）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | 白 | `--surface` |
| 枠 | 破線 2px | `--accent` |
| 角丸 | 12px | `--radius-row` |
| 内側の余白 | 16px | |
| 入力欄との間隔 | 12px | |
| 見出し | 14px / 800 | `--accent-strong` |
| 模範解答 | 本文、行間 1.65 | `--text` |

## アクセシビリティ

- 英文の模範解答には `lang="en"` を付ける。
- 見出しは見た目だけの太字ではなく、要素の構造でも見出しと分かるようにするか、枠に `aria-label="模範解答"` を付ける。
- 破線の枠は飾りとして扱い、「模範解答」の文で中身を示す。
