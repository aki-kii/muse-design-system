# 0004: 余白・角丸・文字はスケールにそろえ、部品だけの寸法は部品の文書に書く

- 状態: 決定
- 日付: 2026-11-17

## 背景

v0.6.0 までの判断待ちの点の 7〜10、16、23（番号は v0.6.0 時点の判断待ちの一覧のもの。一覧は v0.8.1 で廃止し、決定はこの記録に残す）は、スケールにない寸法の扱いだった。「余白は4の倍数」と 14px・18px が食い違い、数値タイルの 14px、タイポの段の 13・15・17・22・28・38px、学習ノートとスライドエディタの部品の寸法（ノードの影、コースのアイコンの角丸、11px の文字、32px の丸ボタン、FAB の 48px など）が段に乗っていなかった。

実アプリを見ると、4つとも Tailwind の 4px 刻みで組んでいて、14px・18px の余白はどのアプリも使っていない。スライドエディタは余白を 16px にそろえている。11px の文字は筋トレ記録・スライドエディタ・AWS アップデートで `text-[11px]` として使われている。

決め方の基準は [0003](0003-color-and-contrast.md) と同じ（実アプリの現行値が正、アクセシビリティは WCAG 側、トークンは実際に使われているものだけ、文書の修正で済む側でそろえる、保留も当面の扱いを決めて閉じる）。

## 決定

- 余白（7）: 余白は4の倍数にする。`--space-card-gap` を 14px → 12px、`--space-card-padding` を 18px → 16px に変えた（基準1）。部品の中の細かい調整は2の倍数まで認める。
- 数値タイルの角丸（8）: 14px → 12px（`--radius-row`）。筋トレ記録の数値の面は `rounded-xl`（12px）（基準1・4）。
- タイポの段（9）: 段のサイズをスケールの値で書き直した。Display 30・36px、Heading 18・20・24px、Body 16px／行の高さ 24px、Small 12・14px。本文の行間は 1.55 ではなく 24px（1.5）にそろえる。読み物の解説だけ、パターンで広げてよい（基準4）。
- 11px の文字（16・23）: `--text-2xs`（11px／14px）を足し、段に「Micro」を足した（基準3）。
- タブの大きさ（10）: 52×44px。DS のサイトの見本の実装も 52px で、表の注記を消すだけで済む（基準4）。
- 部品・パターンだけの寸法（16・23）: 1つの部品・パターンでしか使わない寸法はトークンにせず、その文書に値を書く。2つ目の部品やアプリで同じ値が使われたら、トークンにするかを検討する（[0002](0002-component-admission.md) の部品の昇格と同じ考え）。当てはまるもの: ノードの「下にずらした色の帯」、コースのアイコンの角丸 8px・14px、単語カードの 36〜52px、章完了の ★ 64px、丸ボタンの見た目 32px、FAB の 48px、件数バッジの 20px と 2px の縁と 10px の数字、修正中の点の 6px、長押しメニューの幅 176px、部品の文書にあるスケール外の文字（13px・15px・22px）（基準3・5）。
- 幕（16）: コース切替パネルの黒の 40% は `--scrim`（[0003](0003-color-and-contrast.md)）。
- 押せる範囲（23）: `--size-tap-target`（44px）を守る。ページカウンタ行のリンク（36px）は押せる範囲を上下に広げて 44px、長押しメニューの項目（40px）は 44px にした。見た目が 32px の丸ボタンは、押せる範囲を外側に 6px 広げて 44px にする今の作りを決まりとして認める（基準2）。
- 余白 16px（23）: スライドエディタの 16px は、`--space-card-padding` が 16px になったことで一致した。

## 結果

- カードの間隔と内側の余白が 2px ずつ狭くなる。トークンを読み込んでいる側は見た目が変わる。
- 部品の文書には、スケール外の値がそのまま残るものがある（実アプリの現行値を写したもの）。新しい部品はスケールの値で作る。
- スライドエディタのページカウンタ行と長押しメニューは、アプリ側では当面 36px・40px のまま。次に手を入れるときに 44px にする。
