# シートモーダル（Sheet Modal）

## 概要

画面の下からせり上がる板です。上に見出しと閉じる × を置き、中に1つの作業だけを入れます（例: スライドエディタの「ページを追加」「ページを削除」「行き場のないメモ」）。広い画面（640px 以上）では中央に浮くパネルになります。

## 使うとき

- 今の画面の文脈（どの項目・どのページか）を保ったまま、短い入力や選択をさせるとき
- 一覧を一時的に開いて、選んだら閉じるとき

## 使わないとき

- はい・いいえだけの確認 → [確認ダイアログ](confirm-dialog.md)
- 外部に触る操作の確認 → [承認カード](approval-card.md)
- 画面の上から出る切り替え → 同じ板を上から出す（下の「使用例」のコース切替パネル）
- 何画面も続く手続き（シートの中で画面を移らない）

## バリアント

| バリアント | 中身 |
| --- | --- |
| 入力のシート | 見出し → 入力や選択（[入力バー](memo-input-bar.md)の3行、[選択肢ボタン](choice-button.md)など）→ 全幅の確定ボタン |
| 一覧のシート | 見出し → [状態付きリスト項目](status-list-item.md)などの一覧。ないときは「ありません」。確定ボタンは置かない |

スライドエディタでの中身の例は次のとおりです。

| シート | 中身 |
| --- | --- |
| ページを追加 | 前後のページの小さな枠 → [選択肢ボタン](choice-button.md)の位置 → [メモ入力バー](memo-input-bar.md)（3行）→ ブルーの全幅ボタン「追加リクエストとして下書きに積む」 |
| ページを削除 | 「nページ」→ メモ入力バー（削除する理由）→ 赤い全幅ボタン「削除予定にする」。削除予定があるときは「このページは削除予定です（提出済み）」と理由、下書きなら「削除予定を取り消す」 |
| 行き場のないメモ | 行き場のないスレッド（題・「もとはnページ ・ n件」）とページの追加・削除の依頼（シートの中）の一覧。ないときは「ありません」 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 閉じている | なし | |
| 開いている | 幕の上に、下端に付いた板 | |
| 送信できない | 全幅ボタンが不透明度 0.4 で押せない | 入力が空 |
| フォーカス | フォーカスの輪 | |

幕を押すか × を押すと閉じます。全幅ボタンを押すと、その作業を確定して閉じます（スライドエディタでは依頼を下書きに積む）。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 幕 | 黒の 40%。キーボードと一緒に出る入力のシートは黒の 70% | `--scrim` `--scrim-strong` |
| 板 | 白、最大幅 512px、高さは画面の 88% まで（はみ出すとスクロール）、浮く影 | `--surface` `--shadow-float` |
| 板の角丸 | 上の2つの角だけ 20px。640px 以上では4つの角 | `--radius-card` |
| 内側の余白 | 16px 16px 24px | |
| 見出しの行 | 16px / 600 の見出し＋右端に 32px の丸い ×（[アイコンボタン](icon-button.md)の丸）、下に 16px | `--text` |
| 全幅ボタン | 高さ 48px 以上、14px / 600、上に 16px | 角丸 `--radius-row` |
| 全幅ボタンの色 | 追加はブルー、削除は赤、取り消しは `--fill` に 1px の枠。色の面の文字は面に合わせる | `--accent` `--accent-ink` `--danger` `--danger-ink` `--fill` `--border` |
| 一覧の行 | `--fill` の面、1px の枠、内側 12px 16px、行同士 8px。題 14px / 500、補足 12px | `--fill` `--border` `--radius-row` `--dim` |

全幅ボタンは角丸 12px で、[ボタン](button.md)のピルと形が違います。シートの下に並ぶ「確定」はフォームの一部として扱い、入力欄と同じ 12px にします。削除の確定は赤い面にしてよいものとします（[決定記録 0005](../decisions/0005-states-and-exceptions.md)）。

## アクセシビリティ

- 幕は `role="dialog"` と `aria-modal="true"` にし、見出しをダイアログの名前に結び付ける（`aria-labelledby`）。
- 開いたらシートの中の最初の入力（なければ ×）にフォーカスを移し、シートの外へフォーカスが出ないようにする。Esc で閉じ、開いたボタンにフォーカスを戻す。
- × は `aria-label="閉じる"` にする。
- 赤い全幅ボタンは色だけでなく文（「削除予定にする」）で何が起きるかを書く。

## 使用例

### コース切替パネル（学習ノート）

ホームの左上のコースのアイコン（44×32px、角丸 8px）＋ ▼（11px、`--dim`）を押すと、画面の上端から板が出てコースを切り替えます。板の中はキッカー「コース」＋閉じる ✕（[アイコンボタン](icon-button.md)）＋コースのアイコン（76×56px、角丸 14px）とコース名のグリッド＋注記です。コースが1つしかないときは、切り替えのボタンごと出しません。

| 項目 | 値 | トークン |
| --- | --- | --- |
| 板 | 白、下に 1px の罫線、内側の余白 16px 16px 20px | `--surface` `--border` |
| 幕 | 黒の 40% | `--scrim` |
| グリッド | 折り返しの横並び、間隔 16px。項目は幅 92px、14px / 700、押せる範囲 44px 以上 | `--size-tap-target` |
| 選択中のコース | アイコンの外側に 3px の輪（3px 離す） | `--accent` |
| アイコンの面 | コースの色に白の 800 の略称。コースの色は中身側の色で、トークンにしない（[色](../foundations/color.md#中身側の色)） | |
| 注記 | 12px | `--dim` |

切り替えのボタンは `aria-label="コース一覧を開く"` と `aria-expanded` を持ち、見た目に出さないコース名を視覚的に隠した文で入れます。各コースは `<button>` で、選択中は `aria-current="true"` にします。コースを選ぶとホームを切り替えて閉じます。
