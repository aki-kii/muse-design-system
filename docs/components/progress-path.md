# 進捗パス（Progress Path）

## 概要

順番の決まった段階を、円形のノードで縦に並べて線でつなぎ、どこまで終わって次にどこへ進むかを見せる部品です。[リスト行](list-rows.md)のタスク行と違い、段階の状態は本人がチェックを付けるのではなく、中身の進み具合で決まります。

## 使うとき

- 順番に進める段階の並び（学習の段階、手続きのステップ、連続した課題）
- 段階ごとに「完了・現在・途中・未開放」を見せたいとき

## 使わないとき

- 順番のない一覧 → [メディアカード](media-card.md)や[リスト行](list-rows.md)
- 本人がチェックを付けて完了にするもの → [リスト行](list-rows.md)のタスク行
- 段階が1つだけのとき（パスにせず[ボタン](button.md)で始める）
- 進み具合の割合だけを見せる → [リスト行](list-rows.md)のメーター

## バリアント

| バリアント | 構成 | 用途 |
| --- | --- | --- |
| ノード | 円＋題＋状態の文 | 開ける段階。行全体が押せる |
| 区切りの見出し | 14px / 700 の `--dim` の文字 | 段階のまとまりの区切り |

## 状態

| 状態 | 円 | 題と状態の文 | 押せるか |
| --- | --- | --- | --- |
| 完了 | 塗った円に印（★ や ✓） | 題は `--dim`、状態の文「完了」 | 押せる |
| 現在 | `--accent` の面に `--accent-ink` の ▶ | 題は太字、状態の文「次はここ」を `--accent-strong`。行全体を `--surface` の面と 2px の `--accent` の内枠で囲む | 押せる |
| 途中 | `--surface` の面に `--accent` の ▶ と枠 | 状態の文「途中」 | 押せる |
| 未開放 | `--surface` の面に `--faint` の ・ と `--border` の枠 | 題は `--dim`、状態の文なし | 押せない |
| フォーカス | フォーカスの輪 | | 押せるノードだけ |

現在地は1つだけにします。完了の円は `--gold` の面に `--gold-ink` の印にします。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| ノードの円 | 直径 44px、枠 3px | `--size-tap-target` `--border` |
| 円の中の記号 | 17px / 800 | |
| 行の高さ | 56px 以上、内側の余白 8px | `--space-row` |
| 行同士の間隔 | 4px | `--space-inner` |
| 現在の行の角丸 | 20px | `--radius-card` |
| 縦線 | 幅 3px、角丸 2px、円の中心を通る | `--border` |
| 状態の文 | 12px / 700 | |

パスが長く、現在地が画面の外に出るときは、パスの上に現在地を1行で固定してよいです。

## アクセシビリティ

- ノードの列は `<ol>` にする（順番に意味があるため）。まとまりごとに `<section>` と `aria-label`。
- 押せるノードは `<button>` にし、`aria-label` に「題・状態」を入れる。
- 未開放のノードはボタンにせず、`aria-label` で「〇〇はまだ先」と伝える。
- 円の記号は `aria-hidden="true"` にし、状態は文で伝える。色と記号だけにしない。
- 開いたときに現在のノードまでスクロールする場合、上に固定した帯に隠れないよう `scroll-margin-top` を取る。
