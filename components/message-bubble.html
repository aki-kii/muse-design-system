吹き出し（Message Bubble）

会話のための部品。チャット画面だけで使う

デモ

エージェント・本人・時刻の区切り

  1. きょう 9:12

  2. アシスタント: おはよう。今日は午後に打ち合わせが1件あります。

  3. あなた: ありがとう。資料は午前中に見ておくね

  4. アシスタント: 了解です。

メタ行付き（名前 ・ 時刻）

  1. タイトルをもう少し短くしたい10:02

  2. 「週末の読書会のふりかえり」にしました。アシスタント ・ 10:05

「下書き」を足したスライドエディタの形はスレッドの会話にあります。長押しの動きは長押しメニューのデモで確かめられます。

概要#

会話のための部品です。エージェントはグレーで左、本人はブルーで右に置きます。使う場所をチャット画面だけに決めることが、このシステムで最も大事な使い分けです。

吹き出しごとに操作（返信・コピー・選択・削除）が要るときは、長押しで長押しメニューを開きます。

使うとき#

  • 本人とエージェントのやり取りが時系列で流れる、チャット画面の中だけ
  • 短い発言の連なり。長い報告はカードかページに載せる
  • 項目に付けたメモのやり取り（例: スライドエディタのスレッドの会話）

使わないとき#

  • Daily Brief やレポートなどの読み物ページには使わない → ページ見出しとセクションカードで組む
  • 予定表や数字の羅列を吹き出しに入れない → リスト行と数値タイル
  • やり取りの一覧には使わない → 状態付きリスト項目

バリアント#

バリアント面文字位置
エージェント--fill--text左
本人--bubble-user--bubble-user-ink右
時刻の区切りなしSmall 段、--faint中央。まとまりが変わるところに挟む
メタ行付き上の2つと同じ吹き出しの中の右下に、10px の「名前 ・ 時刻」（エージェントは名前を前に付ける）吹き出しごとに時刻を見せるとき

本人の吹き出しは --accent と同じブルーの面に白の文字です（--bubble-user・--bubble-user-ink）。吹き出しを使っている実アプリ（スライドエディタ）の見た目に合わせました（決定記録 0003）。

状態#

ふだんは押せない部品なので、状態を持ちません。長押しメニューを付けたときだけ、次の状態を持ちます。

状態見た目条件
通常文は選べない（長押しと文の選択がぶつからないようにする）
長押し見た目は変えず、長押しメニューを開く動かさずに 450ms 押し続けた
選択中文が選べるようになるメニューの「選択」を押した

メタ行に「下書き」を足す状態は、スライドエディタ固有の拡張としてスレッドの会話に移しました。

仕様#

項目値トークン
角丸20px（話し手側の下の角だけ 6px）--radius-card --radius-small
最大幅85%
文字14px--text-sm
内側の余白上下 8px・左右 16px--space-row
吹き出し同士（スレッド）8px--space-row
メタ行10px、右寄せ、本文との間 4px面に合わせて --dim（本人側は --bubble-user-ink を不透明度を下げずに使う）

値はスライドエディタの現行に合わせています。本人側のメタ行だけは、スライドエディタの白の 75%（ブルーの面に対して 3.2:1）では 4.5:1 に届かないため、--bubble-user-ink をそのまま使います（決定記録 0003）。

アクセシビリティ#

  • 会話の並びは <ol> や role="log" にし、新しい発言が読み上げられるようにする。
  • 誰の発言かを位置と色だけで伝えない。読み上げ用に話し手の名前を持たせる（見た目では隠してよい）。
  • 長押しメニューを付けるときは、キーボードでも開けるように吹き出しにフォーカスを当てられるようにする（詳しくは長押しメニュー）。吹き出しの上ではブラウザの標準の長押しメニューを出さない。
