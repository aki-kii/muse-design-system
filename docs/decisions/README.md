# 決定記録

デザインの判断のうち、あとから「なぜこうなっているか」を確かめたくなるものを1件1ファイルで残します（ADR: Architecture Decision Record の形）。

- 新しく書くときは [0000-template.md](0000-template.md) をコピーし、番号を1つ進める。
- 一度決めた記録は書き換えない。判断を変えるときは新しい記録を足し、古い記録の状態を「置き換え済み」にする。
- 書くのは決めたことだけ。判断の粒度で1件にまとめ、細かい値は各部品・ファウンデーションの文書に書く。
