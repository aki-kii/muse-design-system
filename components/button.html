ボタン（Button）

操作を始める。強さは3段＋危険のゴースト

デモ

バリアント

詳しく見る

状態（プライマリ）

通常 押下 無効 フォーカス

押すと結果をトーストで知らせます。Tab キーでフォーカスの輪も確かめられます。

概要#

操作を始めるための部品です。強さは3段（プライマリ・セカンダリ・ゴースト）と、危険操作用のゴースト、答え合わせ用の確認ボタンがあります。強さは重要度で選び、見た目の好みで選びません。

使うとき#

  • プライマリは「この画面で一番進めたい操作」に1つだけ
  • セカンダリはプライマリの相方（あとで・キャンセルなど）
  • ゴーストは補助的な遷移（詳しく見るなど）

使わないとき#

  • プライマリを2つ並べない（順位が消える）
  • 単なる情報表示にボタンを使わない → チップかタグ
  • 危険操作をプライマリにしない → 危険のゴースト＋承認をはさむ型

バリアント#

バリアント面文字用途例
プライマリ--accent--accent-ink一番進めたい操作続ける
セカンダリ--fill--textプライマリの相方あとで
ゴーストなし--accent-strong補助的な遷移詳しく見る
危険のゴーストなし--danger削除・拒否削除
確認--ok--ok-ink答えを確かめる・採点する操作だけ答え合わせ
  • セカンダリの --fill の面は、カードやシートの中（--surface の上）で使う。--bg の上に直接置くときは、面を --surface にして --border の 1px の枠を付ける（--fill と --bg はほぼ同じ明るさのため。決定記録 0003）。
  • 確認は学習ノートの「答え合わせ」の現行の形で、プライマリの代わりに使う。1画面に1つだけにする。
  • シートやダイアログの下に並ぶ確定ボタン（全幅・角丸 12px）と、確認ダイアログの赤い面の「削除する」は、フォームの一部としての例外です。シートモーダル・確認ダイアログを見てください（決定記録 0005）。

状態#

状態見た目条件
通常上の表のとおり
押下色が濃くなる押している間
無効不透明度 0.4 にして押せなくする操作の条件がそろっていない（例: 送信できない）
フォーカス--accent の 2px の輪（外側に 2px 離す）キーボードで選ばれたとき

仕様#

項目値トークン
高さ44px 以上--size-tap-target
角丸999px（ピル）--radius-pill
文字15px / 600
横の余白22px
ボタン同士の間隔10px

アクセシビリティ#

  • <button> 要素を使う。画面の移動だけのゴーストは <a> でもよい。
  • 無効は disabled 属性で示す。押せない理由が分かりにくいときは、近くに文で理由を書く。
  • ラベルは動詞を含む短い文にする（「続ける」「1回だけ許可」）。
