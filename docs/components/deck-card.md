# デッキカード（Deck Card）

## 概要

スライドのデッキ（1回の登壇分のスライドの束）を一覧で見せるカードです。上に表紙のサムネイル、下にタイトルと「枚数・更新日」を置きます。カード全体を押すとそのデッキのエディタを開きます。

## 使うとき

- スライドエディタのデッキ一覧（最初の画面）
- 表紙を見れば中身が思い出せるもの。サムネイルが選ぶ手がかりになるとき

## 使わないとき

- 単発の学習ノートの一覧 → [本棚カバーカード](shelf-cover-card.md)
- 表紙の絵がなく、文字だけで足りる一覧 → [リスト行](list-rows.md)
- 読み物ページの話題の単位 → [セクションカード](section-card.md)

## バリアント

なし（1種類だけ）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | 表紙のサムネイル＋タイトル＋メタ情報 | |
| 押下 | そのデッキのエディタへ移る | |
| フォーカス | フォーカスの輪 | キーボードで選ばれたとき |
| 表紙なし | サムネイルの位置に `--fill` の面とタイトルの文字 | 1枚目がまだ描けないとき（元のアプリの読み込み中・画像なし） |

## 仕様

構成:

1. 表紙のサムネイル（1枚目のスライドを縮小して描く）
2. タイトル
3. メタ情報（「n枚」と更新日）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 並べ方 | 縦1列、カード同士 24px、外側 24px 16px | |
| カードの面 | 白、1px の枠、カードの影、はみ出しは隠す | `--surface` `--border` `--shadow-card` |
| 角丸 | 20px | `--radius-card` |
| サムネイル | 幅いっぱい、比 980:552、下に 1px の罫線 | `--border` |
| サムネイルの中身 | [スライドの型](../patterns.md#e-スライドの型)をそのまま縮小（寸法はサムネイルの幅に対する割合） | 色はデッキ側の色（[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 18） |
| メタ部分の余白 | 16px | |
| タイトル | 14px / 600、行間 1.7 | `--text` `--text-sm` |
| メタ情報 | 12px、項目の間 16px、タイトルとの間 8px | `--dim` `--text-xs` |

## アクセシビリティ

- カード全体を1つの `<button>`（または `<a>`）にし、`aria-label` はデッキのタイトルにする。並びは `<ul>` と `<li>`。
- サムネイルの中の文字は読み上げに出さない（`aria-hidden="true"`）。タイトルと重複するため。
- 枚数と日付は「18枚」「11月15日」のように単位付きの文で出す。
