# ページプレビューカード（Page Preview Card）

**アプリ固有の複合体。** スライドエディタでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

ページを追加するとき、「前のページ」と「次のページ」の2つの小さな枠を横に並べて、どこに入るかを見せる部品です。枠はスライドと同じ比で、中にページ番号だけを出します。

## 組み合わせ

- スライドと同じ比の小さな枠を2つ横に並べ、中にページ番号だけを出す（押せない）

## 使うとき

- [シートモーダル](../../components/sheet-modal.md)の「ページを追加」で、[位置ラジオ](position-radio.md)の上に置く
- 前後関係を見ながら差し込む位置を選ばせるとき

## 使わないとき

- スライドの中身を見せる → [スライドステージ](slide-stage.md)、[デッキカード](deck-card.md)のサムネイル
- 押して選ぶ → 位置ラジオ（プレビューは押せない）

## バリアント

| バリアント | 見た目 | 条件 |
| --- | --- | --- |
| ページあり | 「n ページ」 | |
| なし | 「なし」（薄い文字） | 最後のページで、次のページがない |

## 状態

押せない部品なので、状態を持ちません。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 並べ方 | 2つを横に同じ幅で、間 12px | |
| 見出し | 「前のページ」「次のページ」、12px、枠との間 4px | `--dim` `--text-xs` |
| 枠 | 比 980:552、白の面、1px の枠、内側 8px、中央に文字（スライドエディタの現行） | `--surface` `--border` |
| 角丸 | 6px | `--radius-small` |
| 枠の中の文字 | 11px。「なし」は一段薄い色（不透明度で薄くしない） | `--dim` `--text-2xs`、「なし」は `--faint` |

## アクセシビリティ

- 2つの枠は飾りに近いので、見出しと文字をそのまま読み上げさせる（「前のページ 4 ページ」「次のページ なし」）。画像にしない。
- 「なし」は薄い色だけでなく文字で示す。
