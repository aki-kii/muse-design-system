# ナビゲーション（Navigation: Sidebar / Tab Bar）

## 概要

移動の部品は2種です。広い画面は左のサイドバー、狭い画面は下に浮くタブバーにします。どちらも現在地を `--accent-soft` の面とブルーで示します。

## 使うとき

- タブバーは行き来が多い主要画面だけ（最大5つ）
- 現在地は必ず1つだけハイライトする

## 使わないとき

- 一時的な画面（適用例・詳細）をタブに入れない（戻る導線で足りる）
- タブに文字ラベルを足さない（アイコン＋現在地の色で示すのがアプリの型）

## バリアント

| バリアント | 構成 | 用途 |
| --- | --- | --- |
| サイドバー | アイコン＋ラベルの項目。目次用途では見出し（セクション名）＋インデントした小項目 | 広い画面 |
| タブバー | アイコンだけ、5つまで。画面下に浮くピル | 狭い画面 |

## 状態

| 状態 | 見た目 |
| --- | --- |
| 通常 | アイコンは `--dim`。サイドバーはポインタを重ねると `--fill` の面 |
| 現在地 | `--accent-soft` の面、アイコンは `--accent`。サイドバーの文字は太字（700） |
| フォーカス | `--accent` の 2px の輪 |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| タブの大きさ | 52×44px | `--size-tap-target` |
| タブバーの角丸 | 999px | `--radius-pill` |
| タブバーの枠 | 1px の枠（影は付けない） | `--border` |
| サイドバーの幅 | 252px | |
| サイドバーの節の見出し | 12px / 700 | `--faint` |

## アクセシビリティ

- 全体を `<nav>` で囲み、`aria-label` で何のナビゲーションかを付ける。
- 現在地の項目に `aria-current="page"` を付ける。
- タブバーは文字がないので、各タブに `aria-label` で名前を付ける。
