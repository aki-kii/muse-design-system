アイコンボタン（Icon Button）

アイコン1つで示す補助の操作。丸と四角

デモ

丸（再読み込みを押すと回る）・危険

丸（強調）・オンとオフ

四角（地の上に軽く置く）

見た目は 32px・36px ですが、押せる範囲はどれも 44px 四方です。

読み上げ（学習ノート）

インライン型

「I have been to Kyoto twice.🔊」は、経験を表す現在完了の文です。

単独型

journey

押すと en-US・速さ 0.95 で読み上げます。端末が音声合成に対応していないときは何も起きません。

概要#

文字のラベルを持たず、アイコン1つだけで操作を示す小さなボタンです。閉じる・戻る・再読み込み・削除・送信のように、形を見れば意味が分かる操作に使います。強さで選ぶボタンと違い、画面の端やほかの部品の中に添える補助の操作です。

使うとき#

  • ヘッダーの左右（戻る・閉じる・再読み込み）や、シート・パネルの閉じる ×
  • 入力欄の中の送信・音声入力、要素の横の読み上げ
  • 意味が広く知られたアイコンで足りる操作

使わないとき#

  • その画面で一番進めたい操作 → ボタンのプライマリ（文字で書く）
  • アイコンだけでは意味が伝わりにくい操作 → 文字のあるボタン
  • 押せない印（状態のバッジ）→ 状態付きリスト項目の先頭の印、完了バッジ
  • 横に3つ以上並べない（意味が覚えられなくなる）。メニューにまとめる

バリアント#

バリアント見た目用途
丸32px の円。--fill の面に 1px の枠、アイコンは --dimヘッダー・シートの補助操作
丸（強調）32px の円。--accent の面に --accent-ink のアイコン入力欄の送信
四角36px、角丸 10px、面なし。アイコンは --dim✕ や 🔊 のように、地の上に軽く置く操作
危険丸と同じ形で、アイコンを --danger削除（押したあとに確認ダイアログを出す）
読み上げ🔊 で、直前の英文1つを音声で読む。四角の単独型と、本文の中に入れるインライン型英単語・英語の例文・英文の模範解答の直後（学習ノート）

アイコンは DS のアイコンの組（Lucide の形の線のアイコン。アイコン）を使います。

読み上げ#

型見た目置く場所
単独型四角（36×36px、角丸 10px）に 20px の 🔊、--dim単語カードの単語と例文の横、模範解答の枠の見出しの横
インライン型本文の英文の直後に 15px の 🔊（左に 2px）。行の中に収まる解説ページの本文（lang="en" の範囲ごとに1つ）、復習の文脈の枠
  • 日本語の文とページ全体の読み上げには使わない。音声以外の操作に 🔊 の形を使わない。
  • 読み上げる文は、画面の英文から括弧の注記を除いたもの。言語は en-US、速さ 0.95。カードを出した時点で音声を用意し、押してすぐ鳴らす。
  • 読み上げ中も見た目は変えず、押し直すと最初から読む。端末が音声合成に対応していなければ何も起きない。
  • 自動では再生しない。音は本人が押したときだけ出す。
  • アイコンは学習ノートの現行どおり絵文字の 🔊。線のアイコンへの置き換えは、学習ノートの画面を作り直すときに行う。

状態#

状態見た目条件
通常上の表のとおり
押下・ホバー四角は --fill の面が出る。丸は 0.9 倍に縮む
処理中アイコンが回る（再読み込み）。押せない押した操作を待つ間
無効不透明度 0.4、押せない操作できない
オンaria-pressed="true" の見た目（例: 音声入力中）押すたびに切り替わる操作
フォーカスフォーカスの輪

仕様#

項目値トークン
丸の見た目32×32px--radius-pill
四角の見た目36×36px、角丸 10px
押せる範囲見た目の外側に広げて 44px 四方--size-tap-target
アイコン16〜20px、線 2〜2.6px--dim（強調は --accent-ink）
並べるときの間隔8px

見た目の 32px・36px は、この部品だけの寸法です。見た目は小さくしてよく、押せる範囲を外側に広げて 44px を確保します（決定記録 0004）。

アクセシビリティ#

  • <button> にし、必ず aria-label を付ける（例:「閉じる」「一覧に戻る」「再読み込み」）。アイコンの SVG は aria-hidden="true"。
  • 切り替わる操作は aria-pressed を付け、ラベルも押したあとに起きることに変える（「音声入力」／「音声入力を終了」）。
  • 読み上げのインライン型は本文の HTML に後から足すため、role="button"・tabindex="0"・aria-label="読み上げる" を付け、Enter と Space でも読み上げる。
  • 処理中は disabled にし、終わったら結果をトーストなどの文で伝える。
