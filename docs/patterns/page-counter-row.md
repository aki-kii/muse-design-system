# ページカウンタ行（Page Counter Row）

**出自:** スライドエディタ。別のアプリで要るときは、まず下の「組み合わせ」の汎用部品で組みます（[昇格のルール](../decisions/0002-component-admission.md)）。

## 概要

[スライドステージ](slide-stage.md)の下に置く1行です。左に「今のページ / 全体」、右端に「行き場のないメモ（n）」のリンクを出します。行き場のないメモは、ページが消えたり並びが変わったりして、元のページに戻せなくなったスレッドと依頼のことです。

## 組み合わせ

- 「n / 全体」の文字（`tabular-nums`）
- 行き場のないメモへのリンク（[ボタン](../components/button.md)のゴーストに近い文字のリンク）

## 使うとき

- スライドエディタで、ステージとスレッドの一覧の間に置く
- ページ番号のほかに、どのページにも属さないものへの入口が要るとき

## 使わないとき

- 学習の進み具合 → [プレイヤートップバー](player-top-bar.md)の進捗
- 行き場のないメモが0件のときにリンクを出さない（行の左側だけにする）

## バリアント

| バリアント | 見た目 | 条件 |
| --- | --- | --- |
| ページだけ | 「4 / 18」 | 行き場のないメモがない |
| リンク付き | 「4 / 18」＋右端に「行き場のないメモ（2）」 | 行き場のないメモが1件以上 |

## 状態

| 状態 | 見た目 | 対象 |
| --- | --- | --- |
| 通常 | 上の表のとおり | |
| 押下 | 「行き場のないメモ」の[シートモーダル](../components/sheet-modal.md)を開く | リンク |
| フォーカス | フォーカスの輪 | リンク |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 行の余白 | 上 16px・左右 16px、下 0。文字のベースラインで揃える | |
| ページ | 13px / 600、数字は `tabular-nums` | `--text` |
| リンク | 12px、下線（3px 離す）、右端に寄せる | `--accent-strong` `--text-xs` |
| リンクの押せる範囲 | 高さ 44px。見た目は変えず、押せる範囲を上下に広げる | `--size-tap-target` |

リンクの押せる範囲は、元のアプリの 36px から `--size-tap-target` の 44px に広げました（[決定記録 0004](../decisions/0004-scale-and-local-values.md)）。

## アクセシビリティ

- 「n / 全体」は、ページが変わったときに読み上げで伝わるよう `aria-live="polite"` の領域に置く。
- リンクは画面の中でシートを開くので `<button>` にする。件数は文に含める（「行き場のないメモ（2）」）。
