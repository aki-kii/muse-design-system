# 学習ノートの複合体

学習ノート（解説と問題を1画面ずつめくるアプリ）でだけ使う、部品の組み合わせです。v0.4.0 で部品として足し、v0.6.0 でパターンに移しました。どれも「組み合わせ」の節に、使っている汎用の部品を書いています。

別のアプリで同じものが要るときは、ここの複合体をそのまま持ち出さず、「組み合わせ」の汎用部品で組みます。2つ目のアプリで同じ形が要ったら、[昇格のルール](../../decisions/0002-component-admission.md)に従って部品への昇格を検討します。

| 複合体 | 一言 | 組み合わせ |
| --- | --- | --- |
| [コースパス](course-path.md) | Part・Unit の下に章のノードを縦線でつなぐ学習経路 | 進捗パス |
| [今ここストリップ](now-strip.md) | 今の Part・章とクリア済みの数を上に固定して見せる | 進捗パスの現在地、セクションカードの面 |
| [プレイヤートップバー](player-top-bar.md) | ✕・進捗・コンボ・XP を並べた学習プレイヤーのヘッダー | アイコンボタン、メーター |
| [単語カード](word-card.md) | 意味を隠して思い出す。復習では意味の4択になる | フラッシュカード、選択肢ボタン |
| [クイズ選択肢](quiz-option.md) | 選択中・正解・不正解の状態を持つ解答の選択肢 | 選択肢ボタン |
| [結果バナー](result-banner.md) | 答え合わせの判定と解説。正解なら紙吹雪 | ボタン |
| [模範解答ボックス](model-answer-box.md) | 記述式の答え合わせの後に、破線の枠で模範解答を見せる | 読み上げボタン |
| [質問ボックス](ask-box.md) | ページ・問題ごとにその場で質問できる Q&A の欄 | 入力欄、ボタン |
| [読み上げボタン](speak-button.md) | 英文の横の 🔊。インライン型と単独型 | アイコンボタン |
| [章完了パネル](chapter-complete-panel.md) | ★と「章名 クリア！」、次の章へ／パスに戻る | ボタン |
| [本棚カバーカード](shelf-cover-card.md) | 表紙の色＋白い線のアイコン＋進捗で単発ノートを見せる | メディアカード |
| [コース切替パネル](course-switcher.md) | 画面の上から出てコースを切り替える | シートモーダル、アイコンボタン |

単語→復習→講義と進むセッションの画面遷移は、[時間で区切るセッションの型](../../patterns.md#d-時間で区切るセッションの型)にあります。
