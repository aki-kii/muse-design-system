# 空の状態（Empty State）

## 概要

一覧や画面に出す中身がないとき、その理由と次にできることを、中身の場所に短く出す部品です。「まだない」「見つからない」「読み込めなかった」の3つを見分けて書きます。

参考元: [Polaris の Empty state](https://polaris-react.shopify.com/components/layout-and-structure/empty-state)、[Primer の Blankslate](https://primer.style/components/blankslate)、[Carbon の Empty states](https://carbondesignsystem.com/patterns/empty-states-pattern/)。もらったのは「理由＋次の一手」という構成と3つの場合の分け方だけで、見た目は Muse DS のトークンで作っています。

## 使うとき

- 一覧がまだ1件もない（例: このページのコメントはまだありません）
- 検索や絞り込みの結果が0件（例: 見つかりませんでした）
- 読み込みに失敗した（例: 読み込めませんでした）

## 使わないとき

- 読み込み中 → [スケルトン](skeleton.md)
- 操作の結果を知らせる → [トースト](toast.md)
- 一覧の一部だけが空（例: 予定のない時間帯）→ 一覧の中で行として見せる。画面の真ん中に大きく出さない
- 画面全体の案内やチュートリアルを入れない（説明は1文まで）

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| まだない | 線のアイコン（`--faint`）＋見出し＋説明＋作る操作の[ボタン](button.md)（任意） | 初めて開いたとき、全部消したとき |
| 見つからない | 線のアイコン＋見出し＋「条件を外す」の[ボタン](button.md)のゴースト | 検索・絞り込みの結果が0件 |
| 読み込めなかった | 線のアイコン（`--danger`）＋見出し＋「もう一度読み込む」の[ボタン](button.md)のセカンダリ | 通信の失敗、サーバーの誤り |
| 小 | 見出しの1文だけ（`--dim`、14px、中央） | シートやカードの中の狭い一覧 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 表示中 | 上の表のとおり | 中身が0件、または失敗 |
| 再試行中 | 「もう一度読み込む」のボタンが処理中になり、届くまで[スケルトン](skeleton.md)に戻る | 読み込めなかったのバリアントで再試行を押した |

ボタンの状態は[ボタン](button.md)のとおりです。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 置き場所 | 中身が出るはずの場所。カードの中ならカードの面の上 | |
| 並び | 中央揃え、縦に アイコン → 見出し → 説明 → ボタン | |
| 上下の余白 | 32px（小は 24px）。この部品だけの寸法 | |
| アイコン | 32px、線 2px、`--faint`（失敗は `--danger`） | |
| 見出し | 16px / 700、`--text` | |
| 説明 | 14px / 400、`--dim`、1文まで、最大幅 32文字ほど | |
| 要素の間隔 | アイコンと見出し 12px、見出しと説明 4px、説明とボタン 16px | |

文の決まりは次のとおりです。

- 見出しは状態をそのまま書く（「まだありません」「見つかりませんでした」「読み込めませんでした」）。
- 説明は次にできることを書く。失敗の理由が分かるときだけ理由を書き、エラーコードは出さない。
- ボタンは1つまで。

## アクセシビリティ

- 見出しは周りの見出しのレベルに合わせた見出し要素にするか、`<p>` にする。アイコンは `aria-hidden="true"`。
- 検索・絞り込みの結果が0件になったときは、結果の件数を `role="status"` の領域で伝える（例:「0件」）。
- 読み込めなかったときに、フォーカスを勝手に移さない。再試行のボタンは通常の順番で届くようにする。
