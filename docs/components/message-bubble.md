# 吹き出し（Message Bubble）

## 概要

会話のための部品です。エージェントはグレーで左、本人はライトブルーで右に置きます。使う場所をチャット画面だけに決めることが、このシステムで最も大事な使い分けです。

スライドエディタのスレッドのように、吹き出しごとに操作（返信・コピー・選択・削除）が要るときは、長押しで[長押しメニュー](long-press-menu.md)を開きます。

## 使うとき

- 本人とエージェントのやり取りが時系列で流れる、チャット画面の中だけ
- 短い発言の連なり。長い報告はカードかページに載せる
- スライドエディタのスレッドの中（ページに付けたメモのやり取り）

## 使わないとき

- Daily Brief やレポートなどの読み物ページには使わない → ページ見出しと[セクションカード](section-card.md)で組む
- 予定表や数字の羅列を吹き出しに入れない → [リスト行](list-rows.md)と数値タイル
- スレッドの一覧には使わない → [スレッドカード](thread-card.md)

## バリアント

| バリアント | 面 | 文字 | 位置 |
| --- | --- | --- | --- |
| エージェント | `--fill` | `--text` | 左 |
| 本人 | `--bubble-user` | `--bubble-user-ink` | 右 |
| 時刻の区切り | なし | Small 段、`--faint` | 中央。まとまりが変わるところに挟む |
| メタ行付き | 上の2つと同じ | 吹き出しの中の右下に、10px の「名前 ・ 時刻 ・ 下書き」（エージェントは名前を前に付ける） | 吹き出しごとに時刻や下書きを見せるとき（スライドエディタのスレッド） |

## 状態

ふだんは押せない部品なので、状態を持ちません。長押しメニューを付けたときだけ、次の状態を持ちます。

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | 文は選べない（長押しと文の選択がぶつからないようにする） | |
| 長押し | 見た目は変えず、[長押しメニュー](long-press-menu.md)を開く | 動かさずに 450ms 押し続けた |
| 選択中 | 文が選べるようになる | メニューの「選択」を押した |
| 下書き | メタ行に「下書き」 | 修正依頼に出していない本人の発言 |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 角丸 | 20px（話し手側の下の角だけ 6px） | `--radius-card` `--radius-small` |
| 最大幅 | 84% | |
| 文字 | 15px | |
| 内側の余白 | 上下 12px・左右 16px | |
| 吹き出し同士（スレッド） | 8px | `--space-row` |
| メタ行 | 10px、右寄せ、本文との間 4px | 面に合わせて `--dim`（本人側は `--bubble-user-ink`） |

スライドエディタのモックは、静的ページ版 v0.3 の値で、本人の吹き出しを濃いブルーの面に白い文字、本文 14px・内側 8px 16px・最大幅 85% で作っていました。この文書では DS の値を正とします（[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 22）。

## アクセシビリティ

- 会話の並びは `<ol>` や `role="log"` にし、新しい発言が読み上げられるようにする。
- 誰の発言かを位置と色だけで伝えない。読み上げ用に話し手の名前を持たせる（見た目では隠してよい）。
- 長押しメニューを付けるときは、キーボードでも開けるように吹き出しにフォーカスを当てられるようにする（詳しくは[長押しメニュー](long-press-menu.md)）。吹き出しの上ではブラウザの標準の長押しメニューを出さない。
