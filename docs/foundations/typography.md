# タイポグラフィ

書体は Figtree（欧文・数字）と Noto Sans JP（和文）の1組だけです。階層は書体を変えず、サイズと太さで作ります。各段に「どこで使うか」を固定します。

```css
font-family: var(--font-sans); /* Figtree, "Noto Sans JP", "Hiragino Sans", sans-serif */
```

## 段

段のサイズは下の文字サイズのスケールの値だけで作ります（[決定記録 0004](../decisions/0004-scale-and-local-values.md)）。

| 段 | 太さ | サイズ（変数） | 使う場所 |
| --- | --- | --- | --- |
| Display | 800 | 30px（`--text-3xl`）・36px（`--text-4xl`） | ページの主見出しだけ。1ページに1つ |
| Heading | 700 | 18px（`--text-lg`）・20px（`--text-xl`）・24px（`--text-2xl`） | セクション見出し、カードのタイトル |
| Body | 400 | 16px・行の高さ 24px（`--text-base`） | 本文、リストの主文。本文はこの段を基準にする |
| Small | 400–600 | 12px（`--text-xs`）・14px（`--text-sm`） | 補足、メタ情報、凡例。色は `--dim` 以下にする |
| Micro | 600–800 | 11px（`--text-2xs`） | 状態のラベル（「今ここ」）、ページ番号などの小さな印だけ。文には使わない |

- 16px 未満を本文にしない。入力欄も 16px にして、iOS の拡大表示を防ぐ。
- Small と Micro を本文の代わりに使わない。11px より小さい文字は、件数バッジの数字のような部品の中の印に限り、部品の文書に値を書く。
- 本文の行間は 24px（1.5）です。読み物の解説（学習ノートのノート本文など）だけ、パターンの文書で 1.65〜1.8 に広げてよいものとします。
- 数字を縦に揃えるところ（数値タイル、時刻）は `font-variant-numeric: tabular-nums` を使う。
- 部品やパターンの文書に、スケールにないサイズ（13px・15px・22px）が書いてあるものは、その部品・パターンだけの値です。実アプリの現行値を写したもので、当面はそのまま使います。新しい部品はスケールの値で作ります。

## 文字サイズのスケール

適用済みアプリの Tailwind の設定と同じ値を `--text-*` として持ちます。`--text-2xs`（11px）は、筋トレ記録・スライドエディタ・AWS アップデートで `text-[11px]` として使われているため v0.7.0 で足しました。

| 変数 | サイズ | 行の高さ |
| --- | --- | --- |
| `--text-2xs` | 11px | 14px |
| `--text-xs` | 12px | 16px |
| `--text-sm` | 14px | 20px |
| `--text-base` | 16px | 24px |
| `--text-lg` | 18px | 28px |
| `--text-xl` | 20px | 28px |
| `--text-2xl` | 24px | 32px |
| `--text-3xl` | 30px | 36px |
| `--text-4xl` | 36px | 40px |
| `--text-5xl` | 48px | 52px |

## 文の約束

見出しは名詞で短く、補足は `--dim` の Small 段にします。ボタンは動詞を含む短い文にします（「続ける」「1回だけ許可」）。数字には単位と「あとどれくらい」を添えます。
