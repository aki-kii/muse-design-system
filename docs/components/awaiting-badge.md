# 確認待ちバッジ（Awaiting Badge）

## 概要

エージェントが返事をして、本人の確認を待っているスレッドに付ける丸い印です。`--accent` の円の中に白い吹き出しのアイコンを置きます。押せない印で、カード全体を押して開きます。

## 使うとき

- [スレッドカード](thread-card.md)の左端。最後の発言がエージェントのときだけ
- 「次は本人が見る番」を一覧で目立たせたいとき

## 使わないとき

- 件数を見せる → [スピードダイヤルFAB](speed-dial-fab.md)の件数バッジ
- エージェントが作業中 → [修正中インジケータ](typing-indicator.md)
- 解決済み → [解決済みバッジ](done-toggle.md)
- 押せるボタンとして使わない（見た目が[メモ入力バー](memo-input-bar.md)の送信ボタンに近いため、押せる場所に置かない）

## バリアント

なし（1種類だけ）。

## 状態

押せない部品なので、状態を持ちません。出るか出ないかだけです。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 大きさ | 32×32px の円 | `--radius-pill` |
| 面 | ブルー | `--accent` |
| アイコン | 吹き出し、16px、線 2.2px | `--accent-ink` |
| 本文との間 | 12px | |

## アクセシビリティ

- バッジは `aria-hidden="true"` にし、確認待ちであることはカードの `aria-label`（「〇〇（確認待ち）」）で伝える。
- 色だけで伝えないよう、アイコンの形（吹き出し）で解決済み（チェック）と見分けられるようにする。
