# スピードダイヤルFAB（Speed Dial FAB）

## 概要

画面の右下に浮く丸いボタンです。押すと上に向かって操作の一覧が開き、それぞれにラベルのピルと丸いアイコンが付きます。項目には件数のバッジを付けられます（例: スライドエディタの「修正依頼」に、まだ出していない下書きの件数）。

## 使うとき

- 画面のどこからでも呼びたい、作る系の操作が3〜4つあるとき（例: スライドエディタの「スレッドを追加」「ページを追加」「ページを削除」「修正依頼」。スレッドの一覧の上に浮かせる）

## 使わないとき

- 操作が1つだけ → 主ボタンを1つ置く（[ボタン](button.md)のプライマリ）
- 下に固定した[入力バー](memo-input-bar.md)がある画面、モーダルを開いているとき（重なる）
- 主要な画面の行き来 → [ナビゲーション](navigation.md)

## バリアント

なし（1種類だけ）。項目はよく使うものほど主ボタンの近く（下）に並べます。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 閉じている | 48px のブルーの円に「＋」 | |
| 開いている | 主ボタンが「×」に変わり、上に項目が下から順に浮き上がる（各 0.18 秒、40ms ずつずらす） | 主ボタンを押した |
| 件数あり | 項目のアイコンの右上に件数バッジ | 数えるもの（下書きなど）が1件以上 |
| 項目の無効 | 不透明度 0.4、押せない | その操作の対象がない（例: 下書きが0件の「修正依頼」） |
| 項目の文の切り替え | ラベルの文を変える（例:「ページを削除（予定）」） | 今の画面の状態で意味が変わる項目 |
| フォーカス | フォーカスの輪 | 主ボタン・項目 |

項目を押すと一覧は閉じます。まとめて送る項目の結果は、主ボタンのすぐ上に短く出します（例: スライドエディタの[送信完了メッセージ](../patterns/slide-editor/submit-message.md)）。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 位置 | 右 16px・下 12px に浮かせる。項目の間 8px | |
| 主ボタン | 48×48px の円、22px / 600 の「＋」「×」、浮く影 | `--accent` `--accent-ink` `--shadow-float` `--radius-pill` |
| 項目の押せる範囲 | 高さ 44px、ラベルとアイコンの間 8px | `--size-tap-target` |
| ラベルのピル | 13px、上下 4px・左右 12px、白、1px の枠、浮く影 | `--surface` `--text` `--border` `--shadow-float` `--radius-pill` |
| 項目のアイコン | 32×32px の白い円、アイコン 18〜20px、1px の枠、浮く影 | `--surface` `--text` `--border` `--shadow-float` |
| 件数バッジ | 高さ 20px・最小幅 20px のピル、10px / 700、まわりに 2px の背景色の縁。アイコンの右上に 4px はみ出す | 面は `--danger`、文字は `--danger-ink`、縁は `--bg` |

件数バッジの `--danger` は、「未送信の件数」として色の決まりで認めた使い方です（[色](../foundations/color.md#赤の使い方)）。48px の主ボタン、20px のバッジ、10px の数字は、この部品だけの寸法としてここに値を書きます（[決定記録 0004](../decisions/0004-scale-and-local-values.md)）。

## アクセシビリティ

- 主ボタンは `aria-label`（「メニューを開く」／「メニューを閉じる」）と `aria-expanded` を付ける。
- 項目は文字のラベルを持つ `<button>` にする。バッジの数はラベルに含める（「修正依頼（下書き3件）」）。
- 開いたら最初の項目にフォーカスを移し、Esc で閉じて主ボタンに戻す。
- 浮き上がる動きは `prefers-reduced-motion: reduce` のとき止める。
