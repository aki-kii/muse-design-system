# 承認をはさむ型（Approval Flow）

**出自:** Muse（送信・注文・予約など、アカウントや外部に触る操作のたびに出る）

外部に触る操作の型です。実行の直前で必ず[承認カード](../components/approval-card.md)をはさみ、結果をその場に残します。途中の画面遷移で確認させません。

**組み立て:** 提案の本文 → 承認カード（範囲を選ぶ）→ 結果の行＋[トースト](../components/toast.md)

## 流れ

| 段階 | 見た目 | 次へ進む条件 |
| --- | --- | --- |
| 提案 | 何をしようとしているかを本文で書く | 外部に触る操作の直前に来た |
| 確認待ち | 承認カード（1行目「誰が・何を・どこへ」＋補足＋ボタン行）。操作はここで止まる | 「1回だけ許可」「このタスク中は許可」「拒否」のどれかを押した |
| 結果 | ボタン行の代わりに、許可した範囲と時刻をカードに残す（例:「許可した（1回だけ）11:02」）。実行の結果はトーストで知らせる | |

- 「このタスク中は許可」を選んだら、同じタスクの中の同じ種類の操作ではカードを出さない。タスクが終わったら許可も終わる。
- 拒否したら操作をしない。
- 読み取りだけの操作にははさまない（確認の回数が増えて、確認が形だけになる）。
