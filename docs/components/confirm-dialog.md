# 確認ダイアログ（Confirm Dialog）

## 概要

取り消せない削除の前に、画面の中央に出して「本当にいいか」を聞く小さなパネルです。見出しの問い・何が消えるかの補足・「やめる」と「削除する」の2つのボタンだけを持ちます。

## 使うとき

- 中身ごと消える削除（例: スライドエディタのスレッドの削除。中のコメントもすべて消える）
- アプリの中だけで完結する、取り消せない操作

## 使わないとき

- 外部に触る操作（送信・注文など） → [承認カード](approval-card.md)
- 取り消せる操作、小さな削除（コメント1件の削除は[長押しメニュー](long-press-menu.md)から確認なしで消す）
- 入力や選択が要る → [シートモーダル](sheet-modal.md)

## バリアント

なし（1種類だけ）。

## 状態

| 状態 | 見た目 |
| --- | --- |
| 表示中 | 後ろの画面を `--bg` で覆い、中央にパネル |
| フォーカス | フォーカスの輪 |

「やめる」で閉じて元の画面に戻ります。「削除する」で削除して、一覧に戻ります。

## 仕様

構成は次のとおりです。

1. 見出しの問い（例:「スレッドを削除しますか？」）
2. 補足（例:「中のコメントもすべて削除されます」）
3. ボタン行（やめる／削除する）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 覆い | 幕ではなく `--bg` の不透明な面で覆う。後ろの画面は見せない（キーボードが閉じる間に後ろが透けて二重に見えないようにするため。スライドエディタの現行） | `--bg` |
| パネル | 白、最大幅 384px、左右 16px 空ける、1px の枠、浮く影 | `--surface` `--border` `--shadow-float` |
| 角丸 | 20px | `--radius-card` |
| 内側の余白 | 16px | |
| 見出し | 16px / 600 | `--text` |
| 補足 | 14px、見出しとの間 8px | `--dim` `--text-sm` |
| ボタン行 | 横に同じ幅で2つ、間 8px、上に 16px、高さ 44px、角丸 12px、14px | `--size-tap-target` `--radius-row` |
| やめる | 控えめな面、1px の枠 | `--fill` `--border` `--text` |
| 削除する | 赤い面、600 | `--danger` `--danger-ink` |

赤い面のボタンと角丸 12px は、[ボタン](button.md)の「危険操作はゴースト」「ボタンはピル」の例外です。確認ダイアログの中の最後の一押しは、もう一度確かめたうえでの操作なので、赤い面で何が起きるかをはっきり見せます。この例外は確認ダイアログとシートの中の確定ボタンに限ります（[決定記録 0005](../decisions/0005-states-and-exceptions.md)）。

## アクセシビリティ

- `role="alertdialog"` と `aria-modal="true"` にし、見出しを名前（`aria-labelledby`）、補足を説明（`aria-describedby`）に結び付ける。
- 開いたら「やめる」にフォーカスを置く（誤って Enter で消さないため）。Esc は「やめる」と同じにする。閉じたら開いたボタンに戻す。
- 「削除する」は色だけでなく文で何が起きるかを書く。
