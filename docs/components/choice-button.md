# 選択肢ボタン（Choice Button）

## 概要

2〜4個の選択肢から1つを選ばせる、大きめのボタンの組です。文で書いた選択肢を縦か横に並べ、選んだものを `--accent` の面で示します。答え合わせのある問題では、選んだ後に「正解・不正解」の判定の状態を持てます。

## 使うとき

- 文で書ける2〜4個の選択肢から1つを選ぶ（位置・種類・答え）
- 選んだだけでは画面が切り替わらず、別のボタンで確定するとき

## 使わないとき

- オン・オフ → [スイッチ](input-and-switch.md)
- 選ぶとすぐ画面が切り替わる → タブ（[ナビゲーション](navigation.md)）
- 絞り込み・小さな選択 → [チップ](chip-and-tag.md)
- 選択肢が5つ以上 → 一覧から選ぶ形にする
- 自分の言葉で書かせる → [入力欄](input-and-switch.md)

## バリアント

| バリアント | 並べ方 | 用途 |
| --- | --- | --- |
| 縦並び | 1列、間 10px、左揃えの文 | 1〜2行の文の選択肢（問題の答えなど） |
| 横並び | 同じ幅で横に2〜3個、間 8px、中央揃え | 短い語の選択肢（前／後など） |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | `--surface` の面、1.5px の `--border` の枠 | 選ぶ前 |
| 選択中 | 枠 `--accent`、面 `--accent-soft`（横並びは `--accent` の面に `--accent-ink`） | 選んだ。選び直せる |
| 正解 | 枠 `--ok`、面は薄い緑 | 答え合わせの後の正しい選択肢（判定のあるときだけ） |
| 不正解 | 枠 `--danger`、面は薄い赤 | 答え合わせの後、本人が選んだ誤り（判定のあるときだけ） |
| 確定後 | 押せない。見た目はそのまま | 答え合わせ・確定の後 |
| フォーカス | フォーカスの輪 | |

正解・不正解の薄い面はトークンがありません（[判断待ちの点](../open-questions.md#学習ノート由来の部品) 12）。正誤は色だけで伝わらないため、近くに判定の文を必ず出します（同 15）。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 高さ | 48px 以上（横並びは 44px 以上） | `--size-tap-target` |
| 内側の余白 | 上下 14px、左右 16px | |
| 角丸 | 12px | `--radius-row` |
| 枠 | 1.5px | `--border` ほか上の表 |
| 文字 | 縦並びは本文（16px、行間 1.6）、横並びは 14px / 600 | `--text` |

## アクセシビリティ

- 1つだけ選ぶ組は `role="radiogroup"` と `role="radio"`＋`aria-checked` にし、← → で選び直せるようにする。答えを選ぶ問題で「答え合わせ」まで選び直せる形なら、`<button aria-pressed>` でもよい。
- 組には `aria-label`（例:「追加する位置」）を付ける。
- 判定の後は `disabled` にし、結果は文（`role="status"`）で伝える。
