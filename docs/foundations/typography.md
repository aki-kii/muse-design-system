# タイポグラフィ

書体は Figtree（欧文・数字）と Noto Sans JP（和文）の1組だけです。階層は書体を変えず、サイズと太さで作ります。各段に「どこで使うか」を固定します。

```css
font-family: var(--font-sans); /* Figtree, "Noto Sans JP", "Hiragino Sans", sans-serif */
```

## 段

| 段 | 太さ | サイズ | 使う場所 |
| --- | --- | --- | --- |
| Display | 800 | 28–38px | ページの主見出しだけ。1ページに1つ |
| Heading | 700 | 17–22px | セクション見出し、カードのタイトル |
| Body | 400 | 16px・行間 1.55 | 本文、リストの主文。本文はこの段を基準にする |
| Small | 400–600 | 12–13px | 補足、メタ情報、凡例。色は `--dim` 以下にする |

- 16px 未満を本文にしない。入力欄も 16px にして、iOS の拡大表示を防ぐ。
- Small を本文の代わりに使わない。
- 数字を縦に揃えるところ（数値タイル、時刻）は `font-variant-numeric: tabular-nums` を使う。

## 文字サイズのスケール

適用済みアプリの Tailwind の設定と同じ値を `--text-*` として持ちます。

| 変数 | サイズ | 行の高さ |
| --- | --- | --- |
| `--text-xs` | 12px | 16px |
| `--text-sm` | 14px | 20px |
| `--text-base` | 16px | 24px |
| `--text-lg` | 18px | 28px |
| `--text-xl` | 20px | 28px |
| `--text-2xl` | 24px | 32px |
| `--text-3xl` | 30px | 36px |
| `--text-4xl` | 36px | 40px |
| `--text-5xl` | 48px | 52px |

上の「段」のサイズ（17px、13px など）は、このスケールに乗っていないものがあります（[判断待ちの点](../open-questions.md)）。

## 文の約束

見出しは名詞で短く、補足は `--dim` の Small 段にします。ボタンは動詞を含む短い文にします（「続ける」「1回だけ許可」）。数字には単位と「あとどれくらい」を添えます。
