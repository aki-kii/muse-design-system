# トースト（Toast）

## 概要

操作の結果を短く知らせる、画面下に浮くピルです。読まなくても困らない情報だけを出します。

## 使うとき

- コピー・保存・切り替えなど、結果が一目で分かる操作の後
- 文は1行に収まる長さにし、2秒強で消える

## 使わないとき

- エラーや確認が要る内容 → [承認カード](approval-card.md)や本文の中で出す
- 消えると困る情報 → 履歴に残す場所へ

## バリアント

| バリアント | 位置と形 | 表示時間 | 用途 |
| --- | --- | --- | --- |
| 標準 | 画面下の中央に浮くピル | 約 2.2 秒 | 1回の操作の短い結果 |
| 件数 | [スピードダイヤルFAB](speed-dial-fab.md)の列の一番上（右寄せ、FAB と 8px）。角丸 20px、上下 8px・左右 16px、最大幅は画面の 70%、12px の `--accent-strong` の文字 | 約 4 秒 | FAB からまとめて出した結果。何をいくつ出したかを単位付きで書く（例:「修正依頼を出しました（メモ2件・ページ依頼1件）」。スライドエディタ） |

件数は読む時間を取るため長めに出し、送った元の FAB の近くに置きます。次に出し直すと時間を数え直します。

## 状態

| 状態 | 見た目 |
| --- | --- |
| 表示中 | 画面下の中央に浮く |
| 消えた | 約 2.2 秒で消える |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 位置 | 下部中央に浮く（件数は FAB の上） | |
| 角丸 | 999px | `--radius-pill` |
| 影 | 浮く部品の影 | `--shadow-float` |
| 表示時間 | 約 2.2 秒 | |

## アクセシビリティ

- トーストを出す領域に `role="status"`（`aria-live="polite"`）を付け、読み上げで結果が伝わるようにする。
- フォーカスをトーストに移さない。
- 出入りの動きは `prefers-reduced-motion: reduce` のとき止める。
- 消えるので、操作に必要な情報やボタンを入れない。
