幕・×・Esc で閉じます。「メモを追加」は文を書くまで全幅ボタンが押せません。入力のシートなので幕は --scrim-strong。全幅ボタンはフォームの一部として角丸 12px で、削除の確定は赤い面です。影は付けず、幕との明るさの差で板を浮かせます。

概要#

画面の下からせり上がる板です。上に見出しと閉じる × を置き、中に1つの作業だけを入れます。今の画面を離れずに、短い入力や選択をさせるときに使います。広い画面（640px 以上）では中央に浮くパネルになります。

参考元: Material Design 3 の Bottom sheets、Apple HIG の Sheets。

使うとき#

  • 今の画面の文脈（どの項目を見ているか）を保ったまま、短い入力や選択をさせるとき（例: メモを追加する、並び順を選ぶ）
  • 一覧を一時的に開いて、選んだら閉じるとき（例: 項目を選ぶ、保留中のものを見る）

使わないとき#

  • はい・いいえだけの確認 → 確認ダイアログ
  • 外部に触る操作の確認 → 承認カード
  • 何画面も続く手続き（シートの中で画面を移らない）
  • 1件の中身をじっくり見せる → 一覧から詳細へ

バリアント#

バリアント中身例
入力見出し → 入力や選択（入力バーの3行、選択肢ボタンなど）→ 全幅の確定ボタンメモを追加
削除見出し → 何を消すか → 理由などの入力（任意）→ 赤い全幅の確定ボタン項目を削除
一覧見出し → 状態付きリスト項目などの一覧。ないときは空の状態の小。確定ボタンは置かない保留中の項目
上から出す同じ板を画面の上端から出す。上の角は四角、下の2つの角を 20px画面の上にある切り替えボタンから開く選択

状態#

状態見た目条件
閉じているなし
開いている幕の上に、下端に付いた板

幕を押すか × を押すと閉じます。全幅ボタンを押すと、その作業を確定して閉じます。

仕様#

項目値トークン
幕黒の 40%。キーボードと一緒に出る入力のシートは黒の 70%--scrim --scrim-strong
板白、最大幅 512px、高さは画面の 88% まで（はみ出すとスクロール）。影は付けず、幕との明るさの差で浮かせる--surface
板の角丸上の2つの角だけ 20px。640px 以上では4つの角--radius-card
内側の余白16px 16px 24px
見出しの行16px / 600 の見出し＋右端に 32px の丸い ×（アイコンボタンの丸）、下に 16px--text
全幅ボタン高さ 48px 以上、14px / 600、上に 16px角丸 --radius-row
全幅ボタンの色確定はブルー、削除は赤、取り消しは --fill に 1px の枠。色の面の文字は面に合わせる--accent --accent-ink --danger --danger-ink --fill --border
一覧の行--fill の面、1px の枠、内側 12px 16px、行同士 8px。題 14px / 500、補足 12px--fill --border --radius-row --dim

全幅ボタンは角丸 12px で、ボタンのピルと形が違います。シートの下に並ぶ「確定」はフォームの一部として扱い、入力欄と同じ 12px にします。削除の確定は赤い面にしてよいものとします（決定記録 0005）。

アクセシビリティ#

  • 板は role="dialog" と aria-modal="true" にし、見出しをダイアログの名前に結び付ける（aria-labelledby）。
  • 開いたらシートの中の最初の入力（なければ ×）にフォーカスを移し、シートの外へフォーカスが出ないようにする。Esc で閉じ、開いたボタンにフォーカスを戻す。
  • × は aria-label="閉じる" にする。
  • 赤い全幅ボタンは色だけでなく文（「削除する」）で何が起きるかを書く。
