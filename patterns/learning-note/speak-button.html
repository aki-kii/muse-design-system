読み上げボタン（Speak Button）

英文の横の 🔊。インライン型と単独型

デモ

インライン型

「I have been to Kyoto twice.🔊」は、経験を表す現在完了の文です。

単独型

journey

押すと en-US・速さ 0.95 で読み上げます。端末が音声合成に対応していないときは何も起きません。

アプリ固有の複合体。 学習ノートでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（昇格のルール）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

概要#

英文の例文・単語・模範解答の横に付けて、押すとその英文を音声で読み上げる小さなボタンです。文の中に入れる「インライン型」と、要素の横に置く「単独型」があります。

組み合わせ#

  • 単独型はアイコンボタンの四角（36px、角丸 10px）に 🔊 を入れたもの
  • インライン型は本文の中の 🔊 の文字（押せる範囲は文字の大きさ）

使うとき#

  • 英単語・英語の例文・英文の模範解答の直後
  • 解説ページの本文中の英語の例文（lang="en" を付けた範囲ごとに1つ）

使わないとき#

  • 日本語の文（読み上げの対象にしない）
  • ページ全体の読み上げ（この部品は、直前の英文1つだけを読む）
  • 音声以外の操作に 🔊 の形を使わない

バリアント#

バリアント見た目置く場所
インライン型本文の英文の直後に 15px の 🔊。行の中に収まる解説ページの本文、復習の文脈の枠
単独型36×36px の四角の中に 20px の 🔊単語カードの単語と例文の横、模範解答ボックスの見出しの横

状態#

状態見た目条件
通常🔊 を --dim で出す
読み上げ中見た目は変えない。押し直すと最初から読み直す再生中
使えない押しても何も起きない端末が音声合成に対応していない
フォーカスフォーカスの輪キーボードで選ばれたとき

仕様#

項目値トークン
単独型の大きさ36×36px、角丸 10px--dim
押せる範囲44px 以上--size-tap-target
インライン型の文字15px、左に 2px
読み上げの言語en-US、速さ 0.95

読み上げる文は、画面に出ている英文から括弧の注記を除いたものにします。カードを出した時点で、そのカードの英文の音声を先に用意し、押してすぐ鳴るようにします。

アイコンは学習ノートの現行どおり絵文字の 🔊 のままにします。DS のアイコンの組（アイコン）への置き換えは、学習ノートの画面を作り直すときに行います。新しく作る部品は最初から線のアイコンにします。

アクセシビリティ#

  • 単独型は <button> にし、aria-label="読み上げる" を付ける。
  • インライン型は本文の HTML に後から足すため role="button" と tabindex="0" を付け、Enter と Space でも読み上げる。
  • 🔊 の絵文字そのものは読み上げさせない（aria-label で名前を付ける）。
  • 自動では再生しない。音は本人が押したときだけ出す。
