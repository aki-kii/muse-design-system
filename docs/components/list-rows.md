# リスト行（List Rows: Schedule / Task / Stat）

## 概要

カードの中身を作る行のセットです。形は3種だけです。時間で並ぶ「予定行」、完了できる「タスク行」、数字を見せる「数値タイル＋メーター」。新しい行の形は増やさず、この3種のどれかを使います。

## 使うとき

- 予定行: 時刻を持つもの。色バーはカレンダーの色分けと一致させる
- タスク行: 本人が完了を付けられるものだけ
- 数値: 比較や目標がある数字。単独の数字はタイルに入れない

## 使わないとき

- 長い文章は行にせず、本文として書く
- メーター単体で見せない（現在値と残りの文がセット）
- 行ごとに違う左端の形を混ぜない（時間／チェック／数字のどれかで統一）

## バリアント

| バリアント | 構成 | 例 |
| --- | --- | --- |
| 予定行 | 時刻＋色バー＋題＋補足 | 13:00–14:30 ｜ 勉強会 |
| タスク行 | チェック＋題＋補足＋期限の文字 | 会費の振り込み ｜ 今週中 |
| 数値タイル＋メーター | 数値タイルの並び＋メーター＋残りの文 | 8,200 歩 ／ 目標 10,000 歩まであと 1,800 歩 |

## 状態

| 状態 | 見た目 | 対象 |
| --- | --- | --- |
| 通常 | | すべて |
| 完了 | チェックの丸が `--accent` で塗られ、題に打ち消し線、題の色は `--faint`。行全体の不透明度は変えない | タスク行 |
| フォーカス | `--accent` の 2px の輪 | タスク行 |

予定行と数値タイルは押せないので状態を持ちません。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 行の高さ | 44px 以上 | `--size-tap-target` |
| 行の区切り | 罫線 | `--border` |
| 数字 | `tabular-nums` | |
| 予定行の色バー | 幅 4px、角丸 2px | `--cal-common` ほか |
| タスク行のチェック | 直径 24px の丸、枠 2px | `--faint` |
| タスク行の期限 | 12px / 600、右端 | `--accent-strong` |
| 数値タイルの面 | 控えめな面、角丸 12px | `--fill` `--radius-row` |
| メーター | 高さ 8px のピル。地は罫線の色、進捗はブルー | `--border` `--accent` |
| 凡例の印 | 9px の角丸四角（角丸 3px） | `--cal-common` ほか |
| 時刻・補足 | Small 段 | `--dim` |

## アクセシビリティ

- 行の並びは `<ul>` と `<li>` にする。
- タスク行のチェックは `<input type="checkbox">`（または `role="checkbox"` と `aria-checked`）にし、題をラベルとして結び付ける。
- 完了はチェックと打ち消し線の両方で示す（色だけにしない）。
- 本人が付ける完了の色は `--accent`。相手とのやりとりが片付いたことを示す[完了トグル・完了バッジ](done-toggle.md)の `--ok` とは使い分ける（[決定記録 0005](../decisions/0005-states-and-exceptions.md)）。
- メーターは `<progress>` または `role="progressbar"` と `aria-valuenow` などを付け、残りの文も必ず添える。
- 予定行の色バーは飾りとして扱い、どのカレンダーかは凡例と文で分かるようにする。
