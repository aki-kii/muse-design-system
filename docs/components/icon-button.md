# アイコンボタン（Icon Button）

## 概要

文字のラベルを持たず、アイコン1つだけで操作を示す小さなボタンです。閉じる・戻る・再読み込み・削除・送信のように、形を見れば意味が分かる操作に使います。強さで選ぶ[ボタン](button.md)と違い、画面の端やほかの部品の中に添える補助の操作です。

## 使うとき

- ヘッダーの左右（戻る・閉じる・再読み込み）や、シート・パネルの閉じる ×
- 入力欄の中の送信・音声入力、要素の横の読み上げ
- 意味が広く知られたアイコンで足りる操作

## 使わないとき

- その画面で一番進めたい操作 → [ボタン](button.md)のプライマリ（文字で書く）
- アイコンだけでは意味が伝わりにくい操作 → 文字のある[ボタン](button.md)
- 押せない印（状態のバッジ）→ [状態付きリスト項目](status-list-item.md)の先頭の印、[完了バッジ](done-toggle.md)
- 横に3つ以上並べない（意味が覚えられなくなる）。メニューにまとめる

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| 丸 | 32px の円。`--fill` の面に 1px の枠、アイコンは `--dim` | ヘッダー・シートの補助操作 |
| 丸（強調） | 32px の円。`--accent` の面に `--accent-ink` のアイコン | 入力欄の送信 |
| 四角 | 36px、角丸 10px、面なし。アイコンは `--dim` | ✕ や 🔊 のように、地の上に軽く置く操作 |
| 危険 | 丸と同じ形で、アイコンを `--danger` | 削除（押したあとに[確認ダイアログ](confirm-dialog.md)を出す） |

アイコンは線のアイコン（24 の枠、端は丸、16〜20px）を使います。組をまだ決めていない点は[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 28 にあります。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | 上の表のとおり | |
| 押下・ホバー | 四角は `--fill` の面が出る。丸は 0.9 倍に縮む | |
| 処理中 | アイコンが回る（再読み込み）。押せない | 押した操作を待つ間 |
| 無効 | 不透明度 0.5、押せない | 操作できない |
| オン | `aria-pressed="true"` の見た目（例: 音声入力中） | 押すたびに切り替わる操作 |
| フォーカス | フォーカスの輪 | |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 丸の見た目 | 32×32px | `--radius-pill` |
| 四角の見た目 | 36×36px、角丸 10px | |
| 押せる範囲 | 見た目の外側に広げて 44px 四方 | `--size-tap-target` |
| アイコン | 16〜20px、線 2〜2.6px | `--dim`（強調は `--accent-ink`） |
| 並べるときの間隔 | 8px | |

見た目の 32px・36px は段にない寸法です（[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 23）。

## アクセシビリティ

- `<button>` にし、必ず `aria-label` を付ける（例:「閉じる」「一覧に戻る」「再読み込み」）。アイコンの SVG は `aria-hidden="true"`。
- 切り替わる操作は `aria-pressed` を付け、ラベルも押したあとに起きることに変える（「音声入力」／「音声入力を終了」）。
- 処理中は `disabled` にし、終わったら結果を[トースト](toast.md)などの文で伝える。
