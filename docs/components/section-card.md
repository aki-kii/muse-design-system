# セクションカード（Section Card）

## 概要

読み物ページの基本単位です。1カード＝1つの話題で、ページはこのカードを縦に積んで作ります。

## 使うとき

- 予定・数字・読書メモなど、話題ごとに区切って読ませるとき
- 2つ並べるときは同じ高さの話題同士だけ（グリッド）

## 使わないとき

- カードの中にカードを入れない（階層は余白で作る）
- 1行だけの情報をカードにしない → [リスト行](list-rows.md)
- 会話の代わりに使わない → [吹き出し](message-bubble.md)

## バリアント

| バリアント | 違い | 用途 |
| --- | --- | --- |
| 標準 | 構成の1〜5を持つ | 話題ごとの区切り |
| 要約カード | 見出しの代わりに差出人の1行を置き、本文は文章だけ | 読み物ページの冒頭の要約 |

## 状態

押せない部品なので、状態を持ちません。

## 仕様

構成は次のとおりです。

1. アイコン: 話題を表す1つ。`--fill` の角丸四角に置く
2. タイトル: Heading 段。話題の名前だけを短く
3. タグ: 出典・種別。右端に1つまで
4. 本文: 部品の組み合わせ。文章だけのときは Body 段
5. フッター: 凡例・補足。罫線で本文と分ける（必要なときだけ）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | 白 | `--surface` |
| 角丸 | 20px | `--radius-card` |
| 内側の余白 | 16px | `--space-card-padding` |
| カード同士の間隔 | 12px | `--space-card-gap` |
| 影 | カードの影 | `--shadow-card` |
| フッターの罫線 | 1px | `--border` |

## アクセシビリティ

- カードは `<section>` にし、タイトルを見出し要素（ページの構造に合わせて `<h2>` など）にする。
- アイコンは飾りなので `aria-hidden="true"` にする。

## 使用例

### 完了の画面（学習ノート）

章・ノート・今日の復習・今日のセッションが終わったときに、カードを1枚出して終わりを伝えます。中央揃えで ★ → 見出し → 補足 → [ボタン](button.md)を縦に並べ、出たときだけ紙吹雪を落とします。1問ごとの正誤には使いません（[答え合わせの型](../patterns/answer-check.md)）。

| 場面 | 見出し | ボタン |
| --- | --- | --- |
| 章のクリア | 「章名 クリア！」 | 次の章へ（プライマリ）＋パスに戻る（セカンダリ）。次の章がなければ「パスに戻る」だけをプライマリで |
| ノートの終わり | 「このノートはおしまい！」＋ページ数・獲得 XP・ベストコンボ・正答数 | 閉じる |
| 復習の終わり | 「今日の復習はおしまい」 | 閉じる（セッションの中では「講義へ」） |
| セッションの終わり | 「今日の分はおしまい」 | 単語を続ける（セカンダリ）＋ホームへ（プライマリ）を2列 |

| 項目 | 値 | トークン |
| --- | --- | --- |
| 内側の余白 | 24px、中央揃え | |
| ★ | 64px / 800、金色の飾りの記号（`aria-hidden="true"`） | `--gold` |
| 見出し | 24px / 800、`<h2>` | `--text-2xl` |
| 補足 | Small 段 | `--dim` |
| ボタン | 間隔 10px、見出しとの間隔 20px | |

出たら見出しへフォーカスを移すか `role="status"` で伝えます。紙吹雪は[答え合わせの型](../patterns/answer-check.md)と同じもので、`prefers-reduced-motion: reduce` のとき止めます。
