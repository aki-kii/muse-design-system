# コースパス（Course Path / Path Node）

**アプリ固有の複合体。** 学習ノートでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

学習コースの章を、Part・Unit の見出しの下に円形のノードで縦に並べ、縦線でつないで見せる部品です。どこまで終わり、次にどこをやるかを一目で分かるようにします。[リスト行](../../components/list-rows.md)のタスク行と違い、本人が完了を付けるのではなく、問題に答えた結果で状態が決まります。

## 組み合わせ

- [進捗パス](../../components/progress-path.md)（ノードの状態・縦線・現在地の決め方）
- Part 見出し（コースの色の面）と Unit 見出し。学習コース固有の区切り

## 使うとき

- 章の順番が決まっている学習コースのホーム画面
- 状態（完了・現在・途中・未開放）を章ごとに見せたいとき

## 使わないとき

- 順番のない単発ノートの一覧 → [本棚カバーカード](shelf-cover-card.md)
- 本人がチェックを付けて完了にするもの → [リスト行](../../components/list-rows.md)のタスク行
- 章が1つしかないとき（パスにせず、[ボタン](../../components/button.md)で始める）

## バリアント

| バリアント | 構成 | 用途 |
| --- | --- | --- |
| Part 見出し | コースの色の面に、白文字の題（15px / 800）と副題（12px / 600）。コースの色は白の文字に対して 4.5:1 以上のものを選ぶ | Part の区切り |
| Unit 見出し | 14px / 700 の `--dim` の文字 | Unit の区切り |
| 章ノード | 円＋章の題＋状態の文 | 開ける章。行全体が押せる |
| 未生成の Unit ノード | 円（・）＋ Unit の題 | 中身がまだない Unit。現在地になったときだけ「次はここ」と出す |

## 状態

| 状態 | 円 | 題と状態の文 | 押せるか |
| --- | --- | --- | --- |
| 完了 | `--gold` の面に `--gold-ink` の ★ と立体の影 | 題は 15px / 500 の `--dim`、状態の文「完了」 | 押せる |
| 現在 | `--accent` の面に `--accent-ink` の ▶、影は `--accent-strong` | 題は太字（700）、状態の文「次はここ」（途中なら「途中」）を `--accent-strong`。行全体を `--surface` の面と 2px の `--accent` の内枠で囲む | 押せる |
| 途中 | `--surface` の面に `--accent` の ▶ と `--accent` の枠 | 状態の文「途中」 | 押せる |
| 未開放 | `--surface` の面に `--faint` の ・ と `--border` の枠 | 題は `--dim`、状態の文なし | 押せない |
| フォーカス | フォーカスの輪 | | 押せるノードだけ |

現在地は1つだけです。決め方: 途中の章のうち一番後ろのもの → なければ最初の未完了の章 → なければ最初の未生成の Unit。現在地より前の章と、完了・途中の章は開けます。

## 仕様

構成:

1. Part 見出し（Part ごとに1つ）
2. Part に直接属する章のノード列
3. Unit 見出し＋その Unit のノード列（Unit の数だけ）

| 項目 | 値 | トークン |
| --- | --- | --- |
| ノードの円 | 直径 44px、枠 3px | `--size-tap-target` `--border` |
| 円の中の記号 | 17px / 800 | |
| 行の高さ | 56px 以上、内側の余白 8px | `--space-row` |
| 行同士の間隔 | 4px | `--space-inner` |
| 現在の行の角丸 | 20px | `--radius-card` |
| 縦線 | 幅 3px、角丸 2px、円の中心を通る | `--border` |
| 完了の円の面 | 金色の面に濃い茶の ★（白の ★ では 1.8:1 で届かないため） | `--gold` `--gold-ink` |
| 円の立体の影 | 下に 4px のずらし影（影を付けずに `0 4px 0` の色の帯）。現在は `--accent-strong`、完了は黒の 15%。このパターンだけの値 | `--accent-strong` |
| Part 見出しの面 | コースの色（中身側の色。コースのデータが持つ値） | DS のトークンにしない |
| Part 見出しの角丸 | 12px | `--radius-row` |
| Part 見出しの間隔 | 上に 24px | |
| 状態の文 | 12px / 700 | |

## アクセシビリティ

- Part ごとに `<section>` にし、Part の題を `aria-label` にする。ノードの列は `<ol>` にする（順番に意味があるため）。
- 押せるノードは `<button>` にし、`aria-label` に「題・状態」を入れる（例: 「疑問文と否定文・次はここ」）。
- 未開放のノードはボタンにせず、`aria-label` で「〇〇はまだ先」と伝える。
- 円の記号（★ ▶ ・）は `aria-hidden="true"` にし、状態は文で伝える。色と記号だけにしない。
- ホームを開いたときに現在のノードまでスクロールする場合、[今ここストリップ](now-strip.md)に隠れないよう `scroll-margin-top` を取る。
