進捗パス（Progress Path）

順番のある段階をノードと線でつなぎ、現在地を見せる

デモ

ステップ 1 準備

ステップ 2 記録

  2. ・月の予算を立てる

完了・現在・途中・未開放の4つの状態です（架空の手順）。押せるノードを押すとトーストで知らせます。完了の円は --gold の面に --gold-ink の印です。

概要#

順番の決まった段階を、円形のノードで縦に並べて線でつなぎ、どこまで終わって次にどこへ進むかを見せる部品です。リスト行のタスク行と違い、段階の状態は本人がチェックを付けるのではなく、中身の進み具合で決まります。

使うとき#

  • 順番に進める段階の並び（学習の章、手続きのステップ、連続した課題）
  • 段階ごとに「完了・現在・途中・未開放」を見せたいとき

使わないとき#

  • 順番のない一覧 → メディアカードやリスト行
  • 本人がチェックを付けて完了にするもの → リスト行のタスク行
  • 段階が1つだけのとき（パスにせずボタンで始める）
  • 進み具合の割合だけを見せる → リスト行のメーター

バリアント#

バリアント構成用途
ノード円＋題＋状態の文開ける段階。行全体が押せる
区切りの見出し14px / 700 の --dim の文字段階のまとまりの区切り

まとまりの見出しを色の面にするなど、アプリ固有の飾りはパターン側で足します（例: 学習ノートの Part 見出し）。

状態#

状態円題と状態の文押せるか
完了塗った円に印（★ や ✓）題は --dim、状態の文「完了」押せる
現在--accent の面に --accent-ink の ▶題は太字、状態の文「次はここ」を --accent-strong。行全体を --surface の面と 2px の --accent の内枠で囲む押せる
途中--surface の面に --accent の ▶ と枠状態の文「途中」押せる
未開放--surface の面に --faint の ・ と --border の枠題は --dim、状態の文なし押せない
フォーカスフォーカスの輪押せるノードだけ

現在地は1つだけにします。完了の円は --gold の面に --gold-ink の印にします（学習ノートの完了したノード）。

仕様#

項目値トークン
ノードの円直径 44px、枠 3px--size-tap-target --border
円の中の記号17px / 800
行の高さ56px 以上、内側の余白 8px--space-row
行同士の間隔4px--space-inner
現在の行の角丸20px--radius-card
縦線幅 3px、角丸 2px、円の中心を通る--border
状態の文12px / 700

パスが長く、現在地が画面の外に出るときは、パスの上に現在地を1行で固定してよいです（例: 学習ノートの今ここストリップ）。

アクセシビリティ#

  • ノードの列は <ol> にする（順番に意味があるため）。まとまりごとに <section> と aria-label。
  • 押せるノードは <button> にし、aria-label に「題・状態」を入れる。
  • 未開放のノードはボタンにせず、aria-label で「〇〇はまだ先」と伝える。
  • 円の記号は aria-hidden="true" にし、状態は文で伝える。色と記号だけにしない。
