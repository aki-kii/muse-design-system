フラッシュカード（Flashcard）

表で問い、裏を開いて自己判定する

デモ

自己判定（答えを開いて判定する）

状態: 答えを開いた

用語 2 / 3

キャッシュ
よく使うデータを、速く取り出せる場所に一時的に置いておくこと

中身は架空の用語集です。表の文字の大きさは中身に合わせて決めます。

概要#

表と裏を持つカードを1枚ずつ見せ、裏を開いたあとで本人に「覚えていたか」を判定させる部品です。表で問い、裏で答え、判定で次のカードへ進みます。中身（単語・用語・手順など）には依存しません。

使うとき#

  • 問いと答えの組を、短い間隔で繰り返し思い出させたいとき（語と意味、用語と定義、記号と読み方）
  • 正誤を機械で採点せず、本人の自己判定で次に進めてよいとき

使わないとき#

  • 答えを選ばせて採点する → 選択肢ボタン
  • 解説を読ませる → セクションカード（フラッシュカードの裏に長い解説を載せない）
  • 1回見れば済む情報 → カードにせず本文に書く

バリアント#

バリアント流れ用途
自己判定表 → 「タップして答えを見る」→ 裏を開く → 判定ボタン2つ（例:「もう知ってた」「覚える」）→ 次のカード標準
選んで答える表 → 裏の代わりに選択肢ボタンの縦並び → 正誤を出して次のカード前に間違えたものの復習

状態#

状態見た目条件
裏を隠している破線の枠のボタン「タップして答えを見る」と、その下に短いヒント表を出した直後
裏を開いた破線の --accent の枠に答え。その下に判定ボタン2つ隠した部分を押した
おしまい「今日の分はおしまい」などの文束の最後のカードを判定した
フォーカスフォーカスの輪キーボードで選ばれたとき

仕様#

構成は次のとおりです。

  1. キッカー（束の名前と「n / 全体」）
  2. 表の面（問い）
  3. 補足（任意。例文など）
  4. 裏の面（隠す部分）と判定ボタン
項目値トークン
キッカー13px / 700、字間 0.05em--accent-strong
表の面--surface の面、1px の枠、カードの影、内側の余白 28px 16px--surface --border --shadow-card --radius-card
隠す部分破線 2px の枠、内側の余白 28px 16px、高さ 56px 以上、700--border --dim --radius-card
裏の面破線 2px の枠、内側の余白 16px、20px / 700--accent --radius-card
判定ボタン2列、間 10px。弱い方をセカンダリ、強い方をプライマリボタン

表の文字の大きさは中身で決めます（単語なら大きく、文なら本文の段）。単語の大きさ（学習ノートの 36〜52px など）は、使う側のパターンの文書に値を書きます（決定記録 0004）。

アクセシビリティ#

  • 1枚を <article> にする。中身が日本語以外なら lang を付ける。
  • 隠す部分は <button> にし、aria-label（例:「答えを見せる」）を付ける。開いたら裏の面にフォーカスを移し、判定ボタンより前に読ませる。
  • 自動で次のカードへ進めるときは、結果の文を role="status" にし、読み終わる前に進めないよう時間を長めに取る。
  • カードが変わったら、画面の先頭へスクロールを戻す。
