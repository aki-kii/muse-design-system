# 検索フィールド（Search Field）

## 概要

一覧の中身を、打った文字でその場で絞り込むための入力欄です。虫めがねのアイコンと、打った文字を消す ✕ を持ちます。ラベルを持つ[入力欄](input-and-switch.md)と違い、一覧の上に置いて見た目だけで用途が分かる形にします。

参考元: [Carbon の Search](https://carbondesignsystem.com/components/search/usage/)、[Material Design 3 の Search](https://m3.material.io/components/search/overview)、[Primer の TextInput（先頭にアイコンを置く形）](https://primer.style/components/text-input)。もらったのは「アイコン＋欄＋消す操作」の構成と、打つたびに絞り込む振る舞いだけで、見た目は Muse DS のトークンで作っています。

## 使うとき

- 10件を超える一覧から、名前で1つを探す（例: 絵文字を選ぶシート、登録した項目の一覧）
- 打つたびに結果が変わってよい、端末の中だけで済む絞り込み

## 使わないとき

- 選択肢が数個で、全部が見えている → [チップ](chip-and-tag.md)の絞り込み、[選択肢ボタン](choice-button.md)
- 保存する値を入れる（名前・メモ・指示）→ [入力欄](input-and-switch.md)
- 会話として送る → [入力バー](memo-input-bar.md)
- 画面の主な操作が検索ではない画面のヘッダーに、常に出しておかない。一覧を開いたときだけ出す

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| 標準 | 高さ 44px のピル。`--surface` の面に 1.5px の `--border` の枠 | `--bg` の上の一覧 |
| 面 | 同じ形で枠なし、`--bg` の面 | シート・カードの中（`--surface` の上） |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 空 | 虫めがね＋プレースホルダ（`--faint`）。✕ は出さない | 何も打っていない |
| 入力中 | 文字の右に ✕ の[アイコンボタン](icon-button.md)（四角、`--dim`） | 1文字以上ある |
| フォーカス | 枠が `--accent` になり、外に `--accent` の 2px の輪（2px 離す） | |
| 結果なし | 欄はそのまま。下の一覧を[空の状態](empty-state.md)の「見つからない」にする | 絞り込みの結果が0件 |
| 無効 | 不透明度 0.4、打てない | 一覧の読み込み中 |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 高さ | 44px | `--size-tap-target` |
| 角丸 | 999px | `--radius-pill` |
| 左右の余白 | 左 14px（アイコンの前）、右 4px（✕ の後） | |
| 虫めがね | 18px、線 2px、`--dim` | |
| 文字 | 16px / 400、`--text`（16px 未満にしない。iOS で画面が拡大されるため） | `--text-base` |
| ✕ | 36×36px の見た目、押せる範囲 44px | `--size-tap-target` |
| 一覧との間隔 | 12px | `--space-card-gap` |

構成は次のとおりです。

1. 虫めがねのアイコン（飾り）
2. 欄（`<input type="search">`）
3. ✕ の[アイコンボタン](icon-button.md)（打った文字を消し、欄にフォーカスを戻す）

振る舞いは次のとおりです。

- 打つたびに絞り込む。確定の操作（検索ボタン・Enter）は要らない。
- 大文字・小文字、ひらがな・カタカナの違いは区別せずに探す。
- 打った文字は、画面を閉じたら消す（残さない）。

## アクセシビリティ

- ラベルを見せないので、欄に `aria-label` を付ける（例:「絵文字を検索」）。プレースホルダだけで名前にしない。
- 包む要素を `<search>`（または `role="search"`）にする。
- ✕ の[アイコンボタン](icon-button.md)には `aria-label="検索の文字を消す"` を付ける。ブラウザの既定の消すボタンは隠して、二重にしない。
- 結果の件数を `role="status"` の領域で伝える（例:「12件」）。打つたびに読み上げが重ならないよう、少し待ってから更新する。
