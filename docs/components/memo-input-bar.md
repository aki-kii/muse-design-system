# 入力バー（Input Bar）

## 概要

会話やメモで、短い文を書いて送るための入力欄です。角丸の欄の中にマイク（音声入力）の丸ボタンを置き、文字が入るとその左に送信の丸ボタンが現れます。文は常に欄の全幅で折り返し、ボタンと重なりません。1行の間はボタンが文と同じ行の右端にあり、文が1行に収まらなくなると欄が広がってボタンが欄の中の下段に移ります。書いている途中の文は画面を移っても残ります。

## 使うとき

- 会話の返信や、新しいやり取りの最初の文（画面の下に固定する）。例: 項目に付けたコメントのやり取り
- [ボトムシート](bottom-sheet.md)の中の短い自由記述（3行の高さで置く）。例: 「メモを追加」の本文、削除する理由
- 声でも文字でも書けるようにしたい、短い自由記述

## 使わないとき

- ラベルとヒントが要る項目 → [入力欄](input-and-switch.md)
- ページの中に埋め込む自由記述の欄 → [入力欄](input-and-switch.md)の複数行と[ボタン](button.md)で組む
- 1行で決まった値を入れるもの（日付・数値など）

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| 下に固定 | 白い面の領域（上に 1px の罫線、内側 12px 16px）の中に置く。最初は1行で、ボタンは同じ行の右端 | 会話の画面 |
| シートの中 | 文の欄は最初から3行の高さで欄の全幅。ボタンは常に欄の中の下段 | ボトムシートの中の自由記述 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 空 | プレースホルダ（`--faint`）とマイクだけ | |
| 入力あり | マイクの左に送信ボタン | 空白以外の文字がある |
| 音声入力中 | マイクが赤い面に白いアイコンになる | マイクを押した |
| 音声入力のエラー | 欄の上に 12px の赤い文（「マイクが許可されていません」など） | 許可がない・つながらない・使えない |
| 1行 | 文の欄とボタンが同じ行に並ぶ。ボタンは右端 | 文が、ボタンの左の幅に1行で収まる |
| 複数行 | ボタンが欄の中の下段（右寄せ）に移り、文の欄は欄の全幅になる。文の行が増えると欄の高さが伸び、欄全体で 152px に達したら文の欄の中をスクロール | 文がボタンの左の幅に1行で収まらない、または改行がある |
| フォーカス | フォーカスの輪 | |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 欄の面 | 控えめな面、1px の枠、内側 4px 8px | `--fill` `--border` |
| 欄の角丸 | 20px | `--radius-card` |
| 文字 | 16px、行の高さ 24px（iOS の拡大表示を防ぐ） | `--text` `--text-base` |
| 文の折り返し幅 | 常に欄の全幅（欄の内側の左右 8px＋文の欄の 4px を除いた幅）。ボタンの分だけ狭めて折り返さない | |
| ボタンの位置 | 1行の間は文と同じ行の右端、下揃え。複数行では文の欄の下に別の段として置き、右寄せ。文がボタンの横や下に回り込むことはない | |
| 最大の高さ | 欄全体で 152px（複数行のときはボタンの段 36px を含む） | |
| 丸ボタン | 見た目 32×32px の円、欄の内側の右下（下 4px）に置き、間 8px。押せる範囲は外側に 6px 広げて 44px | `--radius-pill` `--size-tap-target` |
| 送信 | ブルーの面、上向きの矢印 18px（線 2.4px） | `--accent` `--accent-ink` |
| マイク | 白い面、1px の枠、マイクのアイコン 18px | `--surface` `--text` `--border` |
| マイク（音声入力中） | 赤い面、白いアイコン | `--danger` `--danger-ink`（「録音中」は `--danger` を使ってよい。[色](../foundations/color.md#赤の使い方)） |
| エラーの文 | 12px、欄との間 8px | `--danger` `--text-xs` |

欄の角丸 20px は[入力欄](input-and-switch.md)の 12px と違います。会話の入力は吹き出しに合わせて丸く、フォームの入力は 12px、と分けています。

## アクセシビリティ

- 欄には視覚的に隠した `<label>`（例:「メモを入力」）を付ける。プレースホルダをラベルの代わりにしない。
- 送信は `aria-label="送信"`、マイクは `aria-label`（「音声入力」／「音声入力を終了」）と `aria-pressed` を付ける。
- 音声入力のエラーは `role="alert"` で伝える。
- 音声入力中であることは、色だけでなく `aria-pressed` とラベルの文で伝える。
- 送信ボタンは空白以外の文字がないあいだは `hidden` にして、見た目からも読み上げとフォーカスの順からも外す。
- 1行と複数行でボタンの位置が変わっても、フォーカスの順（文の欄 → 送信 → マイク）は変えない。
