選択肢ボタン（Choice Button）

2〜4個から1つを選ぶ大きなボタンの組。判定の状態も持てる

デモ

縦並び（選んでから確定する）

横並び（2択）

判定つき（選んで「確かめる」を押す）

1週間は何日？

状態の一覧（判定のあるとき）

押すか ← → で選び直せます。正解・不正解は --ok-soft・--danger-soft の面と、✓ ✗ の印で示します。

概要#

2〜4個の選択肢から1つを選ばせる、大きめのボタンの組です。文で書いた選択肢を縦か横に並べ、選んだものを --accent の面で示します。答え合わせのある問題では、選んだ後に「正解・不正解」の判定の状態を持てます。

使うとき#

  • 文で書ける2〜4個の選択肢から1つを選ぶ（位置・種類・答え）
  • 選んだだけでは画面が切り替わらず、別のボタンで確定するとき

使わないとき#

  • オン・オフ → スイッチ
  • 選ぶとすぐ画面が切り替わる → タブ（ナビゲーション）
  • 絞り込み・小さな選択 → チップ
  • 選択肢が5つ以上 → 一覧から選ぶ形にする
  • 自分の言葉で書かせる → 入力欄

バリアント#

バリアント並べ方用途
縦並び1列、間 10px、左揃えの文1〜2行の文の選択肢（例: 配送の方法）
横並び同じ幅で横に2〜3個、間 8px、中央揃え。未選択は --fill の面と 1px の枠、選択中は文字を 600短い語の選択肢（例: 前／後、小／中／大）
判定つき縦並びに判定の状態（正解・不正解）を足したもの。下に「確かめる」のボタンの確認答えのある問題

判定つきでは、押した瞬間には正誤を出さず、「確かめる」を押してから出します。何も選んでいない間は「確かめる」を無効にします。正解の選択肢は、選んでいなくても正解の状態で示し、判定の文を近くに必ず一緒に出します。

状態#

状態見た目条件
通常--surface の面、1.5px の --border の枠選ぶ前
選択中枠 --accent、面 --accent-soft（横並びは --accent の面に --accent-ink）選んだ。選び直せる
正解枠 --ok、面 --ok-soft、文の後ろに「 ✓」確かめた後の正しい選択肢（判定のあるときだけ）
不正解枠 --danger、面 --danger-soft、文の後ろに「 ✗」確かめた後、本人が選んだ誤り（判定のあるときだけ）
確定後押せない。見た目はそのまま確かめた・確定した後
フォーカスフォーカスの輪

正誤は色だけで伝えず、選択肢の文の後ろに ✓ ✗ の印を付け、近くに判定の文も出します（決定記録 0005）。薄い面の上の文字は --text のままにします。

仕様#

項目値トークン
高さ48px 以上（横並びは 44px 以上）--size-tap-target
内側の余白上下 14px、左右 16px
角丸12px--radius-row
枠1.5px--border ほか上の表
文字縦並びは本文（16px、行間 1.6）、横並びは 14px / 600--text

アクセシビリティ#

  • 1つだけ選ぶ組は role="radiogroup" と role="radio"＋aria-checked にし、← → で選び直せるようにする。答えを選ぶ問題で「確かめる」まで選び直せる形なら、<button aria-pressed> でもよい。
  • 組には aria-label（例:「配送の方法」）を付ける。
  • 判定の後は disabled にし、結果は文（role="status"）で伝える。
