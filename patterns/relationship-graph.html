関係グラフ（Relationship Graph）

項目同士の関係を眺めて辿り、グラフでの選択がそのまま絞り込みになる

デモ

検索・選択中のチップ・期間の入口・グラフ

項目を検索
仕様書 議事録
過去7日 一覧で見る

見本の図: 検索フィールドの下に選択中のチップ「仕様書」「議事録」、期間の入口「過去7日」と「一覧で見る」、その下に7つの項目の関係グラフ。仕様書と議事録が選択中で、2つをつなぐ太いエッジが強調されている。

期間の入口を押すと開くシートの中身（相対・絶対）

相対絶対
過去24時間 過去7日 過去30日

期間

相対絶対
11/1〜11/7

見本の図: 期間のシート。相対では「過去24時間」「過去7日」「過去30日」から選び、絶対では開始日と終了日を入れる。

形を見せる静的な見本で、押しても動きません。ノードの大きさは件数、エッジの太さは一緒に出てきた回数です。選択中のノードとチップは同じ選択を映し、期間はどちらの方式でも範囲に直して使います。中身は架空です。

よくある型である理由: 項目同士のつながりをノードとエッジの図で眺め、気になる項目を選んで周りを辿る型は、ノートや知識を扱う製品に広くあります（Obsidian の Graph view）。選んだ条件を取り消せるチップとして並べる形（Material 3 の Chips の input chip）と、相対・絶対の両方で期間を選ぶ形（Polaris の Date picking）も、絞り込みを持つ製品でよく組み合わされます。

使っているところ: AWSアップデートのスペース（サービス同士の関係を眺めて、記事の一覧を絞り込む）。

概要#

項目同士の関係をグラフで眺めて探索し、選んだ項目がそのまま絞り込みの条件になる型です。グラフで選んでも、検索で選んでも、同じ1つの選択状態に入ります。期間は小さな入口から開くシートで変え、絞った条件のまま一覧へ移れます。

組み合わせ#

  • 関係グラフ: ノード（項目。大きさは件数）とエッジ（同じ文脈に一緒に出てきた項目同士。太さは一緒に出てきた回数）。ノードを押すと選択になる
  • 検索: 検索フィールド。打つと候補（アイコン付き）を出し、候補を押すと選択に加える
  • 選択中の条件: チップの選択中を検索フィールドの下に並べる。チップを押すと取り消す
  • 期間の入口: 今の指定を書いた小さなボタン（第2ボタン）。押すとボトムシートを開く
  • 期間のシート: 相対（過去24時間・過去7日など）と絶対（開始日〜終了日の入力欄）を切り替えて選ぶ
  • 一覧への導線: 「一覧で見る」のボタン。今の選択と期間のまま一覧のビューへ移る

配置#

  • 上から、検索フィールド → 選択中のチップ → 期間の入口と一覧への導線 → グラフの順に置く。条件をまとめて上に置き、グラフは残りの広さを使う。
  • 選択中のチップの段は、選択がないときは出さない。
  • 期間の指定は常に開いておかない。入口のボタンに今の指定（「過去7日」「11/1〜11/7」）を書き、変えるときだけシートを開く。

状態の連動#

操作選択グラフチップ
検索の候補を押す項目を加えるそのノードを選択中の色にする末尾に加える
ノードを押す（選択していない）項目を加えるそのノードを選択中の色にする末尾に加える
ノードを押す（選択中）項目を外す選択中の色を戻すそのチップを消す
チップを押す項目を外す選択中の色を戻すそのチップを消す
期間を変える変えない期間に入る件数でノードの大きさ・エッジの太さを描き直す変えない
一覧で見る変えない—一覧のビューに同じ条件を引き継ぐ
  • 選択の持ち主は1つにする。グラフ・検索・チップは、どれもその選択を読み書きするだけにして、別々に持たない。
  • 選択中のノードと、選択中のノード同士をつなぐエッジは --accent で描く。ほかは --surface の面と --border の線にする。
  • 相対の期間も絶対の期間も、決めた時点で開始日時〜終了日時の範囲に直してから使う。相対の期間は、使うたびに今の時刻から範囲を出し直す。
  • 期間に入る件数が0の項目は、ノードを薄くして残すか消すかを製品ごとに決め、同じ製品の中ではそろえる。選択中の項目は0件でも消さない。

使うとき#

  • 項目同士のつながりそのものに意味があり、つながりを辿って関心のあるものを見つけたい（分類・タグ・登場する対象など）
  • 選んだ項目で一覧を絞り込み、中身は一覧で読む

使わないとき#

  • 項目のあいだにつながりがない、またはつながりを見ても判断が変わらない → 検索と絞り込み
  • ノードが多すぎて図にしても読めない（目安として数十を超える）→ 件数の多い順に絞ってから描くか、検索と絞り込みにする
  • 1件の詳細を読むのが目的 → 一覧から詳細へ

アクセシビリティ#

  • グラフだけでは選べないようにしない。同じ項目は必ず検索の候補からも選べるようにする。
  • ノードは押せる要素にし、aria-pressed で選択中かを伝え、名前に件数を含める（「仕様書、12件」）。図全体は role="group" と aria-label（「項目の関係」）で包む。
  • 選択中のチップには「仕様書の選択を外す」のような名前を付ける。
  • 選択・期間が変わったら、件数を role="status" の領域で伝える。
  • 選択中は色だけで伝えず、ノードの縁の太さやチップの並びでも分かるようにする。
