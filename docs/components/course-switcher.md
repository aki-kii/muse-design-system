# コース切替パネル（Course Switcher）

## 概要

ホーム画面の左上のコース名を押すと、画面の上から出てくるコースの一覧です。コースのアイコンを並べ、押したコースにホームを切り替えます。

## 使うとき

- 学習コースが2つ以上あり、ホームに1コースずつ出すとき

## 使わないとき

- 単発ノートの一覧 → 本棚タブと[本棚カバーカード](shelf-cover-card.md)
- 主要な画面の行き来 → [ナビゲーション](navigation.md)のタブバー
- コースが1つしかないとき（切り替えのボタンごと出さない）

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| 切り替えのボタン | コースのアイコン（44×32px）＋ ▼（11px、`--dim`）。コース名は読み上げ用の文だけに入れる | ホームの左上。パネルを開く |
| パネル | キッカー「コース」＋閉じる ✕ ＋コースのアイコン（76×56px）とコース名のグリッド＋注記 | 開いたとき |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 閉じている | 切り替えのボタンだけ | |
| 開いている | 画面の上端からパネル、その下は暗い幕 | ボタンを押したとき |
| 選択中のコース | アイコンの外側に 3px の `--accent` の輪（3px 離す） | 今ホームに出ているコース |
| フォーカス | フォーカスの輪 | キーボードで選ばれたとき |

幕を押すか ✕ を押すと閉じます。コースを選ぶと、そのコースのホームに切り替えて閉じます。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| パネルの面 | 白、下に 1px の罫線 | `--surface` `--border` |
| パネルの内側の余白 | 16px 16px 20px | |
| 幕 | 黒の 40% | 未定義（[判断待ちの点](../open-questions.md#学習ノート由来の部品) 16） |
| グリッド | 折り返しの横並び、間隔 16px | |
| コースの項目 | 幅 92px、14px / 700、押せる範囲 44px 以上 | `--size-tap-target` |
| コースのアイコンの面 | コースの色、白の 800 の略称（EN・AWS など） | 色は未定義（同 13） |
| コースのアイコンの角丸 | パネルは 14px、ボタンは 8px | 段にない（同 16） |
| 注記 | 12px | `--dim` |

## アクセシビリティ

- パネルは `role="dialog"` と `aria-label="コース一覧"` を付ける。開いたらパネルの中へフォーカスを移し、閉じたら切り替えのボタンへ戻す。Esc で閉じる。
- 切り替えのボタンは `aria-label="コース一覧を開く"`、`aria-expanded` で開閉を示す。見た目にコース名を出さないので、ボタンの中に視覚的に隠した「〇〇・コースを切り替える」を入れる。
- ✕ は `aria-label="コース一覧を閉じる"` にする。
- 各コースは `<button>` にし、`aria-label="コース 〇〇に切り替える"`、選択中は `aria-current="true"` にする。選択中は輪の色だけでなく `aria-current` でも伝える。
