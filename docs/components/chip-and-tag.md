# チップとタグ（Chip / Tag）

## 概要

チップは「選べる・押せる小さな情報」、タグは「押せない分類ラベル」です。見た目は似ていますが役割が違うので混ぜません。

## 使うとき

- チップ: 天気・睡眠のような「その場のメタ情報」の列挙、絞り込みの選択肢
- タグ: カードの出典や種別を、見出しの右端に小さく示すとき

## 使わないとき

- 重要な操作をチップにしない → [ボタン](button.md)
- タグを押せる見た目にしない（押せないものは、ピル型でも小さくして色を薄くする）
- 長い文を入れない（1チップは短い語句まで）

## バリアント

| バリアント | 見た目 | 用途 | 例 |
| --- | --- | --- | --- |
| チップ | `--fill` の面、13px / 600、アイコンを前に置ける | 押せる・状態を持つ情報 | 東京・晴れのち曇り 14℃ |
| チップ（枠線） | `--surface` の面＋ 1px の `--border` の枠 | `--fill` の面の上、またはカードの外（`--bg` の上）に置くとき。`--fill` は `--bg` とほぼ同じ明るさで見分けられないため | |
| タグ | `--fill` の面、11px / 600、文字は `--dim` | 押せない分類 | 仕事、サンプル、締切 12/23 |

## 状態

| 状態 | 見た目 | 対象 |
| --- | --- | --- |
| 通常 | 上の表のとおり | チップ・タグ |
| 選択中 | `--accent-soft` の面、文字は `--accent-strong` | チップだけ |
| フォーカス | フォーカスの輪 | チップだけ |

タグは押せないので状態を持ちません。

## 仕様

| 項目 | チップ | タグ | トークン |
| --- | --- | --- | --- |
| 高さ | 36px | 文字に合わせる（上下 3px） | |
| 文字 | 13px / 600 | 11px / 600 | |
| 横の余白 | 14px | 9px | |
| 角丸 | 999px | 999px | `--radius-pill` |
| 間隔 | 8px | | `--space-row` |

## アクセシビリティ

- 押せるチップは `<button>` にし、選択の状態は `aria-pressed` で示す。
- チップの見た目の高さは 36px なので、押せる範囲は上下に広げて 44px を確保する。
- タグは `<span>` にし、押せる要素にしない。
- 選択中は面の色と文字色の両方を変える（色の濃さだけに頼らない）。
