# コンポーネント

部品の見本帳です。新しい画面を作るときは、まずここにある部品で組めないかを見ます。

どの部品も同じ [テンプレート](_template.md) で書いています: 概要／使うとき／使わないとき／バリアント／状態／仕様／アクセシビリティ／関連。この部品集の中心は「使うとき／使わないとき」です。

| 部品 | 一言 |
| --- | --- |
| [ボタン](button.md) | 操作を始める。強さは3段＋危険のゴースト |
| [チップとタグ](chip-and-tag.md) | チップは押せる小さな情報、タグは押せない分類ラベル |
| [セクションカード](section-card.md) | 読み物ページの基本単位。1カード＝1つの話題 |
| [リスト行](list-rows.md) | 予定行・タスク行・数値タイル＋メーターの3種 |
| [入力欄とスイッチ](input-and-switch.md) | ラベル＋欄＋ヒント。スイッチは即時に効く設定だけ |
| [ナビゲーション](navigation.md) | 広い画面はサイドバー、狭い画面はタブバー |
| [承認カード](approval-card.md) | 外部に触る操作の前に止まって確認を取る |
| [吹き出し](message-bubble.md) | 会話のための部品。チャット画面だけで使う |
| [トースト](toast.md) | 操作の結果を短く知らせる |

### 学習ノートの部品

学習ノート（解説と問題を1画面ずつめくるアプリ）から足した部品です。

| 部品 | 一言 |
| --- | --- |
| [コースパス](course-path.md) | Part・Unit の下に章のノードを縦線でつなぐ学習経路 |
| [今ここストリップ](now-strip.md) | 今の Part・章とクリア済みの数を上に固定して見せる |
| [プレイヤートップバー](player-top-bar.md) | ✕・進捗・コンボ・XP を並べた学習プレイヤーのヘッダー |
| [単語カード](word-card.md) | 意味を隠して思い出す。復習では意味の4択になる |
| [クイズ選択肢](quiz-option.md) | 選択中・正解・不正解の状態を持つ解答の選択肢 |
| [結果バナー](result-banner.md) | 答え合わせの判定と解説。正解なら紙吹雪 |
| [模範解答ボックス](model-answer-box.md) | 記述式の答え合わせの後に、破線の枠で模範解答を見せる |
| [質問ボックス](ask-box.md) | ページ・問題ごとにその場で質問できる Q&A の欄 |
| [読み上げボタン](speak-button.md) | 英文の横の 🔊。インライン型と単独型 |
| [章完了パネル](chapter-complete-panel.md) | ★と「章名 クリア！」、次の章へ／パスに戻る |
| [本棚カバーカード](shelf-cover-card.md) | 表紙の色＋白い線のアイコン＋進捗で単発ノートを見せる |
| [コース切替パネル](course-switcher.md) | 画面の上から出てコースを切り替える |

単語→復習→講義と進むセッションの画面遷移は部品ではないため、[パターン](../patterns.md#d-時間で区切るセッションの型)に入れています。

## 部品を足すとき

1. 既存の部品で組めないかを確かめる。組めるなら足さない。
2. [テンプレート](_template.md) をコピーして、全部の見出しを埋める。状態と「使うとき／使わないとき」のない部品は登録しない（[原則3](../principles.md#3-部品には必ず状態と使い分けを付ける)）。
3. 新しい値が要るなら、先にトークンに登録する。
4. この一覧と CHANGELOG に足す（MINOR）。
