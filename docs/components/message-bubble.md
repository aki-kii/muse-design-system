# 吹き出し（Message Bubble）

## 概要

会話のための部品です。エージェントはグレーで左、本人はブルーで右に置きます。使う場所をチャット画面だけに決めることが、このシステムで最も大事な使い分けです。

吹き出しごとに操作（返信・コピー・選択・削除）が要るときは、長押しで[長押しメニュー](long-press-menu.md)を開きます。

## 使うとき

- 本人とエージェントのやり取りが時系列で流れる、チャット画面の中だけ
- 短い発言の連なり。長い報告はカードかページに載せる
- 項目に付けたメモのやり取り（例: スライドエディタの[スレッドの会話](../patterns/slide-editor/thread-conversation.md)）

## 使わないとき

- Daily Brief やレポートなどの読み物ページには使わない → ページ見出しと[セクションカード](section-card.md)で組む
- 予定表や数字の羅列を吹き出しに入れない → [リスト行](list-rows.md)と数値タイル
- やり取りの一覧には使わない → [状態付きリスト項目](status-list-item.md)

## バリアント

| バリアント | 面 | 文字 | 位置 |
| --- | --- | --- | --- |
| エージェント | `--fill` | `--text` | 左 |
| 本人 | `--bubble-user` | `--bubble-user-ink` | 右 |
| 時刻の区切り | なし | Small 段、`--faint` | 中央。まとまりが変わるところに挟む |
| メタ行付き | 上の2つと同じ | 吹き出しの中の右下に、10px の「名前 ・ 時刻」（エージェントは名前を前に付ける） | 吹き出しごとに時刻を見せるとき |

本人の吹き出しは `--accent` と同じブルーの面に白の文字です（`--bubble-user`・`--bubble-user-ink`）。吹き出しを使っている実アプリ（スライドエディタ）の見た目に合わせました（[決定記録 0003](../decisions/0003-color-and-contrast.md)）。

## 状態

ふだんは押せない部品なので、状態を持ちません。長押しメニューを付けたときだけ、次の状態を持ちます。

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | 文は選べない（長押しと文の選択がぶつからないようにする） | |
| 長押し | 見た目は変えず、[長押しメニュー](long-press-menu.md)を開く | 動かさずに 450ms 押し続けた |
| 選択中 | 文が選べるようになる | メニューの「選択」を押した |

メタ行に「下書き」を足す状態は、スライドエディタ固有の拡張として[スレッドの会話](../patterns/slide-editor/thread-conversation.md)に移しました。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 角丸 | 20px（話し手側の下の角だけ 6px） | `--radius-card` `--radius-small` |
| 最大幅 | 85% | |
| 文字 | 14px | `--text-sm` |
| 内側の余白 | 上下 8px・左右 16px | `--space-row` |
| 吹き出し同士（スレッド） | 8px | `--space-row` |
| メタ行 | 10px、右寄せ、本文との間 4px | 面に合わせて `--dim`（本人側は `--bubble-user-ink` を不透明度を下げずに使う） |

値はスライドエディタの現行に合わせています。本人側のメタ行だけは、スライドエディタの白の 75%（ブルーの面に対して 3.2:1）では 4.5:1 に届かないため、`--bubble-user-ink` をそのまま使います（[決定記録 0003](../decisions/0003-color-and-contrast.md)）。

## アクセシビリティ

- 会話の並びは `<ol>` や `role="log"` にし、新しい発言が読み上げられるようにする。
- 誰の発言かを位置と色だけで伝えない。読み上げ用に話し手の名前を持たせる（見た目では隠してよい）。
- 長押しメニューを付けるときは、キーボードでも開けるように吹き出しにフォーカスを当てられるようにする（詳しくは[長押しメニュー](long-press-menu.md)）。吹き出しの上ではブラウザの標準の長押しメニューを出さない。
