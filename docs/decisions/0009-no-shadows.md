# 0009: 影は使わず、階層は余白・整列・罫線・面の色で作る

- 状態: 決定
- 日付: 2026-11-17

## 背景

これまでは `--shadow-card`（カードの控えめな影）と `--shadow-float`（浮く部品の影）の2つを持ち、カード・タブバー・トースト・シートなどに付けていた。本人から「基本的に影を使わないで欲しい」と指示があった。原則4（装飾で目立たせず、余白と整列で階層を作る）とも、影は合っていなかった。

## 決定

1. 影（`box-shadow`）は基本使わない。 部品にもサイトの見た目にも付けない。
2. 階層と重なりは、余白・整列・罫線（`--border` の 1px）・面の色（`--bg` と `--surface` の差、幕）で作る。
   - カード: `--surface` の面に 1px の `--border` の枠。
   - 浮く部品（タブバー・トースト・メニュー・FAB）: 1px の枠を付け、地との色の差で見分ける。トーストは濃い面（`--text`）のまま。
   - 重なる部品（シート・ダイアログ）: 幕（`--scrim`）や不透明な覆い（`--bg`）で後ろと分ける。
3. `--shadow-card` と `--shadow-float` は廃止する。 v0.12.0 では値を `none` にして残し（使っている側の CSS が壊れないように）、次の MINOR 版で消す。
4. フォーカスの輪は影ではなく `outline` で描く（アクセシビリティのため常に見せる）。

## 結果

- v0.12.0 で、トークンの値を `none` にし、部品の文書の仕様表とサンプルサイトの CSS から影を外した。進捗パスの円の「下にずらした色の帯」も外した。
- 困ること: Muse DS を取り込んでいるアプリでは、影が消えて見た目が平らになる。枠がない面は地との差が小さくなるため、アプリ側で 1px の枠を足す必要がある。
