# 本棚カバーカード（Shelf Cover Card）

## 概要

単発の学習ノートを、本の表紙のように見せるカードです。表紙の色の面に白い線のアイコンを置き、下に題と進捗バーを付けます。2列のグリッドに並べて「本棚」にします。

## 使うとき

- 単発ノート（コースに属さないノート）の一覧
- 読みかけと読み終えたものを分けて並べるとき（間に ★ の区切りを入れる）

## 使わないとき

- 順番のある章の一覧 → [コースパス](course-path.md)
- コースの切り替え → [コース切替パネル](course-switcher.md)
- 文字だけで足りる一覧 → [リスト行](list-rows.md)

## バリアント

| バリアント | 見た目 | 条件 |
| --- | --- | --- |
| 読みかけ | 進捗バー（ページ位置／全ページ） | 読み終えていない |
| 読み終えた | 表紙の右上に白い ★。区切り「— ★ —」の下に並べる | 最後のページまで読んだ |

表紙のアイコンは分類（ネットワーク・データベース・コード・コンテナなど10種）で選びます。

## 状態

| 状態 | 見た目 |
| --- | --- |
| 通常 | 上の表のとおり |
| 押下 | 開いたノートへ移る |
| フォーカス | フォーカスの輪 |

## 仕様

構成:

1. 表紙（色の面＋アイコン、読み終えたら ★）
2. 題（2行まで）
3. 進捗バー

| 項目 | 値 | トークン |
| --- | --- | --- |
| グリッド | 2列、間隔 12px | |
| カードの面 | 白、1px の枠、カードの影、はみ出しは隠す | `--surface` `--border` `--shadow-card` |
| 角丸 | 20px | `--radius-card` |
| 表紙 | 高さ 82px、ノートごとの色 | 色は未定義（[判断待ちの点](../open-questions.md#学習ノート由来の部品) 13） |
| アイコン | 40×40px、白の線 2.6px、線の端は丸 | |
| 題 | 13px / 700、行間 1.45、2行で切る | `--text` |
| 内側の余白 | 8px 10px 10px | |
| 進捗バー | 高さ 6px のピル。地は罫線の色、進捗は緑 | `--border` `--ok` `--radius-pill` |
| 読み終えたの区切り | 2px の線＋ ★（15px、金色） | `--border`、金色は未定義（同 11） |

進捗バーが緑なのは、元の学習ノートで「本棚の進み具合」を「完了に向かうもの」として扱っていたためです。ブルー（`--accent`）の進捗と色を分けるかどうかも、判断待ちの点 13 に含めます。

## アクセシビリティ

- カード全体を1つの `<button>`（または `<a>`）にし、`aria-label` を「〇〇を開く」、読み終えたものは「〇〇を開く・読み終えた」にする。
- 表紙のアイコンと ★ は `aria-hidden="true"` にする。
- 進捗バーは `role="progressbar"` と値を付けるか、題のラベルに「あと n ページ」を含める。
- 表紙の色の上に置くのは白いアイコンと ★ だけで、文字は置かない（色によってはコントラストが足りないため）。
