# 長押しメニュー（Long-press Menu）

## 概要

[吹き出し](message-bubble.md)を長押ししたときに、そのすぐ下（入らなければ上）に出る小さなメニューです。返信・コピー・選択・削除の4つを、アイコンとラベルの行で並べます。削除は本人の発言にだけ出し、赤で示します。

## 使うとき

- スレッドの中の吹き出し1つに対する操作
- 操作が常に見えている必要がなく、画面を吹き出しの文だけにしておきたいとき

## 使わないとき

- 画面全体に関わる操作 → [スピードダイヤルFAB](speed-dial-fab.md)
- スレッドごと消す → [デッキヘッダー](deck-header.md)のスレッドの上端の削除と[確認ダイアログ](confirm-dialog.md)
- 長押しでしか届かない操作を作らない。メニューの操作はどれも、ほかの手段（文の選択、入力バーへの貼り付け）でもできるものに限る

## バリアント

| バリアント | 項目 | 条件 |
| --- | --- | --- |
| エージェントの発言 | 返信・コピー・選択 | |
| 本人の発言 | 返信・コピー・選択・削除 | |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 閉じている | なし | |
| 開いている | 吹き出しの下 6px（入らなければ上）に出る。画面の端から 8px 内側に収める | 動かさずに 450ms 押し続けた |
| 押下 | 項目の操作をして閉じる | |
| フォーカス | フォーカスの輪 | |

指が 10px 以上動いたらスクロールとみなし、開きません。メニューの外を押すと閉じます（開いた直後 350ms は、長押しを離した指で閉じないよう無視します）。

項目を押したときの動き:

- **返信:** 発言を「> 」付きの引用にして[メモ入力バー](memo-input-bar.md)の先頭に入れ、欄にフォーカスを移す。
- **コピー:** 本文をコピーし、[タイピングストリップ](typing-strip.md)の位置に「コピーしました」を出す。
- **選択:** その吹き出しの文を選べるようにする（ふだんは長押しと文の選択がぶつからないよう選べない）。
- **削除:** 確認なしでその発言を消す。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 幅 | 176px | |
| 面 | 白、1px の枠、浮く影、上下 4px | `--surface` `--border` `--shadow-float` |
| 角丸 | 12px | `--radius-row` |
| 項目 | 高さ 40px、左右 16px、アイコン 16px とラベルの間 8px、14px | `--text` `--text-sm` |
| 削除の項目 | アイコンと文字を赤 | `--danger` |
| 長押しの時間 | 450ms（元のアプリ。モックは 550ms） | |

項目の高さ 40px は `--size-tap-target`（44px）に届いていません（[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 23）。

## アクセシビリティ

- メニューは `role="menu"`、項目は `role="menuitem"` の `<button>` にし、`aria-label="コメントのメニュー"` を付ける。
- 長押しはキーボードや読み上げでは使えないため、吹き出しにフォーカスを当てて Shift+F10 またはコンテキストメニューのキーでも開けるようにする。開いたら最初の項目にフォーカスを移し、Esc で閉じて吹き出しに戻す。
- 吹き出しの上では、ブラウザの標準の長押しメニュー（`contextmenu`、iOS の吹き出し）を出さない。
- 削除が確認なしで消えることは、赤い色だけでなく項目の文（「削除」）で示す。
