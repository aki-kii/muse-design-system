# 色

役割で名前を付けたトークンだけを使います。ダークモードでは同じ名前のまま値だけが切り替わります。

## UI の色

| トークン | ライト | ダーク | 使う場所 |
| --- | --- | --- | --- |
| `--bg` | `#EDEEF0` | `#000000` | ページ全体の背景 |
| `--surface` | `#FFFFFF` | `#17181A` | カードの面 |
| `--fill` | `#F0F0F2` | `#232527` | 控えめな面。チップ・第2ボタン・数値タイル |
| `--text` | `#0B0D10` | `#FFFFFF` | 見出しと本文 |
| `--dim` | `#454D56` | `#C2C7CE` | 説明文・メタ情報 |
| `--faint` | `#8A8D91` | `#6E7278` | 時刻・注記 |
| `--border` | `#D2D6DC` | `#3E4248` | 罫線・区切り |
| `--accent` | `#0073E6` | `#5CA8FF` | 主操作・選択中・進捗・リンクだけ |
| `--accent-ink` | `#FFFFFF` | `#0B0D10` | `--accent` の面に載せる文字 |
| `--accent-strong` | `#0064D1` | `#8FC2FF` | ブルーの文字（ゴーストボタン、選択中の文字） |
| `--accent-soft` | `#E7F3FE` | `#12293F` | 選択中の背景・フォーカスの輪 |
| `--danger` | `#D92D20` | `#FF6B5E` | 削除・拒否・エラーだけ |
| `--ok` | `#12805C` | （同じ） | 完了・成功 |
| `--bubble-user` | `#D9EBFF` | `#0E3A5F` | 本人の吹き出しの面 |
| `--bubble-user-ink` | `#0C2D4D` | `#EAF4FF` | 本人の吹き出しの文字 |

`--bg`、`--surface`、`--text`、`--dim`、`--border`、`--accent`、`--accent-ink` は、適用済みのアプリ（jin-toreji-lu の `theme.css`）の値と一致しています。それ以外は静的ページ版 v0.3 の値をそのまま持ってきたもので、アプリにはまだ入っていません（[判断待ちの点](../open-questions.md)）。

## ブルーの使い方

- **使う:** 画面で一番大事な操作1つ、選択中の項目、進捗バー、リンク。
- **使わない:** 装飾、大きな面の塗り、重要でないボタン。「全部青い」は「何も目立たない」と同じ。

## 文字の3段

`--text`（本文）→ `--dim`（補足）→ `--faint`（時刻・注記）の3段までにします。4段目は作らず、弱めたいときはサイズも一緒に落とします。

## 中身側の色

家族カレンダーの色分けはコンテンツの色です。予定行のバーと凡例にだけ使い、ボタンや見出しには流用しません。

| トークン | 値 | 中身 |
| --- | --- | --- |
| `--cal-common` | `#F08A24` | 共通 |
| `--cal-self` | `#0E7C86` | 自分 |
| `--cal-partner` | `#E5487B` | パートナー |

## 組み合わせの決め事

文字の色は、載せる面の色と組みで選びます。下の組み合わせ以外を使うときは、[アクセシビリティ](accessibility.md#コントラスト比) の表で比を確かめます。

| 面 | 載せる文字 |
| --- | --- |
| `--bg` / `--surface` / `--fill` | `--text`、`--dim` |
| `--surface` | `--accent-strong`（リンク・ゴーストボタン）、`--danger` |
| `--accent` | `--accent-ink` だけ |
| `--accent-soft` | `--accent-strong`、`--text` |
| `--bubble-user` | `--bubble-user-ink` だけ |

## 名前の対応

静的ページ版 v0.3 と適用済みアプリで変数名が違っていたため、このリポジトリではアプリ側の名前に揃えました。

| このリポジトリ | 静的ページ版 v0.3 | jin-toreji-lu の theme.css |
| --- | --- | --- |
| `--bg` | `--bg` | `--bg` |
| `--surface` | `--surface` | `--surface` |
| `--fill` | `--fill` | （なし） |
| `--text` | `--ink` | `--text` |
| `--dim` | `--ink-2` | `--dim` |
| `--faint` | `--ink-3` | （なし） |
| `--border` | `--line` | `--border` |
| `--accent` | `--blue` | `--accent` |
| `--accent-ink` | （なし。`#fff` を直接書いていた） | `--accent-ink` |
| `--accent-strong` | `--blue-ink` | （なし） |
| `--accent-soft` | `--blue-soft` | （なし） |
| `--danger` | `--danger` | （なし） |
| `--ok` | `--ok` | （なし） |

v0.3 の `--blue-ink` は「ブルーの文字」、アプリの `--accent-ink` は「ブルーの面に載せる文字」で、似た名前で意味が違います。混同を避けるため、前者を `--accent-strong` にしました。

アプリの `--rest`（`#B45309`）は筋トレアプリの休憩表示に使う中身側の色で、DS のトークンには入れていません。
