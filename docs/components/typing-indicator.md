# 作業中インジケータ（Typing Indicator）

## 概要

エージェントが作業（返事を書く・修正する）をしている間に出す、3つの点が順に跳ねる印です。チャットの「入力中…」と同じ見た目で、「今、手が動いている」ことだけを伝えます。色付き（ブルー）とニュートラル（グレー）の2種があります。

## 使うとき

- 色付き: 一覧の中で、作業中のものを見つけやすくしたいとき（例: スライドエディタの[スレッドカード](../patterns/thread-card.md)、[依頼行](../patterns/request-row.md)、行き場のないメモ、[シートモーダル](sheet-modal.md)の削除予定の文）
- ニュートラル: 会話の中で、[入力バー](memo-input-bar.md)の上に控えめに出すとき（例: スライドエディタの[タイピングストリップ](../patterns/typing-strip.md)）

## 使わないとき

- 読み込み中・送信中など、エージェントの作業ではない待ち時間 → ボタンの無効や[アイコンボタン](icon-button.md)のアイコンの回転
- 進み具合が分かる待ち → 進捗バー
- 完了した結果を知らせる → [トースト](toast.md)

## バリアント

| バリアント | 点の色 | 用途 |
| --- | --- | --- |
| 色付き | `--accent` | 一覧の中の印 |
| ニュートラル | `--dim` | 会話の中の印 |

## 状態

| 状態 | 見た目 |
| --- | --- |
| 動いている | 3つの点が 0.18 秒ずつずれて、上に 3px 跳ねながら濃くなる（1回 1.2 秒） |
| 動きを減らす設定 | 点は止まり、不透明度 0.8 で並ぶ |

作業が終わったら印ごと消えます。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 点 | 6×6px の円、3つ、間 4px | `--radius-pill` |
| 動き | 1.2 秒で1回、上に 3px、不透明度 0.35 ↔ 1 | |
| 文の中に置くとき | 前の文と 8px 空け、縦は中央に揃える | |

## アクセシビリティ

- 印は `role="status"` にし、視覚的に隠した文（例:「エージェントが修正中」）を入れる。
- 一覧のカードの中では、カードの `aria-label` にも同じ文を含める。
- 動きは `prefers-reduced-motion: reduce` のとき止める。
