コンポーネント

部品の見本帳です。新しい画面を作るときは、まずここにある部品で組めないかを見ます。

どの部品も同じ テンプレート で書いています: 概要／使うとき／使わないとき／バリアント／状態／仕様／アクセシビリティ／関連。この部品集の中心は「使うとき／使わないとき」です。

ここに置くのは、中身に依存しない汎用の部品だけです。特定のアプリでしか使わない組み合わせはアプリ側で持ち、世の中でよくあるタスクや状態の型はパターンに置きます。どちらに置くかの基準は下の「収載の基準」にあります。

一覧#

操作と入力#

  • 続けるあとでボタン操作を始める。強さは3段＋危険のゴースト
  • アイコンボタンアイコン1つで示す補助の操作。丸と四角
  • ☀️ 14℃サンプルチップとタグチップは押せる小さな情報、タグは押せない分類ラベル
  • 店頭で受け取る自宅に届ける
    選択肢ボタン2〜4個から1つを選ぶ大きなボタンの組。判定の状態も持てる
  • 入力欄とスイッチラベル＋欄＋ヒント。スイッチは即時に効く設定だけ
  • 検索検索フィールド一覧を打った文字でその場で絞り込む。虫めがねと ✕
  • 入力バー丸い欄にマイクと送信の丸ボタン。会話の入力
  • 完了トグル・完了バッジ緑のチェックの丸。トグルは付け外し、バッジは印
  • ナビゲーション広い画面はサイドバー、狭い画面はタブバー

内容を並べる#

  • 📅
    セクションカード読み物ページの基本単位。1カード＝1つの話題
  • リスト行予定行・タスク行・数値タイル＋メーターの3種
  • 状態付きリスト項目1件ずつ「誰の番か・作業中か」の状態を持つ一覧の項目
  • メディアカードサムネイル＋タイトル＋メタ情報の押せるカード
  • 進捗パス順番のある段階をノードと線でつなぎ、現在地を見せる
  • キャッシュ
    タップして答えを見る
    フラッシュカード表で問い、裏を開いて自己判定する
  • おはようありがとう
    吹き出し会話のための部品。チャット画面だけで使う
  • まだありません
    空の状態中身がないときに、理由と次の一手を中身の場所に出す

重ねて出す・知らせる#

  • 承認カード外部に触る操作の前に止まって確認を取る
  • ボトムシート下からせり上がる板に1つの作業だけを入れる
  • 確認ダイアログ取り消せない削除の前に中央で聞く
    • 返信
    • コピー
    • 削除
    長押しメニュー項目の長押しで、その項目への操作を出す
  • ＋2スピードダイヤルFAB右下の ＋ から作る系の操作を開く。件数バッジ
  • コピーしましたトースト操作の結果を短く知らせる
  • 作業中インジケータ3つの点が跳ねる。色付きとニュートラル
  • スケルトン読み込み中に、中身の形だけを先に灰色の面で見せる

収載の基準#

GOV.UK Design System の収載基準と、Carbon の Core と拡張の分け方にならい、次のように決めています。詳しくは決定記録 0002と決定記録 0008。

  1. 中身に依存しないものだけをここに置く。部品の名前・バリアント・状態・文に、特定のアプリの言葉（デッキ・章・スレッドなど）を使わない。
  2. 例と見本の中身は、架空の汎用的な内容にする。特定のアプリの画面や文言に寄せない。
  3. 特定のアプリでしか使わない組み合わせは、DS に置かずアプリ側で持つ。
  4. 2つ目のアプリで同じ形が要ると分かったら、アプリの言葉を外して部品にできるかを検討する。外せたものだけを部品にする。

部品を足すとき#

  1. 既存の部品で組めないかを確かめる。組めるなら足さない。
  2. 上の「収載の基準」に当てはめる。アプリ固有なら DS に足さず、アプリ側で持つ。
  3. テンプレート をコピーして、全部の見出しを埋める。状態と「使うとき／使わないとき」のない部品は登録しない（原則3）。
  4. 新しい値が要るなら、先にトークンに登録する。
  5. この一覧と CHANGELOG に足す（MINOR）。
