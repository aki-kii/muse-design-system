# パターン

世の中の多くの製品に出てくるタスクや状態の型を、Muse DS の部品でどう組むかを書いたものです。どれも Muse のアプリで実際に使っている型だけを載せています。

| パターン | 一言 |
| --- | --- |
| [読み込み・空・失敗の状態](patterns/loading-states.md) | データを読み込む場所ごとに、読み込み中・0件・読み込めなかったを出し分ける |
| [失敗からのやり直し](patterns/error-recovery.md) | 操作が失敗しても入力を残し、理由と「もう一度」をその場に出す |
| [検索と絞り込み](patterns/search-and-filter.md) | 一覧の上で、ことばで探す・分類で減らす。0件なら条件を外す |
| [一覧から詳細へ](patterns/list-to-detail.md) | 1件を押して詳細を開き、戻ると一覧の同じ場所に帰る |
| [確認をはさむ操作](patterns/approval-flow.md) | 取り消せない操作・外部に触る操作の直前に確認をはさみ、結果をその場に残す |
