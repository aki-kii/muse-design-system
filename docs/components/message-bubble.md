# 吹き出し（Message Bubble）

## 概要

会話のための部品です。エージェントはグレーで左、本人はライトブルーで右に置きます。使う場所をチャット画面だけに決めることが、このシステムで最も大事な使い分けです。

## 使うとき

- 本人とエージェントのやり取りが時系列で流れる、チャット画面の中だけ
- 短い発言の連なり。長い報告はカードかページに載せる

## 使わないとき

- Daily Brief やレポートなどの読み物ページには使わない → ページ見出しと[セクションカード](section-card.md)で組む
- 予定表や数字の羅列を吹き出しに入れない → [リスト行](list-rows.md)と数値タイル

## バリアント

| バリアント | 面 | 文字 | 位置 |
| --- | --- | --- | --- |
| エージェント | `--fill` | `--text` | 左 |
| 本人 | `--bubble-user` | `--bubble-user-ink` | 右 |
| 時刻の区切り | なし | Small 段、`--faint` | 中央。まとまりが変わるところに挟む |

## 状態

押せない部品なので、状態を持ちません。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 角丸 | 20px（話し手側の下の角だけ 6px） | `--radius-card` `--radius-small` |
| 最大幅 | 84% | |
| 文字 | 15px | |
| 内側の余白 | 上下 12px・左右 16px | |

## アクセシビリティ

- 会話の並びは `<ol>` や `role="log"` にし、新しい発言が読み上げられるようにする。
- 誰の発言かを位置と色だけで伝えない。読み上げ用に話し手の名前を持たせる（見た目では隠してよい）。
