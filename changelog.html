Changelog

この文書には Muse DS の変更を版ごとに記録します。書き方は Keep a Changelog、版の付け方は Semantic Versioning に従います。詳しくは docs/versioning.md。

[Unreleased]#

[0.10.0] - 2026-11-17#

Changed#

  • 壊れる変更: パターンの一覧から A〜E の型の分類と「アプリ固有の複合体」の節を外し、全パターンを1つの平らな一覧にした（コンポーネント一覧と同じ体裁）。型の4件は1件ずつの文書（読み物ページの型・承認をはさむ型・状態を見せる型・時間で区切るセッションの型）にした。patterns.html#a-… などの節へのリンクはなくなる。
  • パターンの定義（基本コンポーネントを組み合わせて、よくあるパターンにしたもの）を原則に置いた。パターンの一覧には一覧だけを置く。一覧にあった「横断の約束」はファウンデーションの繰り返しなので外した。

Removed#

  • 壊れる変更: スライドエディタのパターンを Muse DS から外した。スライド用は別の独立したデザインシステムで扱う。外したのはスライドの型（E）と、デッキヘッダー・スライドステージ・ページカウンタ行・スレッドカード・タイピングストリップ・依頼行・ページプレビューカード・スレッドの会話の 8件。コンポーネントの文書からの参照とサイトのデモも外した。URL（patterns/<名前>.html）はなくなる。転送のページは作らない。パターンは 12件になった。

[0.9.1] - 2026-11-17#

Changed#

  • 1つの部品のバリアントにすぎないパターン 8件を、パターンの一覧から外して部品のバリアントにした。形式（寸法・状態・文・アクセシビリティ）はコンポーネントの文書に移した。パターンは 16件になった。
  • 読み上げボタン → アイコンボタンの「読み上げ」
  • クイズ選択肢 → 選択肢ボタンの「クイズ」、位置ラジオ → 同じく「位置」
  • 確認待ちバッジ → 状態付きリスト項目の確認待ちの印
  • 送信完了メッセージ → トーストの「件数」
  • デッキカード → メディアカードの「デッキ」、本棚カバーカード → 同じく「本棚」
  • コースパス → 進捗パスの「コース」
  • 「1つの部品のバリアントにすぎないものはパターンにしない」を ADR 0002 と収載の基準に足した。
  • サイトのデモも部品のページに移した。外したパターンの URL（patterns/<名前>.html）はなくなる。転送のページは作らない。

[0.9.0] - 2026-11-17#

Changed#

  • 壊れる変更: パターンの複合体 24件をアプリ別のフォルダ（docs/patterns/learning-note/・docs/patterns/slide-editor/）から docs/patterns/ 直下に移し、1つの一覧にした。索引は パターン の表1つにまとめ、アプリ別の一覧（各フォルダの README）は外した。サイトの URL も patterns/<アプリ>/<名前>.html から patterns/<名前>.html に変わる。転送のページは作らない。
  • 各複合体の冒頭の1行を「出自: どのアプリで使っているか」にした。
  • コンポーネント・ファウンデーション・README・ADR 0002 から複合体へのリンクと置き場所の説明を新しい場所に合わせた。

[0.8.2] - 2026-11-17#

Removed#

  • v0.6.0 でパターンに移した部品 23件の案内の文書（docs/components/<名前>.md の「（移動しました）」）と、コンポーネント一覧の「移した部品」の節を外した。サイトでも元の URL（components/<名前>.html）から移行先への転送のページを作らなくなった。移した部品と移行先は [0.6.0] とこの記録、ADR 0002 に残っている。

[0.8.1] - 2026-11-17#

Removed#

  • 「判断待ちの点」の文書（docs/open-questions.md）とサイトのページ・リンクを外した。判断待ちが残っていないため。28件の決定は ADR 0003〜0006 に記録済みで、決める基準5つも 0003 の背景にある。

Changed#

  • 決定記録の書き方を「決めたことだけを、判断の粒度で書く」にした。0001・0003〜0006 の判断待ちの一覧へのリンクを外し、一覧の番号が v0.6.0 時点のものだと注記した。
  • 1.0.0 にする目安の「判断待ちの点がすべて決まっている」を「決めきれていない判断が残っていない」にした。

[0.8.0] - 2026-11-17#

ほかのデザインシステム（Carbon、Polaris、Primer、Material Design）から、Muse のアプリで使い道のある部品を3つもらった版。もらったのは部品の考え方と構成だけで、見た目は Muse DS のトークンで作った。あわせて、サンプルサイトのヘッダーの操作をアイコンボタンにし、docs/ と README の文章を yomiyasu で推敲した。

Added#

  • 部品「スケルトン」（読み込み中に中身の形を先に見せる。参考元: Carbon の Skeleton states、Polaris の Skeleton、Primer の SkeletonBox）。学習ノート・筋トレ記録・AWS アップデートが「読み込み中…」の文だけを出している場所の置き換え先。
  • 部品「空の状態」（まだない・見つからない・読み込めなかったの3つと小。参考元: Polaris の Empty state、Primer の Blankslate、Carbon の Empty states）。スライドエディタの「まだありません」、筋トレ記録の「読み込めなかった」などの置き換え先。
  • 部品「検索フィールド」（虫めがね＋欄＋消す ✕、打つたびに絞り込む。参考元: Carbon の Search、Material Design 3 の Search、Primer の TextInput）。AWS アップデートの絵文字の検索が実例。
  • サイトとデモのアイコンに Lucide の sun・moon・monitor・menu・search・inbox・circle-alert の形を足した。

Changed#

  • サンプルサイトのヘッダーの「表示モード」と「目次」を、文字のボタンから線のアイコンのボタン（36px の丸）に変えた。表示モードは自動・ライト・ダークでモニター・太陽・月のアイコンに切り替わり、目次は開くと ✕ になる。どちらも aria-label と title（ツールチップ）で、今の状態と押したあとに起きることを伝える。
  • docs/ と README の日本語の文章を、日本語推敲スキル yomiyasu で推敲した。意味・事実・数値・固有名詞・コード・トークン名・見出しは変えていない。

[0.7.0] - 2026-11-17#

判断待ちの点（28件）をすべて解消した版。実アプリの現行値を正とし、コントラストは WCAG 2.2 AA を満たす側に倒した（ADR 0003〜0006）。

Added#

  • 色のトークン8件: --ok-ink・--ok-soft・--danger-ink・--danger-soft・--gold・--gold-ink・--scrim・--scrim-strong（と、それぞれのダークの値）。どれも学習ノート・スライドエディタ・筋トレ記録・AWS アップデートのどれかが実際に使っている値。
  • 文字サイズ --text-2xs（11px／14px）と、タイポの段「Micro」。
  • ボタンの「確認」バリアント（--ok の面。答え合わせ用）。
  • ファウンデーション「アイコン」（Lucide の形の線のアイコン）。
  • 決定記録 0003（色とコントラスト）、0004（スケールと部品だけの寸法）、0005（状態の見せ方とボタンの例外）、0006（アイコンの組）。
  • 色の文書に「赤の使い方」「緑と金色の使い方」「控えめな面の置き場所」と、学習ノート・スライドエディタとの名前の対応。アクセシビリティの文書に「状態の見せ方」「タップ範囲」。

Changed#

  • --faint を #656A72／ダーク #8E939A に濃くした（4.5:1 以上）。
  • --ok のダークを #3ECF8E にした（以前はライトと同じ値）。
  • --bubble-user・--bubble-user-ink を、スライドエディタに合わせて --accent のブルーの面に白（ダークは #5CA8FF に #0B0D10）にした。吹き出しの本文 14px、内側 8px 16px、最大幅 85%。
  • --space-card-gap を 14px → 12px、--space-card-padding を 18px → 16px にした（余白は4の倍数）。
  • フォーカスの輪を --accent-soft の 3px から --accent の 2px（2px 離す）に変えた。サイトとデモも同じ。
  • タイポの段をスケールの値（Display 30・36px、Heading 18・20・24px、Body 16px／24px、Small 12・14px）で書き直した。
  • 数値タイルの角丸を 14px → 12px にした。
  • 完了は行全体の不透明度を使わず、--faint＋打ち消し線＋印で示す。無効の不透明度を 0.4 にそろえた。
  • 選択肢の正解・不正解に ✓ ✗ の印を付けた。
  • 長押しメニューの項目とページカウンタ行のリンクの押せる範囲を 44px にした。
  • 確認ダイアログの後ろは幕ではなく --bg で覆う。シートの幕は --scrim／--scrim-strong。
  • ページプレビューカードの枠を黒から --surface の面に、スライドステージの地を --bg 連動にした（スライドエディタの現行）。
  • --danger の用途に「録音中」「未送信の件数」を足した。
  • 判断待ちの点の文書を、各項目の決定と基準・決定記録を書いた「解消済み」の一覧にした。部品・パターンの文書とサイトのデモから「未定義」「判断待ち」の記述を外し、決めた値に置き換えた。デモのコースの色は白の文字に対して 4.5:1 以上の例に変えた。

Removed#

  • 使わなくなった primitive の neutral.500（#8A8D91）・neutral.600（#6E7278）と、余白の space.14・space.18。サイトのデモ用の仮の値（--demo-gold・--demo-ok-soft・--demo-danger-soft・--demo-on-color・--demo-scrim-*・--demo-slide-ground）。

[0.6.0] - 2026-11-17#

部品を抽象度で整理した版。コンポーネントには中身に依存しない汎用の部品だけを残し、アプリ固有の複合体をパターンに移した（ADR 0002）。

Added#

  • 汎用の部品6件: フラッシュカード（単語カードの核）、進捗パス（コースパスの核）、メディアカード（デッキカード・本棚カバーカードの核）、状態付きリスト項目（スレッドカード・依頼行の核）、アイコンボタン（デッキヘッダーの丸ボタン・読み上げボタンの核）、選択肢ボタン（クイズ選択肢・位置ラジオの核）。サイトにデモと一覧の見本も足した。
  • docs/patterns/learning-note/ と docs/patterns/slide-editor/。複合体ごとに「組み合わせ」の節で、使っている汎用の部品を書いた。
  • スライドエディタの複合体「スレッドの会話」（吹き出しのメタ行・下書き・長押しの組み合わせ）。
  • 決定記録 0002「コンポーネントには汎用の部品だけを置き、アプリ固有の複合体はパターンに置く」。コンポーネントの README に「収載の基準」（2つ目のアプリで使われたら昇格を検討し、汎用にできるものだけを部品にする）を書いた。
  • README にサンプルサイトの URL と、scripts/build-site.mjs・scripts/publish-site.sh・site/ の説明。

Changed#

  • 壊れる変更（0.x のため MINOR）: 学習ノートの12件（コースパス、今ここストリップ、プレイヤートップバー、単語カード、クイズ選択肢、結果バナー、模範解答ボックス、質問ボックス、読み上げボタン、章完了パネル、本棚カバーカード、コース切替パネル）と、スライドエディタの11件（デッキカード、デッキヘッダー、スライドステージ、ページカウンタ行、スレッドカード、確認待ちバッジ、タイピングストリップ、依頼行、ページプレビューカード、位置ラジオ、送信完了メッセージ）を、コンポーネントからパターンに移した。元の docs/components/<名前>.md は移行先への案内に置き換え、サイトの components/<名前>.html は移行先へ転送する。
  • スライドエディタ由来のうち中身に依存しない7件は、アプリの言葉を外してコンポーネントに残した。名前を3件変えた: 修正中インジケータ → 作業中インジケータ、メモ入力バー → 入力バー、完了トグル・解決済みバッジ → 完了トグル・完了バッジ（ファイル名は同じ）。
  • 吹き出しから、スライドエディタ固有の「下書き」の状態とモックの値の違いを「スレッドの会話」に移した。メタ行と長押しの状態は汎用として残した。
  • コンポーネントの一覧を「操作と入力」「内容を並べる」「重ねて出す・知らせる」に分け直した。サイトのナビゲーションも同じ分け方にし、パターンの下にアプリごとの複合体を並べた。
  • デモとサンプルの文から、実在のイベント名・発表題・人名とエージェントの固有名を外し、架空の内容と「アシスタント」「ユーザー」に置き換えた。
  • README の取り込みの説明を、リポジトリが public であることに合わせた。今後の課題の CI の説明を、今のサイトの組み立てに合わせた。

Removed#

  • 適用例 Daily Brief（docs/examples/daily-brief.md、サイトの examples/daily-brief.html、site/demos/daily-brief.html）と、README・パターン・サイトのトップからのリンク。部品のデモ（セクションカード・リスト行など）は残した。

[0.3.0] - 2026-11-17#

静的ページのドキュメントとして作った v0.3 を、このリポジトリに移した最初の版。

Added#

  • 4層のドキュメント構成（原則／ファウンデーション／コンポーネント／パターン）を Markdown に移した。
  • tokens/tokens.json: Design Tokens 形式で、primitive（値）と semantic（役割）の2層に分けた。ダークモードの値も持つ。
  • tokens/tokens.css: tokens.json から生成する CSS 変数。data-theme でライト／ダークを固定できる。
  • scripts/build-tokens.mjs: tokens.css の生成と一致確認。
  • 部品ドキュメントのテンプレート（概要／使うとき／使わないとき／バリアント／状態／仕様／アクセシビリティ）と、9部品の文書。
  • ファウンデーションに、トークンの階層、Tailwind との対応、アクセシビリティの基準とコントラスト比の表を足した。
  • 決定記録（docs/decisions/）と判断待ちの一覧（docs/open-questions.md）。

Changed#

  • 色の値を、Muse DS を適用済みのアプリ（jin-toreji-lu）の実値に合わせた。静的ページ版 v0.3 の値との違いは ADR 0001 に記録した。
  • CSS 変数の名前を、適用済みアプリの名前（--text、--dim、--border、--accent）に揃えた。v0.3 の名前との対応は foundations/color.md にある。
