メディアカード（Media Card）

サムネイル＋タイトル＋メタ情報の押せるカード

デモ

大（サムネイル＋タイトル＋件数・日付）

小（表紙＋タイトル＋進捗バー）

中身は架空です。サムネイルや表紙の色は中身側の色で、DS のトークンでは塗りません。

本棚（学習ノート）

★

読みかけ2冊と、区切りの下に読み終えた2冊を並べています。表紙の色は中身側の色の例、区切りの ★ は --gold の飾りです。

概要#

上にサムネイル、下にタイトルとメタ情報（件数・日付・進み具合など）を置いた、押せるカードです。見た目で思い出せるものを一覧で選ばせるときに使います。カード全体が1つのリンク（またはボタン）です。

使うとき#

  • 表紙や見た目が選ぶ手がかりになるものの一覧（資料、ノート、アルバムなど）
  • 1件ごとに開く先がある一覧

使わないとき#

  • 文字だけで足りる一覧 → リスト行
  • 状態（確認待ち・作業中など）を見せたい一覧 → 状態付きリスト項目
  • 読み物ページの話題の単位 → セクションカード
  • 順番のある段階 → 進捗パス

バリアント#

バリアントサムネイルメタ情報並べ方
大横長（中身の比、例: 980:552）。下に 1px の罫線タイトル＋件数・日付を横に1列、間 24px
小（表紙）色の面＋白い線のアイコン（高さ 76px 前後）タイトル＋進捗バー2列のグリッド、間 12px

サムネイルがないときは、--fill の面にタイトルを --dim で出します（「サムネイルなし」の状態）。

デッキ（大。スライドエディタ）#

デッキ（1回の登壇分のスライドの束）の一覧の最初の画面です。サムネイルは1枚目のスライドをそのまま縮小して描き（寸法はサムネイルの幅に対する割合、色はデッキ側の色）、メタ情報は「18枚」「11月15日」のように単位付きで出します。外側の余白は 24px 16px、タイトルとメタ情報の間は 8px。押すとそのデッキのエディタを開きます。

本棚（小（表紙）。学習ノート）#

コースに属さない単発ノートの一覧です。

項目値トークン
表紙高さ 82px、ノートごとの色（ノートのデータが持つ値）DS のトークンにしない
表紙のアイコン40×40px、白の線 2.6px、線の端は丸。分類（ネットワーク・データベース・コード・コンテナなど10種）で選ぶ
題13px / 700、行間 1.45、2行で切る--text
内側の余白8px 10px 10px
進捗バーページ位置／全ページ。進捗は緑（読み終えるまでの進み。今の操作の進みのブルーと分ける）--border --ok
読み終えた表紙の右上に白い ★。区切り「— ★ —」（2px の線＋15px の金色の ★）の下にまとめる--border --gold

表紙の色の上には白いアイコンと ★ だけを置き、文字は置きません（色によってはコントラストが足りないため）。

状態#

状態見た目条件
通常--surface の面、1px の枠、カードの影
押下0.98 倍に縮む押している間
サムネイルなし上の文のとおり表紙がまだない
フォーカスフォーカスの輪（カード全体）キーボードで選ばれたとき

仕様#

構成は次のとおりです。

  1. サムネイル（飾り）
  2. タイトル（2行まで）
  3. メタ情報（Small 段の --dim。進捗はメーター）
項目値トークン
面白、1px の枠、カードの影--surface --border --shadow-card
角丸20px（中のサムネイルは角丸の内側で切る）--radius-card
メタの領域の余白16px（小は 10px 12px）
タイトル14px / 600、行間 1.7--text
メタ情報12px、項目の間 16px--dim
進捗バー高さ 6px のピル--border --accent

サムネイルの中の色（表紙・スライドの色）は中身側の色で、DS のトークンでは塗りません（色）。

アクセシビリティ#

  • 一覧は <ul>、1枚は <a>（開く先がページなら）か <button> にする。
  • サムネイルは aria-hidden="true" にし、名前はタイトルの文で伝える。カードの aria-label にはタイトルとメタ情報を入れる。
  • 進捗バーを出すときは、割合を aria-label かメタ情報の文に含める（例:「〇〇を開く・あと n ページ」「〇〇を開く・読み終えた」）。表紙のアイコンと ★ は aria-hidden="true"。
