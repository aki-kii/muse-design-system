完了トグル・完了バッジ（Done Toggle / Done Badge）

緑のチェックの丸。トグルは付け外し、バッジは印

デモ

トグル（押すと切り替わる） トグル（オン） 解決済みバッジ

オンの面は --ok、チェックは --ok-ink です（ダークでは黒）。

概要#

項目を「完了（解決済み）」にする丸いトグルと、完了を示す丸い印です。どちらもチェックのアイコンで、オンのときは緑（--ok）の円になります。トグルは押してオン・オフを切り替え、バッジは押せない印です。

使うとき#

  • トグル: 依頼ややり取りのように、相手がいる項目の完了を本人が付け外しするとき。状態付きリスト項目の右端や、項目を開いた先の上端に置く
  • バッジ: 完了した状態付きリスト項目の先頭の印

使わないとき#

  • やることの一覧のチェック → リスト行のタスク行
  • 即時に効く設定 → スイッチ
  • エージェントが作業中のものには出さない（同じ大きさの空きを置いて位置を保つ）

バリアント#

バリアント見た目用途
トグル32px の円。オフは --fill の面に緑のチェック、オンは緑の面に白いチェック完了の付け外し
完了バッジ32px の緑の円に白いチェック。押せない完了した項目の先頭の印

状態#

状態見た目対象
オフ--fill の面、1px の --border の枠、チェックは --okトグル
オン--ok の面と枠、チェックは --ok-inkトグル
押下0.9 倍に縮む（0.1 秒）トグル
フォーカス--accent の 2px の輪トグル

仕様#

項目値トークン
大きさ見た目 32×32px の円。押せる範囲は外側に 6px 広げて 44px--radius-pill --size-tap-target
チェック16px、線 2.6px--ok、オンは --ok-ink
オンの面緑--ok

緑の面に載せる白は --ok-ink です（ダークでは黒。白だと 2.0:1 で届かないため）。

「完了」の色は意味で使い分けます。この部品の --ok（緑）は「相手とのやりとりが片付いた（解決済み・依頼が済んだ）」を示し、リスト行のタスク行のように「本人が自分で付ける完了」は --accent（ブルー）です（決定記録 0005）。

アクセシビリティ#

  • トグルは <button aria-pressed> にし、aria-label は押したあとに起きることにする（「解決済みにする」／「未解決に戻す」、依頼は「完了にする」／「未完了に戻す」）。
  • バッジは aria-hidden="true" にし、解決済みであることはカードの aria-label で伝える。
  • 完了は色だけでなく、題の打ち消し線でも示す。
