# 送信完了メッセージ（Submit Message）

**アプリ固有の複合体。** スライドエディタでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

「修正依頼」を出したあと、[スピードダイヤルFAB](../../components/speed-dial-fab.md)のすぐ上に出る短い通知です。何をいくつ出したかを件数で書きます（「修正依頼を出しました（メモ2件・ページ依頼1件）」）。約 4 秒で消えます。

## 組み合わせ

- [トースト](../../components/toast.md)の文と形を、画面下の中央ではなく[スピードダイヤルFAB](../../components/speed-dial-fab.md)のすぐ上に出したもの

## 使うとき

- FAB から下書きをまとめて出した直後
- 何件出たかを確かめたい、まとめての送信の結果

## 使わないとき

- 1回の操作の短い結果（コピー・保存など） → [トースト](../../components/toast.md)
- エラー → その場の文（[メモ入力バー](../../components/memo-input-bar.md)のエラーなど）
- 会話の中の結果 → [タイピングストリップ](typing-strip.md)の短い文

## バリアント

なし（1種類だけ）。

## 状態

| 状態 | 見た目 |
| --- | --- |
| 表示中 | FAB の主ボタンと項目の上に浮く |
| 消えた | 約 4 秒で消える。次の送信で出し直すと時間を数え直す |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 位置 | FAB の列の一番上（右寄せ）、FAB と 8px | |
| 面 | 白、1px の枠、浮く影 | `--surface` `--border` `--shadow-float` |
| 角丸 | 20px | `--radius-card` |
| 内側の余白 | 上下 8px・左右 16px | |
| 最大幅 | 画面の幅の 70% | |
| 文字 | 12px | `--accent-strong` `--text-xs` |
| 表示時間 | 約 4 秒 | |

[トースト](../../components/toast.md)（下部中央・ピル・約 2.2 秒）と違い、件数を読む時間を取るため長めに出し、送った元の FAB の近くに置きます。

## アクセシビリティ

- `role="status"`（`aria-live="polite"`）で読み上げる。フォーカスは移さない。
- 件数は「メモ2件・ページ依頼1件」のように単位付きの文で書く。
- 消えるので、操作に必要な情報やボタンを入れない。
