# 答え合わせの型（Answer Check）

**出自:** 学習ノート（学習プレイヤーの問題、復習の問題の2か所）。別のアプリで要るときは、まず下の「組み合わせ」の汎用部品で組みます（[昇格のルール](../decisions/0002-component-admission.md)）。

## 概要

問題に答えてから「答え合わせ」を押し、判定と解説をその場に出す流れです。答える欄・判定の帯・模範解答・解説への入口を、問題のカードの中で1つの状態として連動させます。答え合わせの後は答えを変えられず、開き直しても同じ判定が出ます。

## 組み合わせ

- 答える欄: [選択肢ボタン](../components/choice-button.md)のクイズ（選択式）、または[入力欄](../components/input-and-switch.md)の複数行（記述式）
- 「答え合わせ」の[ボタン](../components/button.md)のプライマリ（画面下の操作の行）
- 結果バナー: 正解・不正解の薄い面の帯。判定の文と解説を持つ（汎用の部品にはしていない。使っているアプリが1つだけのため）
- 模範解答の枠: 破線の `--accent` の枠と見出し＋[アイコンボタン](../components/icon-button.md)の読み上げ（記述式だけ）
- 「解説を見返す」「章の解説全体」: [ボタン](../components/button.md)のセカンダリとゴースト（惜しいときだけ）
- 問題のカードの末尾に[質問ボックス](ask-box.md)（答え合わせの前でも後でも出す）

## 流れ

| 段階 | 見た目 | 次へ進む条件 |
| --- | --- | --- |
| 答える前 | 選択肢か入力欄。「答え合わせ」は無効 | 選択肢を選んだ、または入力欄に文字がある |
| 答えた | 「答え合わせ」が押せる。選択式は押した選択肢を選択中にするだけで、正誤は出さない | 「答え合わせ」を押した |
| 採点中（記述式） | 「答え合わせ」を押せなくする | 判定が届いた。届かなければ入力の下に `--danger` の文を `role="alert"` で出し、「答えた」に戻す |
| 判定後 | 答える欄を押せなくし、選択式は[選択肢ボタン](../components/choice-button.md)の正解・不正解の状態で示す。記述式は入力欄の下に模範解答の枠を出す。その下に結果バナー | 次のページへ進む |
| 保存済み | 前に答えた問題を開き直したとき、判定後と同じ見た目を動きなしで出す | |

惜しいときに関係する解説ページがあれば、結果バナーの中に「解説を見返す」「章の解説全体」を置き、押すとその場で解説を広げます（画面を移らない）。

## 使うとき

- 選択式・記述式の問題の答え合わせ（学習プレイヤー、復習）

## 使わないとき

- 操作の結果を短く知らせるだけ → [トースト](../components/toast.md)
- 採点できなかったなどのエラー → 本文の中に `--danger` の文で出す（結果バナーにしない）
- 単語の意味を問うとき（カードの中の1行の文で足りる）→ [単語カード](word-card.md)
- 答え合わせの前に模範解答や判定を出さない

## バリアント

| バリアント | 見た目 | 文 |
| --- | --- | --- |
| 正解 | 薄い緑の面、判定の文は `--ok`、紙吹雪あり | 「正解！その調子だよ」＋解説 |
| 惜しい | 薄い赤の面、判定の文は `--danger`、紙吹雪なし | 「惜しい！ここがポイントだよ」＋解説＋解説への入口 |
| 記述式 | 上のどちらかに、入力欄の下の模範解答の枠を足す | 見出し「模範解答」＋模範解答の文（括弧内の注記は除く） |

## 状態

| 状態 | 見た目 |
| --- | --- |
| バナーが出たとき | 0.35 秒で拡大しながら出る。正解なら紙吹雪が 1.1 秒で落ちる |
| 表示中 | 次のページへ進むまで残る（[トースト](../components/toast.md)と違い消えない） |
| 保存済み | 動きなしで同じ判定を出す |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| バナーの面 | 正解は薄い緑、惜しいは薄い赤 | `--ok-soft` `--danger-soft` |
| バナーの角丸 | 12px | `--radius-row` |
| バナーの内側の余白 | 16px | |
| 問題とバナーの間隔 | 20px | |
| 判定の文 | 22px / 800（大きい文字なので 3:1 で足りる。薄い面の上で 4.2:1） | `--ok` または `--danger` |
| 解説 | 本文、行間 1.65 | `--text` |
| 紙吹雪 | 8×12px の小片 18個、角丸 2px。色は `#EC4561`・`#2F7CF6`・`#F5B301`・`#2E9E5B` の4色を順に | 飾りの色で、DS のトークンにしない（学習ノートの現行の値） |
| 模範解答の枠 | 白の面、破線 2px、角丸 12px、内側の余白 16px、入力欄との間隔 12px | `--surface` `--accent` `--radius-row` |
| 模範解答の見出し | 14px / 800 | `--accent-strong` |
| 模範解答の文 | 本文、行間 1.65 | `--text` |

## アクセシビリティ

- 結果バナーに `role="status"` を付け、判定と解説が読み上げで伝わるようにする。フォーカスは移さない。
- 判定は色だけでなく文で示す（判定の文を省かない）。
- 紙吹雪は `aria-hidden="true"` の飾りにし、押す操作を邪魔しない（`pointer-events: none`）。
- 拡大の動きと紙吹雪は `prefers-reduced-motion: reduce` のとき止める。
- 模範解答の枠には `aria-label="模範解答"` を付け、英文には `lang="en"` を付ける。破線は飾りとして扱い、「模範解答」の文で中身を示す。
