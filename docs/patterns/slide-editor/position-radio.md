# 位置ラジオ（Position Radio）

**アプリ固有の複合体。** スライドエディタでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

「このページの前に追加」「このページの後に追加」の2つから1つを選ぶ、横並びの大きなボタンの組です。選ばれた方はブルーの面になります。

## 組み合わせ

- [選択肢ボタン](../../components/choice-button.md)の横並び（2択）

## 使うとき

- [シートモーダル](../../components/sheet-modal.md)の「ページを追加」で、[ページプレビューカード](page-preview-card.md)の下に置く
- 2択（多くても3択）で、どちらも文で書けるもの

## 使わないとき

- オン・オフ → [スイッチ](../../components/input-and-switch.md)
- 選ぶとすぐ画面が切り替わる → タブ（[ナビゲーション](../../components/navigation.md)）
- 選択肢が4つ以上 → 一覧から選ぶ形にする

## バリアント

なし（1種類だけ）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 選ばれていない | `--fill` の面、1px の `--border` の枠、14px | |
| 選ばれている | `--accent` の面と枠、文字は 600 | 押した方。開いたときは「後」 |
| フォーカス | フォーカスの輪 | |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 並べ方 | 横に同じ幅で、間 8px、上に 16px | |
| 高さ | 44px | `--size-tap-target` |
| 角丸 | 12px | `--radius-row` |
| 文字 | 14px、左右 8px | `--text` `--text-sm` |
| 選ばれているときの文字 | 600 | `--accent-ink` |

## アクセシビリティ

- 組は `role="radiogroup"` と `aria-label="追加する位置"`、各ボタンは `role="radio"` と `aria-checked` にする。← → で選びを動かせるようにする（フォーカスは選ばれている方だけに置く）。
- 選ばれたことは面の色だけでなく、太さ（600）と `aria-checked` でも伝える。
