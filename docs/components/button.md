# ボタン（Button）

## 概要

操作を始めるための部品です。強さは3段（プライマリ・セカンダリ・ゴースト）と、危険操作用のゴースト、答え合わせ用の確認ボタンがあります。強さは重要度で選び、見た目の好みで選びません。

## 使うとき

- プライマリは「この画面で一番進めたい操作」に1つだけ
- セカンダリはプライマリの相方（あとで・キャンセルなど）
- ゴーストは補助的な遷移（詳しく見るなど）

## 使わないとき

- プライマリを2つ並べない（順位が消える）
- 単なる情報表示にボタンを使わない → [チップかタグ](chip-and-tag.md)
- 危険操作をプライマリにしない → 危険のゴースト＋[承認をはさむ型](../patterns.md#b-承認をはさむ型)

## バリアント

| バリアント | 面 | 文字 | 用途 | 例 |
| --- | --- | --- | --- | --- |
| プライマリ | `--accent` | `--accent-ink` | 一番進めたい操作 | 続ける |
| セカンダリ | `--fill` | `--text` | プライマリの相方 | あとで |
| ゴースト | なし | `--accent-strong` | 補助的な遷移 | 詳しく見る |
| 危険のゴースト | なし | `--danger` | 削除・拒否 | 削除 |
| 確認 | `--ok` | `--ok-ink` | 答えを確かめる・採点する操作だけ | 答え合わせ |

- セカンダリの `--fill` の面は、カードやシートの中（`--surface` の上）で使う。`--bg` の上に直接置くときは、面を `--surface` にして `--border` の 1px の枠を付ける（`--fill` と `--bg` はほぼ同じ明るさのため。[決定記録 0003](../decisions/0003-color-and-contrast.md)）。
- 確認は学習ノートの「答え合わせ」の現行の形で、プライマリの代わりに使う。1画面に1つだけにする。
- シートやダイアログの下に並ぶ確定ボタン（全幅・角丸 12px）と、確認ダイアログの赤い面の「削除する」は、フォームの一部としての例外です。[シートモーダル](sheet-modal.md)・[確認ダイアログ](confirm-dialog.md)を見てください（[決定記録 0005](../decisions/0005-states-and-exceptions.md)）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | 上の表のとおり | |
| 押下 | 色が濃くなる | 押している間 |
| 無効 | 不透明度 0.4 にして押せなくする | 操作の条件がそろっていない（例: 送信できない） |
| フォーカス | `--accent` の 2px の輪（外側に 2px 離す） | キーボードで選ばれたとき |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 高さ | 44px 以上 | `--size-tap-target` |
| 角丸 | 999px（ピル） | `--radius-pill` |
| 文字 | 15px / 600 | |
| 横の余白 | 22px | |
| ボタン同士の間隔 | 10px | |

## アクセシビリティ

- `<button>` 要素を使う。画面の移動だけのゴーストは `<a>` でもよい。
- 無効は `disabled` 属性で示す。押せない理由が分かりにくいときは、近くに文で理由を書く。
- ラベルは動詞を含む短い文にする（「続ける」「1回だけ許可」）。
