# 完了トグル・解決済みバッジ（Done Toggle / Resolved Badge）

## 概要

スレッドや依頼を「解決済み・完了」にする丸いトグルと、解決済みを示す丸い印です。どちらもチェックのアイコンで、オンのときは緑（`--ok`）の円になります。トグルは押してオン・オフを切り替え、バッジは押せない印です。

## 使うとき

- トグル: スレッドの上端（[デッキヘッダー](deck-header.md)のスレッドの上端）と[依頼行](request-row.md)の右端。本人が完了を付け外しするもの
- バッジ: 解決済みの[スレッドカード](thread-card.md)の左端

## 使わないとき

- やることの一覧のチェック → [リスト行](list-rows.md)のタスク行
- 即時に効く設定 → [スイッチ](input-and-switch.md)
- エージェントが修正中のものには出さない（同じ大きさの空きを置いて位置を保つ）

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| トグル | 32px の円。オフは `--fill` の面に緑のチェック、オンは緑の面に白いチェック | 完了の付け外し |
| 解決済みバッジ | 32px の緑の円に白いチェック。押せない | 解決済みのスレッドカード |

## 状態

| 状態 | 見た目 | 対象 |
| --- | --- | --- |
| オフ | `--fill` の面、1px の `--border` の枠、チェックは `--ok` | トグル |
| オン | `--ok` の面と枠、チェックは白、カードの影 | トグル |
| 押下 | 0.9 倍に縮む（0.1 秒） | トグル |
| フォーカス | フォーカスの輪 | トグル |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 大きさ | 見た目 32×32px の円。押せる範囲は外側に 6px 広げて 44px | `--radius-pill` `--size-tap-target` |
| チェック | 16px、線 2.6px | `--ok`、オンは白 |
| オンの面 | 緑 | `--ok` |
| オンの影 | カードの影 | `--shadow-card` |

緑の面に載せる白には、まだトークンがありません（[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 19）。また、[リスト行](list-rows.md)のタスク行は完了を `--accent` で塗るので、「完了の色」が2つあります（同 25）。

## アクセシビリティ

- トグルは `<button aria-pressed>` にし、`aria-label` は押したあとに起きることにする（「解決済みにする」／「未解決に戻す」、依頼は「完了にする」／「未完了に戻す」）。
- バッジは `aria-hidden="true"` にし、解決済みであることはカードの `aria-label` で伝える。
- 完了は色だけでなく、題の打ち消し線でも示す。
