# 今ここストリップ（Now Strip）

**アプリ固有の複合体。** 学習ノートでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

[コースパス](course-path.md)の上に固定して、いまの Part・章と、クリア済みの章の数を見せる帯です。パスを下にスクロールしても現在地が分かるようにします。

## 組み合わせ

- [セクションカード](../../components/section-card.md)の面（`--surface`・枠・カードの影）を1行にして `position: sticky` で固定したもの
- 中身は[進捗パス](../../components/progress-path.md)の現在地と、完了の数

## 使うとき

- 長いコースパスを持つホーム画面で、パスの直前に1つだけ置く

## 使わないとき

- パスが1画面に収まる短いコース（パスの現在ノードで足りる）
- 操作を載せない（始める操作は画面下の[ボタン](../../components/button.md)にする）
- 学習プレイヤーの中 → [プレイヤートップバー](player-top-bar.md)

## バリアント

| バリアント | 構成 | 用途 |
| --- | --- | --- |
| 現在地あり | ラベル「今ここ」＋「Part の題 · 章の題」＋「クリア済み n章 · 全m章」 | 未完了の章がある |
| 全部クリア | 「全部クリア済みだよ」＋「クリア済み n章 · 全n章」 | すべての章が完了 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | パスの上の位置に置かれる | スクロール前 |
| 固定 | 画面上端から 8px の位置に貼り付く | スクロールして上端に届いたとき |

押せないので、押下・フォーカスの状態は持ちません。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | 白、1px の枠、カードの影 | `--surface` `--border` `--shadow-card` |
| 角丸 | 20px | `--radius-card` |
| 内側の余白 | 上下 12px、左右 16px | |
| 固定の位置 | `position: sticky; top: 8px` | |
| ラベル「今ここ」 | 11px / 800、字間 0.05em | `--accent-strong`（11px は段にない。[判断待ちの点](../../open-questions.md#学習ノート由来の部品) 16） |
| 題 | 14px / 700 | `--text` |
| 数 | 13px | `--dim` |

## アクセシビリティ

- 見出し要素にはせず、`<p>` の並びにする（ページの見出し構造に入れない）。
- 固定される帯の高さぶん、パスのノードに `scroll-margin-top` を取り、フォーカスやスクロールで移ったノードが帯の下に隠れないようにする。
