# シートモーダル（Sheet Modal）

## 概要

画面の下からせり上がる板です。上に見出しと閉じる × を置き、中に1つの作業（ページを追加・ページを削除・行き場のないメモ）だけを入れます。広い画面（640px 以上）では中央に浮くパネルになります。

## 使うとき

- 今の画面の文脈（どのページか）を保ったまま、短い入力や選択をさせるとき
- 一覧を一時的に開いて、選んだら閉じるとき（行き場のないメモ）

## 使わないとき

- はい・いいえだけの確認 → [確認ダイアログ](confirm-dialog.md)
- 外部に触る操作の確認 → [承認カード](approval-card.md)
- 画面の上から出る切り替え → [コース切替パネル](course-switcher.md)
- 何画面も続く手続き（シートの中で画面を移らない）

## バリアント

| バリアント | 中身 |
| --- | --- |
| ページを追加 | [ページプレビューカード](page-preview-card.md) → [位置ラジオ](position-radio.md) → [メモ入力バー](memo-input-bar.md)（3行）→ ブルーの全幅ボタン「追加リクエストとして下書きに積む」 |
| ページを削除 | 「nページ」→ メモ入力バー（削除する理由）→ 赤い全幅ボタン「削除予定にする」。削除予定があるときは「このページは削除予定です（提出済み）」と理由、下書きなら「削除予定を取り消す」 |
| 行き場のないメモ | 行き場のないスレッド（題・「もとはnページ ・ n件」）と[依頼行](request-row.md)（シートの中）の一覧。ないときは「ありません」 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 閉じている | なし | |
| 開いている | 幕の上に、下端に付いた板 | |
| 送信できない | 全幅ボタンが不透明度 0.4 で押せない | 入力が空（ページを追加） |
| フォーカス | フォーカスの輪 | |

幕を押すか × を押すと閉じます。全幅ボタンを押すと依頼を下書きに積んで閉じます。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 幕 | 黒の 55% | 未定義（[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 20） |
| 板 | 白、最大幅 512px、高さは画面の 88% まで（はみ出すとスクロール）、浮く影 | `--surface` `--shadow-float` |
| 板の角丸 | 上の2つの角だけ 20px。640px 以上では4つの角 | `--radius-card` |
| 内側の余白 | 16px 16px 24px | |
| 見出しの行 | 16px / 600 の見出し＋右端に 32px の丸い ×（[デッキヘッダー](deck-header.md)の丸ボタン）、下に 16px | `--text` |
| 全幅ボタン | 高さ 48px 以上、14px / 600、上に 16px | 角丸 `--radius-row` |
| 全幅ボタンの色 | 追加はブルー、削除は赤、取り消しは `--fill` に 1px の枠 | `--accent` `--danger` `--fill` `--border` |
| 一覧の行 | `--fill` の面、1px の枠、内側 12px 16px、行同士 8px。題 14px / 500、補足 12px | `--fill` `--border` `--radius-row` `--dim` |

全幅ボタンは角丸 12px で、[ボタン](button.md)のピルと形が違います。シートの下に並ぶ「確定」はフォームの一部として扱う、とするかは[判断待ちの点](../open-questions.md#スライドエディタ由来の部品) 26 に含めます。

## アクセシビリティ

- 幕は `role="dialog"` と `aria-modal="true"` にし、見出しをダイアログの名前に結び付ける（`aria-labelledby`）。
- 開いたらシートの中の最初の入力（なければ ×）にフォーカスを移し、シートの外へフォーカスが出ないようにする。Esc で閉じ、開いたボタンにフォーカスを戻す。
- × は `aria-label="閉じる"` にする。
- 赤い全幅ボタンは色だけでなく文（「削除予定にする」）で何が起きるかを書く。
