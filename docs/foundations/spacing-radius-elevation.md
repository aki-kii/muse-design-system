# 余白・角丸・影

## 余白

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--space-inner` | 4px | 要素内の最小間隔 |
| `--space-row` | 8px | チップ同士・行の上下 |
| `--space-card-gap` | 12px | カード同士の間隔 |
| `--space-card-padding` | 16px | カードの内側（標準） |
| `--space-section` | 44px | セクションの間隔 |

部品の中は詰めて（4–8px）、部品同士は 12px、まとまり同士は 44px にします。余白の差がそのまま階層になります。

余白は 4 の倍数にします。実アプリはどれも Tailwind の 4px 刻みで組んでいるため、v0.7.0 でカード同士を 14px → 12px、カードの内側を 18px → 16px に変えました（[決定記録 0004](../decisions/0004-scale-and-local-values.md)）。部品の中の細かい調整（2px・6px・10px）は 2 の倍数まで認めます。

## 角丸

角丸は部品の大きさと役割で決め、気分で変えません。

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--radius-small` | 6px | 小物・小角（吹き出しのしっぽ側など） |
| `--radius-row` | 12px | 行・入力欄 |
| `--radius-card` | 20px | カード・吹き出し |
| `--radius-pill` | 999px | ボタン・チップ・タグ・タブバー・トースト |

触れるもの（ボタン・チップ）はピル、読むもの（カード）は 20px、フォームは 12px です。数値タイルは 12px（`--radius-row`）にします。シートやダイアログの下に並ぶ確定ボタンは、フォームの一部として 12px にします。

パターンの中だけで使う角丸（学習ノートのコースのアイコンの 8px・14px など）は、そのパターンの文書に値を書き、段には足しません。

## 影

影は2種類だけです。学習ノートのノードの「下にずらした色の帯」（`0 4px 0`）は、影ではなく[進捗パス](../components/progress-path.md)のコースの形として書いています。

| 変数 | 使う場所 |
| --- | --- |
| `--shadow-card` | カードの控えめな影 |
| `--shadow-float` | 浮く部品（タブバー・トースト） |

ダークモードでは同じ名前のまま、黒を濃くした値に切り替わります。

## 大きさ

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--size-tap-target` | 44px | 押せる要素の最小の高さと幅 |

## 幕

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--scrim` | 黒の 40% | パネル・下から出るシート |
| `--scrim-strong` | 黒の 70% | キーボードと一緒に出る入力のシート |

確認ダイアログは幕を使わず、`--bg` の不透明な面で後ろを覆います。

## 部品だけの寸法

FAB の 48px、件数バッジの 20px、修正中の点の 6px、長押しメニューの幅 176px のように、1つの部品でしか使わない寸法はトークンにせず、その部品の文書に値を書きます。2つ目の部品やアプリで同じ値が使われたら、トークンにするかを検討します（[決定記録 0004](../decisions/0004-scale-and-local-values.md)）。
