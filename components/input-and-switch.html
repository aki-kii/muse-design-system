入力欄とスイッチ（Input / Switch）

ラベル＋欄＋ヒント。スイッチは即時に効く設定だけ

デモ

入力欄（空のまま欄を離れるとエラーの状態）

ほかの人に見える名前です

エラー

@ の後ろまで入れてください

スイッチの行（行全体が押せる）

朝のお知らせ毎朝 7:00 に通知する
通知承認が要るときに知らせる

概要#

入力欄は「ラベル＋欄＋ヒント」の3点セットです。スイッチはオン／オフが即座に効く設定だけに使います。

使うとき#

  • 入力欄: ラベルは常時表示する。プレースホルダは例だけに使う
  • スイッチ: 切り替えた瞬間に反映される設定（通知のオン／オフなど）

使わないとき#

  • 「保存」が必要な設定にスイッチを使わない → ボタンで確定する形にする
  • 選択肢が3つ以上あるものにスイッチを使わない

バリアント#

バリアント構成例
入力欄ラベル＋欄＋ヒント表示名
スイッチの行題＋補足＋スイッチ朝のお知らせ ｜ 毎朝 7:00 に通知する

状態#

状態見た目対象
通常1.5px の枠、--border入力欄
フォーカス枠が --accent になり、外に --accent の 2px の輪（2px 離す）入力欄・スイッチ
エラーヒントの位置に --danger の文入力欄
オン--accent の面スイッチ
オフ--border の面スイッチ

仕様#

項目値トークン
ラベル13px / 600
入力欄の高さ48px
入力欄の角丸12px--radius-row
入力欄の文字16px（iOS の拡大表示を防ぐ）--text-base
ヒント12px--dim
スイッチの大きさ52×32px
スイッチの角丸999px--radius-pill

ヒントは「何を書けばいいか」の例を出す場所で、エラーの文もここに出します。

アクセシビリティ#

  • ラベルは <label for> で欄に結び付ける。プレースホルダをラベルの代わりにしない。
  • ヒントとエラーの文は aria-describedby で欄に結び付け、エラーのときは aria-invalid="true" を付ける。
  • エラーは赤い色だけでなく文で伝える。
  • スイッチは <button role="switch" aria-checked> にし、題をラベルとして結び付ける。スイッチの高さは 32px なので、行全体を押せるようにして 44px を確保する。
