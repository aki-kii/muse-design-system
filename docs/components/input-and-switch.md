# 入力欄とスイッチ（Input / Switch）

## 概要

入力欄は「ラベル＋欄＋ヒント」の3点セットです。スイッチはオン／オフが即座に効く設定だけに使います。

## 使うとき

- 入力欄: ラベルは常時表示する。プレースホルダは例だけに使う
- スイッチ: 切り替えた瞬間に反映される設定（通知のオン／オフなど）

## 使わないとき

- 「保存」が必要な設定にスイッチを使わない → [ボタン](button.md)で確定する形にする
- 選択肢が3つ以上あるものにスイッチを使わない

## バリアント

| バリアント | 構成 | 例 |
| --- | --- | --- |
| 入力欄 | ラベル＋欄＋ヒント | フィードの指示 |
| スイッチの行 | 題＋補足＋スイッチ | 朝のブリーフ ｜ 毎朝 7:00 に Daily Brief を更新する |

## 状態

| 状態 | 見た目 | 対象 |
| --- | --- | --- |
| 通常 | 1.5px の枠、`--border` | 入力欄 |
| フォーカス | 枠が `--accent` になり、外に `--accent-soft` の輪 | 入力欄・スイッチ |
| エラー | ヒントの位置に `--danger` の文 | 入力欄 |
| オン | `--accent` の面 | スイッチ |
| オフ | `--border` の面 | スイッチ |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| ラベル | 13px / 600 | |
| 入力欄の高さ | 48px | |
| 入力欄の角丸 | 12px | `--radius-row` |
| 入力欄の文字 | 16px（iOS の拡大表示を防ぐ） | `--text-base` |
| ヒント | 12px | `--dim` |
| スイッチの大きさ | 52×32px | |
| スイッチの角丸 | 999px | `--radius-pill` |

ヒントは「何を書けばいいか」の例を出す場所で、エラーの文もここに出します。

## アクセシビリティ

- ラベルは `<label for>` で欄に結び付ける。プレースホルダをラベルの代わりにしない。
- ヒントとエラーの文は `aria-describedby` で欄に結び付け、エラーのときは `aria-invalid="true"` を付ける。
- エラーは赤い色だけでなく文で伝える。
- スイッチは `<button role="switch" aria-checked>` にし、題をラベルとして結び付ける。スイッチの高さは 32px なので、行全体を押せるようにして 44px を確保する。
