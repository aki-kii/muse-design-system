# 0006: アイコンの組は Lucide の形の線のアイコンにする

- 状態: 決定
- 日付: 2026-11-17

## 背景

[判断待ちの点](../open-questions.md)の 17 と 28。DS にアイコンの決まりがなく、学習ノートは ✕・🔊・★・▶ を文字や絵文字で出し、スライドエディタは Lucide 風の線のアイコン（24 の枠、線 2〜2.6px、端は丸、16〜20px）で統一していた。学習ノートも、コースのノードや本棚の表紙のアイコンは同じ描き方の SVG（線 2.6px、端は丸）を使っている。

## 決定

- DS のアイコンの組は、[Lucide](https://lucide.dev/)（ISC ライセンス）の形の線のアイコンにする。24×24 の枠、線 2px（小さいものは 2.6px まで）、端と角は丸、塗りなし、色は `currentColor`、表示は 16〜20px（基準1: スライドエディタと学習ノートの SVG の現行の描き方）。
- SVG はアプリに直接書いてよく、パッケージを入れるかはアプリごとに決める。
- 文字の記号（✓ ✗ ★）は、文の中の印や飾りとして使ってよい。操作のボタンには線のアイコンを使う。
- 学習ノートの ✕・🔊・▶ は当面現行どおりにし、学習ノートの画面に手を入れるときに線のアイコンへ置き換える。新しく作る部品は最初から線のアイコンにする（基準5）。

## 結果

- [アイコン](../foundations/icons.md) をファウンデーションに足した。
- アイコンの組を変えるときは、この記録を置き換える新しい記録を書く。
