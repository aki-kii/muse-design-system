# 色

役割で名前を付けたトークンだけを使います。ダークモードでは同じ名前のまま値だけが切り替わります。

## UI の色

| トークン | ライト | ダーク | 使う場所 |
| --- | --- | --- | --- |
| `--bg` | `#EDEEF0` | `#000000` | ページ全体の背景 |
| `--surface` | `#FFFFFF` | `#17181A` | カードの面 |
| `--fill` | `#F0F0F2` | `#232527` | 控えめな面。チップ・第2ボタン・数値タイル。`--surface` の上だけ |
| `--text` | `#0B0D10` | `#FFFFFF` | 見出しと本文 |
| `--dim` | `#454D56` | `#C2C7CE` | 説明文・メタ情報 |
| `--faint` | `#656A72` | `#8E939A` | 時刻・注記・完了した項目の題 |
| `--border` | `#D2D6DC` | `#3E4248` | 罫線・区切り |

| `--danger-soft` | `#FDECEA` | `#3A1D1A` | 不正解・エラーの薄い面 |

| `--ok-soft` | `#E2F2EA` | `#12291F` | 正解・成功の薄い面 |
| `--gold` | `#F5B400` | `#FFC933` | 達成の面と飾り（完了したノード、★、祝福の帯） |

`--bg`、`--surface`、`--text`、`--dim`、`--border`、`--accent`、`--accent-ink` は、筋トレ記録と AWS アップデートの `theme.css` の値と一致しています。`--fill`、`--accent-strong`、`--accent-soft`、`--danger`、`--ok`（ライト）、`--ok-soft`、`--danger-soft`、`--gold`、`--gold-ink` は、学習ノートとスライドエディタが実際に使っている値です。`--faint` と、色の面に載せる文字（`-ink`）のダークの値は、WCAG の基準を満たすために DS で決めた値です（[決定記録 0003](../decisions/0003-color-and-contrast.md)）。

## ブルーの使い方

- 使う: 画面で一番大事な操作1つ、選択中の項目、進捗バー、リンク、フォーカスの輪、本人が付ける完了。
- 使わない: 装飾、大きな面の塗り、重要でないボタン。「全部青い」は「何も目立たない」と同じ。
- ブルーの文字は `--accent-strong`。 `--accent` を小さい文字に使うと、`--bg` の上で 3.9:1 になり 4.5:1 に届かない。`--accent` は面・枠・アイコン・大きい文字に使う。

## 赤の使い方

`--danger` は次の用途だけに使います。

- 削除・拒否・エラー
- 録音中（音声入力中のマイク）
- 未送信の件数（下書きの件数バッジ）

小さい赤の文字は `--surface` の上（カードやシートの中）に置き、`--bg` の上に直接置きません（`--bg` の上では 4.2:1）。

## 緑と金色の使い方

- 完了の色は意味で分ける。 本人が自分で付ける完了（タスク・筋トレのセット）は `--accent`。相手とのやりとりが片付いた（解決済み・依頼が済んだ）、正解は `--ok`。
- 金色は面と飾りだけ。 `--gold` は文字の色に使わない（白の面の上で 1.8:1）。金色の面の上の文字や ★ は `--gold-ink`。XP のような数字は `--text` で書き、横に金色の ★ を飾りとして置く。

## 控えめな面（`--fill`）の置き場所

`--fill` は `--bg` とほぼ同じ明るさ（1.02:1）です。チップ・第2ボタン・数値タイルの `--fill` の面は、カードやシートの中（`--surface` の上）でだけ使います。カードの外（`--bg` の上）に置くときは、`--surface` の面に `--border` の 1px の枠を付けます。

## 文字の3段

`--text`（本文）→ `--dim`（補足）→ `--faint`（時刻・注記・完了した項目）の3段までにします。4段目は作らず、弱めたいときはサイズも一緒に落とします。3段とも、`--bg`・`--surface`・`--fill` のどれの上でも 4.5:1 以上あります。行や文字を不透明度で薄くして段を作らないでください（比が下がるため）。

## 中身側の色

コンテンツが持つ色は、DS のトークンの役割の色とは別に扱います。ボタンや見出しには流用しません。

| 中身 | 扱い |
| --- | --- |
| 家族カレンダー | `--cal-common`（`#F08A24`）・`--cal-self`（`#0E7C86`）・`--cal-partner`（`#E5487B`）。予定行のバーと凡例だけ |
| 学習ノートのコース・ノートの色 | コースやノートのデータが持つ値。DS のトークンにしない。白の文字を載せる面（Part 見出し）に使う色は、白に対して 4.5:1 以上のものを選ぶ。表紙のように文字を載せない面は飾りとして扱う |
| スライドの中の色（文字・強調・図・コードの面、スライドの地） | デッキ側の色。DS のトークンにしない。ダークでもデッキの見た目のまま |
| 紙吹雪 | 飾りの色。DS のトークンにしない（学習ノートの現行の4色） |
| 筋トレ記録の休憩表示（`--rest`） | アプリ側の色。DS のトークンにしない |

## 組み合わせの決め事

文字の色は載せる面の色と組みで選びます。下の組み合わせ以外を使うときは、[アクセシビリティ](accessibility.md#コントラスト比) の表で比を確かめます。

| 面 | 載せる文字 |
| --- | --- |
| `--bg` / `--surface` / `--fill` | `--text`、`--dim`、`--faint`、`--accent-strong` |
| `--surface` | `--danger`（小さい文字はここだけ） |
| `--accent` / `--bubble-user` | `--accent-ink` / `--bubble-user-ink` だけ |
| `--ok` | `--ok-ink` だけ |
| `--danger` | `--danger-ink` だけ |
| `--gold` | `--gold-ink` だけ |
| `--accent-soft` | `--accent-strong`、`--text` |
| `--ok-soft` / `--danger-soft` | `--text`（`--ok`・`--danger` は 18px 以上の太字だけ） |

## 名前の対応

静的ページ版 v0.3 と適用済みアプリで変数名が違っていたため、このリポジトリではアプリ側の名前に揃えました。

| このリポジトリ | 静的ページ版 v0.3 | jin-toreji-lu の theme.css |
| --- | --- | --- |
| `--bg` | `--bg` | `--bg` |
| `--surface` | `--surface` | `--surface` |
| `--fill` | `--fill` | （なし） |
| `--text` | `--ink` | `--text` |
| `--dim` | `--ink-2` | `--dim` |
| `--faint` | `--ink-3` | （なし） |
| `--border` | `--line` | `--border` |
| `--accent` | `--blue` | `--accent` |
| `--accent-ink` | （なし。`#fff` を直接書いていた） | `--accent-ink` |
| `--accent-strong` | `--blue-ink` | （なし） |
| `--accent-soft` | `--blue-soft` | （なし） |
| `--danger` | `--danger` | （なし） |
| `--ok` | `--ok` | （なし） |

v0.3 の `--blue-ink` は「ブルーの文字」、アプリの `--accent-ink` は「ブルーの面に載せる文字」で、似た名前で意味が違います。混同を避けるため、前者を `--accent-strong` にしました。
