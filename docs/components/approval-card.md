# 承認カード（Approval: Needs Review）

## 概要

アシスタントやアプリが、本人のアカウントや外部に触る操作をする前に、必ず止まって確認を取るための専用カードです。普通のカードと違い、操作ボタンまでが部品の一部です。

## 使うとき

- 送信・注文・予約など、取り消しにくい操作の直前
- 結果はカード内に残す（許可した範囲と時刻）

## 使わないとき

- 読み取りだけの操作に使わない（確認の回数が増えて、確認が形だけになる）
- 普通の[セクションカード](section-card.md)で代用しない（ボタンの意味が曖昧になる）

## バリアント

なし（1種類だけ）。

## 状態

| 状態 | 見た目 |
| --- | --- |
| 確認待ち | 1行目の文＋ボタン行 |
| 結果 | ボタン行の代わりに、許可した範囲と時刻を 13px / 600 の `--accent-strong` で残す |

## 仕様

構成は次のとおりです。

1. 1行目: 「誰が・何を・どこへ」を書く（例: アシスタント が メールを送ろうとしています）
2. 補足: 操作の中身
3. ボタン行: 許可の範囲を選ばせる

| ボタン | バリアント |
| --- | --- |
| 1回だけ許可 | プライマリ |
| このタスク中は許可 | セカンダリ |
| 拒否 | 危険のゴースト |

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | 白、1px の枠 | `--surface` `--border` |
| 角丸 | 20px | `--radius-card` |
| 内側の余白 | 16px | |
| 1行目 | 15px / 600 | |
| 補足 | 13px | `--dim` |
| 許可の単位 | 1回／このタスク中 | |

## アクセシビリティ

- カードは `<section>` にし、1行目を見出しとしてカードの名前に結び付ける（`aria-labelledby`）。
- 確認待ちのカードが現れたら、読み上げで気付けるようにする（`role="region"` と見出し、または `aria-live="polite"` の通知）。
- 結果の文は色だけでなく「許可した（1回だけ）11:02」のように文で残す。
