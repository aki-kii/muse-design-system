# プレイヤートップバー（Player Top Bar）

**アプリ固有の複合体。** 学習ノートでだけ使います。v0.6.0 でコンポーネントからパターンに移しました（[昇格のルール](../../decisions/0002-component-admission.md)）。別のアプリで同じものが要るときは、まず下の「組み合わせ」の汎用部品で組みます。

## 概要

学習プレイヤー（解説と問題を1画面ずつめくる画面）の上端に置くヘッダーです。閉じる ✕、進捗トラック、コンボ、XP を1行に並べ、その下にノード名・章名・位置を1行で添えます。

## 組み合わせ

- [アイコンボタン](../../components/icon-button.md)（✕。ホームに戻る）
- [リスト行](../../components/list-rows.md)のメーターと同じ形の進捗トラック
- コンボと XP の文字（学習プレイヤー固有）

## 使うとき

- 学習プレイヤーの全画面（解説・問題・単語カード・章完了）
- [章完了パネル](chapter-complete-panel.md)を出している間も残す

## 使わないとき

- ホーム・本棚など、タブで行き来する画面（[ナビゲーション](../../components/navigation.md)を使う）
- 復習画面とセッション画面では、✕＋見出しだけの簡易な形にする（コンボと XP は出さない）
- 進捗バーを単独で使う → [リスト行](../../components/list-rows.md)のメーター

## バリアント

| バリアント | 進捗の範囲 | 位置の文 |
| --- | --- | --- |
| 章の中 | 今の章のページ数に対する位置 | 「ノート名 · 章名 · 3/7」 |
| ノート全体 | ノート全体のページ数に対する位置（章を指定せずに開いたとき） | 「ノート名 · 5/24」 |

## 状態

| 要素 | 状態 | 見た目 |
| --- | --- | --- |
| コンボ | 2以上 | 「×n」を `--accent` |
| コンボ | 0〜1 | 「×n」を `--dim` |
| 進捗トラック | 進んだとき | 幅が伸びる（0.45 秒） |
| 進捗トラック | 終わり | 100% |
| ✕ | フォーカス | フォーカスの輪 |

## 仕様

構成:

1. ✕（ホームに戻る）
2. 進捗トラック（残りの幅をすべて使う）
3. コンボ「×n」
4. XP「XP n」
5. 位置の文（2行目）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 要素の間隔 | 12px | |
| ✕ | 36×36px、22px、角丸 10px | `--dim` |
| 進捗トラック | 高さ 8px のピル。地は罫線の色、進捗はブルー | `--border` `--accent` `--radius-pill` |
| コンボ | 15px / 800 | `--accent` または `--dim` |
| XP | 15px / 800、金色 | 未定義（[判断待ちの点](../../open-questions.md#学習ノート由来の部品) 11） |
| 位置の文 | 12px、1行で切る（…） | `--dim` |

✕ の見た目は 36px ですが、押せる範囲は `--size-tap-target`（44px）を確保します。

## アクセシビリティ

- ✕ は `<button>` にし、`aria-label="ホームに戻る"` を付ける。
- 進捗トラックは `role="progressbar"` と `aria-valuenow` / `aria-valuemin` / `aria-valuemax` を付け、`aria-label` で範囲を言う（「今の章の進み具合」「ノートの進み具合」）。
- コンボと XP は `aria-label` で「コンボ 2」「240 XP」と読ませる（「×2」を記号のまま読ませない）。
- トラックの伸びる動きは `prefers-reduced-motion: reduce` のとき止める。
