# スケルトン（Skeleton）

## 概要

読み込み中に、これから出る中身の形だけを灰色の面で先に見せる部品です。中身が届いたら同じ場所でそのまま置き換わるので、画面が跳ねません。

参考元: [Carbon の Skeleton states](https://carbondesignsystem.com/patterns/loading-pattern/#skeleton-states)、[Polaris の Skeleton](https://polaris-react.shopify.com/components/feedback-indicators/skeleton-page)、[Primer の SkeletonBox](https://primer.style/components/skeleton-box)。もらったのは「中身の形を先に見せる」という考え方と構成だけで、見た目は Muse DS のトークンで作っています。

## 使うとき

- 画面を開いてから中身が届くまでの待ち（Muse の各アプリで「読み込み中…」の文だけを出している場所）
- 形が決まっている一覧やカード（リスト行・セクションカード・メディアカード）の読み込み
- 待ちが 0.3 秒ほどを超えそうなとき

## 使わないとき

- ボタンを押したあとの処理の待ち → [アイコンボタン](icon-button.md)・[ボタン](button.md)の処理中の状態
- 相手（エージェント）が書いている途中 → [作業中インジケータ](typing-indicator.md)
- 時間がかかる処理で、何をしているかを伝えたいとき → 「今日の発表を集めて並べ替えています」のような文と[作業中インジケータ](typing-indicator.md)。形だけでは待つ理由が伝わらない
- 読み込みに失敗したとき → [空の状態](empty-state.md)のエラー
- 中身の形が決まっていない画面に、それらしい形を作って出さない

## バリアント

| バリアント | 見た目 | 用途 |
| --- | --- | --- |
| 文 | 高さ 12px のピルの線を 2〜3本。最後の1本は 60% の長さ | 見出し・本文・メタ情報 |
| 丸 | 部品と同じ大きさの円 | アイコン・チェックの丸・アバターの位置 |
| 面 | 部品と同じ大きさと角丸の四角 | サムネイル・数値タイル・カード全体 |

バリアントは単独では使わず、置き換わる部品の形（[リスト行](list-rows.md)や[メディアカード](media-card.md)）に合わせて組みます。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 読み込み中 | `--fill` の面がゆっくり明滅する（不透明度 1 → 0.55、1.6 秒で往復） | 中身を待っている |
| 動きを減らす | 明滅を止め、`--fill` の面のまま | `prefers-reduced-motion: reduce` |
| 読み込み済み | スケルトンを消し、同じ場所に中身を出す | 中身が届いた |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面の色 | `--fill`（カードの上）、`--border`（`--bg` の上） | `--fill`・`--border` |
| 文の線 | 高さ 12px、角丸 999px、行の間隔 8px | `--radius-pill`、`--space-row` |
| 面の角丸 | 置き換わる部品と同じ（カード 20px、行 12px） | `--radius-card`・`--radius-row` |
| 並べる数 | 画面に収まる数まで（一覧なら 3〜5件） | |
| 明滅 | 1.6 秒で往復、`ease-in-out` | |

構成:

1. 置き換わる部品の外枠（カードの面・行の面）は本物と同じに描く
2. 中の文字・アイコン・画像の位置にだけ、スケルトンの線・丸・面を置く

## アクセシビリティ

- スケルトンの要素は `aria-hidden="true"` にし、読み上げない。
- 読み込む範囲（一覧の親など）に `aria-busy="true"` を付け、別に「読み込み中」を `.vh`（見えない文）で1つだけ置く。届いたら `aria-busy` を外す。
- 明滅は `prefers-reduced-motion: reduce` のとき止める。
- 10 秒を超えても届かないときは、スケルトンを出し続けず[空の状態](empty-state.md)のエラーに切り替える。
