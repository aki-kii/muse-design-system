# メディアカード（Media Card）

## 概要

上にサムネイル、下にタイトルとメタ情報（件数・日付・進み具合など）を置いた、押せるカードです。見た目で思い出せるものを一覧で選ばせるときに使います。カード全体が1つのリンク（またはボタン）です。

## 使うとき

- 表紙や見た目が選ぶ手がかりになるものの一覧（資料、ノート、アルバムなど）
- 1件ごとに開く先がある一覧

## 使わないとき

- 文字だけで足りる一覧 → [リスト行](list-rows.md)
- 状態（確認待ち・作業中など）を見せたい一覧 → [状態付きリスト項目](status-list-item.md)
- 読み物ページの話題の単位 → [セクションカード](section-card.md)
- 順番のある段階 → [進捗パス](progress-path.md)

## バリアント

| バリアント | サムネイル | メタ情報 | 並べ方 |
| --- | --- | --- | --- |
| 大 | 横長（中身の比、例: 980:552）。下に 1px の罫線 | タイトル＋件数・日付を横に | 1列、間 24px |
| 小（表紙） | 色の面＋白い線のアイコン（高さ 76px 前後） | タイトル＋進捗バー | 2列のグリッド、間 12px |

サムネイルがないときは、`--fill` の面にタイトルを `--dim` で出します（「サムネイルなし」の状態）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 通常 | `--surface` の面、1px の枠、カードの影 | |
| 押下 | 0.98 倍に縮む | 押している間 |
| サムネイルなし | 上の文のとおり | 表紙がまだない |
| フォーカス | フォーカスの輪（カード全体） | キーボードで選ばれたとき |

## 仕様

構成は次のとおりです。

1. サムネイル（飾り）
2. タイトル（2行まで）
3. メタ情報（Small 段の `--dim`。進捗はメーター）

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | 白、1px の枠、カードの影 | `--surface` `--border` `--shadow-card` |
| 角丸 | 20px（中のサムネイルは角丸の内側で切る） | `--radius-card` |
| メタの領域の余白 | 16px（小は 10px 12px） | |
| タイトル | 14px / 600、行間 1.7 | `--text` |
| メタ情報 | 12px、項目の間 16px | `--dim` |
| 進捗バー | 高さ 6px のピル | `--border` `--accent` |

サムネイルの中の色（表紙・スライドの色）は中身側の色で、DS のトークンでは塗りません（[色](../foundations/color.md#中身側の色)）。

## アクセシビリティ

- 一覧は `<ul>`、1枚は `<a>`（開く先がページなら）か `<button>` にする。
- サムネイルは `aria-hidden="true"` にし、名前はタイトルの文で伝える。カードの `aria-label` にはタイトルとメタ情報を入れる。
- 進捗バーを出すときは、割合を `aria-label` かメタ情報の文に含める。
