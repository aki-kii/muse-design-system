# リアクションバー（Reaction Bar）

## 概要

一覧の項目に、絵文字のリアクションを付ける部品です。項目ごとに入口の丸ボタンがあります。入口を押すと、丸いピル型のバーが横にスライドして開きます。

バーには、よく使う15個の絵文字が一列に並びます。幅に入りきらない分は、バーを横にスクロールして選びます。バーの右端には「＋」ボタンがあります。「＋」を押すと絵文字の一覧（グリッド）が開き、15個以外の絵文字も選べます。

1項目に付けられる絵文字の数は、「1つだけ」と「複数」のどちらかに決めて使います。

## 使うとき

- 一覧の項目それぞれに、軽い反応を残したいとき
- 反応を文にするほどではなく、あとで見返したり数えたりしたいとき

## 使わないとき

- 「済み」「未」のように意味が決まった印 → [完了トグル・完了バッジ](done-toggle.md)
- 評価や回答のように、選択肢が決まっている選択 → [選択肢ボタン](choice-button.md)
- 項目への操作（コピー・削除など） → [長押しメニュー](long-press-menu.md)

## バリアント

付けられる数で2種類あります。1つの画面の中では、どちらかにそろえます。

| バリアント | 付けられる数 | 付いた絵文字の見せ方 | 押したあと |
| --- | --- | --- | --- |
| 1つだけ | 1項目に1つ | 入口のボタンに出す | バーを閉じる |
| 複数 | 1項目にいくつでも | 項目の題の下に、付けた順に並べる。入口は笑顔のアイコンのまま | バーを開いたままにする |

バーに並べる絵文字は、次の15個をこの順に置きます。

👍 ⭐ 🤔 ❤️ 😂 😮 😢 🙏 🔥 🎉 👀 💡 ✅ 🤣 🥺

グリッドには、バーにない絵文字を並べます。バーの15個はグリッドに重ねて置きません。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 付いていない | 入口に笑顔の線のアイコン（`--faint`） | |
| 付いている | 入口の面を `--fill` にする。1つだけのときは、入口に付けた絵文字を出す | 絵文字を1つ以上付けた |
| バーが開いている | 入口の下にバーが出る。右から 28px スライドしながら 220ms で現れる | 入口を押した |
| グリッドが開いている | バーの下にグリッドが出る。220ms でフェードして現れる。「＋」に `--accent-soft` の丸い背景が付く | 「＋」を押した |
| 選択中の絵文字 | バーとグリッドの中で、付けている絵文字に `--accent-soft` の丸い背景を付ける | |
| 押下 | 不透明度を下げる | |
| フォーカス | フォーカスの輪 | |

押したときの動きは、バーとグリッドで同じです。

- 付けていない絵文字を押すと、その絵文字が付く。1つだけのときは、付いていた絵文字と付け替わる。
- 付けている絵文字をもう一度押すと、取り消す。
- 1つだけのときは、絵文字を押したらバーとグリッドを閉じる。複数のときは開いたままにし、続けて付け外しできる。
- 「＋」を押すとグリッドが開き、開いているときに押すとグリッドを閉じる。
- 開いているときに入口を押すと、バーとグリッドをまとめて閉じる。

バーを開いたときは、付けている絵文字が見える位置までバーをスクロールします。付けている絵文字にグリッドのものがあるときは、グリッドも開いた状態で出し、その絵文字が見える位置までグリッドをスクロールします。

バーの絵文字の列は、右端の「＋」の手前で、入りきらない絵文字を途中で切って見せます。続きがあることは、この切れ目で伝えます。列だけが横にスクロールし、「＋」はいつも右端に残ります。スクロールバーは出しません。マウスのホイールの縦の回転でも、列を横に送れるようにします。

グリッドは4行半の高さで切り、続きは縦にスクロールして選びます。こちらもスクロールバーは出しません。

UI の中に説明文は置きません。使い方は入口のアイコン、並んだ絵文字、「＋」で伝えます。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 入口 | 36px の丸。1px の枠、面は白。押せる範囲は外側に広げて 44px | `--surface` `--border` `--size-tap-target` |
| 入口のアイコン | 笑顔の線のアイコン 20px | `--faint` |
| 入口の絵文字（1つだけ） | 19px。面は控えめな面 | `--fill` |
| 付いた絵文字の列（複数） | 題の下 8px。高さ 28px・最小幅 32px のピル型を間隔 4px で折り返して並べる。1px の枠、面は控えめな面、絵文字 16px | `--space-row` `--space-inner` `--radius-pill` `--border` `--fill` |
| バー | 項目の下 12px。項目の幅いっぱい。ピル型、1px の枠、面は控えめな面。内側は上下・右 4px、左 6px | `--radius-pill` `--border` `--fill` |
| バーの絵文字の列 | 残りの幅いっぱい。間隔 2px。横にスクロールする | |
| 区切り線 | 列と「＋」の間。幅 1px・高さ 24px、左右 2px | `--border` |
| 「＋」 | 44px 四方の丸。プラスの線のアイコン 20px | `--size-tap-target` `--dim` |
| 「＋」（グリッドが開いている） | 丸い背景、アイコンはブルーの文字色 | `--accent-soft` `--accent-strong` |
| グリッド | バーの下 8px。項目の幅いっぱい。1px の枠、面は控えめな面、角丸はカード。内側 6px、間隔 2px。列は幅に合わせて 44px 以上で並べる。高さは4行半まで | `--radius-card` `--border` `--fill` `--size-tap-target` |
| 絵文字（バー・グリッド） | 44px 四方。絵文字 21px | `--size-tap-target` |
| 選択中の絵文字 | 丸い背景 | `--accent-soft` |

浮き上がりは影で表さず、罫線と面の色の差で表します（[決定記録 0009](../decisions/0009-no-shadows.md)）。バーとグリッドは `--fill`、選択中は `--accent-soft` にします。どれもライトとダークで同じトークンを使います。

構成は次のとおりです。

1. 入口のボタン（項目の右端）
2. 付いた絵文字の列（複数のときだけ。項目の題の下）
3. バー（横にスクロールする15個の絵文字の列と、右端に残る「＋」）
4. グリッド（「＋」で開く、ほかの絵文字の一覧）

## アクセシビリティ

- 入口は `<button>` にし、`aria-expanded` でバーの開閉を示す。`aria-label` には項目の名前を入れる（例:「リアクション（項目の名前）」）。付いている絵文字があれば、それも名前に含める。
- バーは `role="group"` と `aria-label`（「リアクション」）を付ける。絵文字は `<button>` にし、付けているものを `aria-pressed="true"` にする。
- 「＋」は `<button>` にし、`aria-label`（「ほかの絵文字」）と、グリッドの開閉を示す `aria-expanded` を付ける。
- グリッドは `role="group"` と `aria-label`（「ほかの絵文字」）を付ける。絵文字はバーと同じく `<button>` と `aria-pressed` にする。
- 付いた絵文字の列は表示だけにする。付け外しはバーとグリッドで行う。
- キーボードでは Tab で、バーの絵文字、「＋」、グリッドの絵文字の順に移る。フォーカスが移った絵文字は、見える位置までバーやグリッドをスクロールする。
- Esc は、グリッドが開いていればグリッドを閉じて「＋」にフォーカスを戻す。グリッドが閉じていればバーを閉じて入口にフォーカスを戻す。1つだけのときに絵文字を押して閉じたときも、入口にフォーカスを戻す。
- `prefers-reduced-motion: reduce` のときは、バーのスライドとグリッドのフェードを止める。
