# 判断待ちの点

デザインの判断が要るため、このリポジトリでは値や使い分けを変えずに残している点です。決まったら値を直し、[決定記録](decisions/README.md) に移します。

## 色

1. **`--fill` と `--bg` の差がほぼない。** 静的ページ版では背景 `#FAFAFA` より `--fill`（`#F0F0F2`）が暗かったが、アプリの背景 `#EDEEF0` に合わせた結果、`--fill` のほうがわずかに明るくなった（比 1.02:1）。カードの外に置いたチップや第2ボタンが背景と見分けられない。`--fill` をアプリの背景に合わせて調整するか、「`--fill` はカードの中だけで使う」と決めるか。
2. **`--faint` のコントラストが足りない。** ライトで `--surface` に対して 3.3:1、`--bg` に対して 2.9:1。時刻・注記・完了したタスクの題に使っている。値を濃くするか、用途を「読めなくても困らないもの」に限ると明記するか。
3. **ブルーとレッドの文字を `--bg` に直接置くと 4.5:1 に届かない。** `--accent` は 3.9:1、`--danger` は 4.2:1（ライト）。カードの中（`--surface`）なら届く。
4. **ダークの `--ok` が 3.6:1。** 静的ページ版でもダークの値が定義されておらず、ライトと同じ `#12805C` になっている。
5. **アプリにないトークンの値。** `--fill`、`--faint`、`--accent-strong`、`--accent-soft`、`--danger`、`--ok`、吹き出し、影は、静的ページ版の値のまま。アプリの濃いめの色合い（本文 `#0B0D10`、アクセント `#0073E6`）に合わせて調整するか。

## フォーカス

6. **フォーカスの輪が見えにくい。** `--accent-soft` の 3px の輪は、面に対して 1.1〜1.2:1 で、WCAG 2.2 の基準（3:1）に届かない。入力欄は枠が `--accent` に変わるので見えるが、ボタン・チップ・タブでは見えにくい。輪を `--accent` にするか、`--accent-soft` の輪の内側に `--accent` の線を足すか。

## 余白・角丸・文字

7. **「余白は4の倍数」と実際の値が合わない。** 静的ページ版には「余白は4の倍数」とあるが、カード同士 14px、カードの内側 18px は4の倍数ではない。ルールを書き直すか、値を 12/16 などに寄せるか。このリポジトリでは値を残し、ルールの文は載せていない。
8. **数値タイルの角丸 14px が角丸の段にない。** 段は 6/12/20/999。12 か 20 に寄せるか。
9. **タイポの段のサイズ（13・15・17・22・28・38px）が文字サイズのスケール（12・14・16・18・20・24・30・36・48px）に乗っていない。** 段をスケールに合わせるか、段のサイズをスケールに足すか。本文の行間も、段では 1.55、スケールでは 24px（1.5）と違う。
10. **タブの大きさ。** 静的ページ版の仕様の表は 52×44px、見本の実装は 56×44px。どちらを正にするか。

## 学習ノート由来の部品

v0.4.0 で足した学習ノートの部品に必要で、まだトークンがない値です。部品の文書では「未定義」と書き、値は決めていません。参考に、モック（静的ページ版 v0.3 の値で作ったもの）と元の学習ノートで使っていた値を書きます。

11. **金色のトークンがない。** 完了したノードの面、XP の文字、章完了の ★、章をまたいだときの祝福の帯、本棚の区切りの ★ に使っている。モックは `#F5B400`（ダーク `#FFC933`）、帯の文字は `#4A3200`。白の ★ を金色の面に載せると 1.8:1、金色の XP の文字を白い面に置くと 1.8:1 で、どちらも 3:1 に届かない。`--gold` のような役割のトークンを足すか、完了を `--ok` で示すか。
12. **正解・不正解の薄い面がない。** [クイズ選択肢](components/quiz-option.md)と[結果バナー](components/result-banner.md)の面。モックは `--ok-soft`（`#E2F2EA`、ダーク `#12291F`）と `--danger-soft`（`#FDECEA`、ダーク `#3A1D1A`）。トークンに足すか。あわせて、「答え合わせ」のボタンを緑（`--ok`）の面にするか（[ボタン](components/button.md)に緑のバリアントはない）。
13. **コースとノートの色（中身側の色）がない。** Part 見出しの面、コースのアイコン、本棚の表紙に、コースやノートごとの色を使っている。モックは `#0082FB`、`#0E7C86`、`#F08A24`、`#12805C`、`#606770`。白い文字・アイコンを載せたときの比は 3.8、4.9、2.5、4.9、5.7:1 で、オレンジは 3:1 にも届かない。カレンダーの色と同じ「中身側の色」としてパレットを決めて登録するか。本棚の進捗バーを `--ok` にしている点（ほかの進捗は `--accent`）もここで決める。
14. **紙吹雪の色。** モックは `#EC4561`、`#0082FB`、`#F5B400`、`#12805C` の4色で、DS の色と一致していない。既存のトークン（`--accent`、`--ok`、`--danger` と、11 で決める金色）から選ぶか。
15. **選択肢の正誤が色だけ。** クイズ選択肢の正解・不正解は枠と面の色だけで示している。結果バナーの文で補っているが、選択肢そのものに ✓ ✕ などの印を付けるか。
16. **段にない寸法。** ノードの円の立体の影（下に 4px ずらした影。`--shadow-*` にない）、コースのアイコンの角丸 8px と 14px（角丸の段にない）、単語の 36〜52px と ★ の 64px（タイポの段にない）、「今ここ」のラベル 11px（Small 段の 12px より小さい）、コース切替パネルの幕（黒の 40%）。段に足すか、近い段に寄せるか。
17. **アイコンの決まりがない。** 学習ノートの部品は ✕・🔊・★・▶ を文字や絵文字で出している。線のアイコンの組を決めるか、このままにするか。
