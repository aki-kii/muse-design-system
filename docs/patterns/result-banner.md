# 結果バナー（Result Banner）

**出自:** 学習ノート。別のアプリで要るときは、まず下の「組み合わせ」の汎用部品で組みます（[昇格のルール](../decisions/0002-component-admission.md)）。

## 概要

答え合わせの結果を、問題のすぐ下に出す帯です。「正解」か「惜しい」かの判定、解説の文、正解のときの紙吹雪を1つにまとめます。消えずに残る点が[トースト](../components/toast.md)と違います。

## 組み合わせ

- 正解・不正解の薄い面の帯（汎用の部品にはしていない。使っているアプリが1つだけなので、2つ目のアプリで要るまで部品にしない）
- 「解説を見返す」などは[ボタン](../components/button.md)のセカンダリ
- 紙吹雪（学習ノート固有の飾り）

## 使うとき

- 選択式・記述式の問題の答え合わせの後
- 復習画面の問題の答え合わせの後

## 使わないとき

- 操作の結果を短く知らせるだけ → [トースト](../components/toast.md)
- エラー（採点できなかったなど）→ 本文の中に `--danger` の文で出す
- 単語カードの判定（カードの中の1行の文で足りる）→ [単語カード](word-card.md)

## バリアント

| バリアント | 見た目 | 文 |
| --- | --- | --- |
| 正解 | 薄い緑の面、判定の文は `--ok`、紙吹雪あり | 「正解！その調子だよ」＋解説 |
| 惜しい | 薄い赤の面、判定の文は `--danger`、紙吹雪なし | 「惜しい！ここがポイントだよ」＋解説 |

惜しいときに、関係する解説ページがあれば、バナーの下に「解説を見返す」「章の解説全体」のボタンを置き、その場で解説を開けるようにします。

## 状態

| 状態 | 見た目 |
| --- | --- |
| 出たとき | 0.35 秒で拡大しながら出る。正解なら紙吹雪が 1.1 秒で落ちる |
| 表示中 | 次のページへ進むまで残る |
| 保存済みの答え | 前に答えた問題を開き直したときも、動きなしで同じ判定を出す |

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| 面 | 正解は薄い緑、惜しいは薄い赤 | `--ok-soft` `--danger-soft` |
| 角丸 | 12px | `--radius-row` |
| 内側の余白 | 16px | |
| 問題との間隔 | 20px | |
| 判定の文 | 22px / 800（大きい文字なので 3:1 で足りる。薄い面の上で 4.2:1） | `--ok` または `--danger` |
| 解説 | 本文、行間 1.65 | `--text` |
| 紙吹雪 | 8×12px の小片 18個、角丸 2px。色は `#EC4561`・`#2F7CF6`・`#F5B301`・`#2E9E5B` の4色を順に | 飾りの色で、DS のトークンにしない（学習ノートの現行の値） |

## アクセシビリティ

- バナーに `role="status"` を付け、判定と解説が読み上げで伝わるようにする。フォーカスは移さない。
- 紙吹雪は `aria-hidden="true"` の飾りにし、押す操作を邪魔しない（`pointer-events: none`）。
- 拡大の動きと紙吹雪は `prefers-reduced-motion: reduce` のとき止める。
- 判定は色だけでなく文で示す（上の文を省かない）。
