# 状態付きリスト項目（Status List Item）

## 概要

一覧の1件ごとに「いま誰の番か・どこまで進んだか」の状態を持たせ、状態に応じて見た目を変える項目です。先頭の印・題・補足・状態の印を1行（またはカード）に並べ、押すとその項目を開きます。[リスト行](list-rows.md)のタスク行が「本人が付ける完了」だけを持つのに対し、相手（エージェントなど）とのやり取りで変わる状態を持ちます。

## 使うとき

- 依頼・やり取り・ジョブのように、1件ずつ状態が変わっていくものの一覧
- 「次は本人が見る番」「相手が作業中」を一覧のまま見分けたいとき

## 使わないとき

- 状態のない一覧 → [リスト行](list-rows.md)、[セクションカード](section-card.md)
- 本人だけが完了を付ける「やること」 → [リスト行](list-rows.md)のタスク行
- 見た目で選ぶ一覧 → [メディアカード](media-card.md)
- やり取りの中身そのもの → [吹き出し](message-bubble.md)（開いた先）

## バリアント

| バリアント | 構成 | 用途 |
| --- | --- | --- |
| カード型 | 先頭の印＋（題・件数）＋最後の発言＋（時刻・状態の印）。`--surface` の面にカードの影 | 中身の要約まで見せたい一覧 |
| 1行型 | 題＋状態の文字＋右端の[完了トグル](done-toggle.md) | 1回で終わる依頼など、短い一覧 |
| 細いカード型 | 先頭の印＋題だけ | 完了したもの。一覧の下にまとめる |

## 状態

| 状態 | 見た目 | 印 |
| --- | --- | --- |
| 本人の番 | 先頭に `--accent` の円の印 | アプリごとの印（例: 吹き出しのアイコン） |
| 相手が作業中 | 枠を `--accent` にし、時刻の横に色付きの[作業中インジケータ](typing-indicator.md) | 作業中インジケータ |
| 下書きあり | 時刻の横に「下書きn件」（`--accent-strong`） | 文字 |
| 完了 | 細いカード型にし、題を `--faint`＋打ち消し線。先頭に[完了バッジ](done-toggle.md)。行全体の不透明度は変えない | 完了バッジ |
| 押下 | 0.99 倍に縮む | |
| フォーカス | フォーカスの輪 | |

先頭の印は押せない印です。同じ位置に押せるボタンを置きません。完了は行全体を薄くせず、題の色（`--faint`）と打ち消し線と完了バッジで示します。不透明度 0.7 で薄くすると、題の文字が 4.5:1 に届かなくなるためです（[決定記録 0005](../decisions/0005-states-and-exceptions.md)）。

## 仕様

| 項目 | 値 | トークン |
| --- | --- | --- |
| カード型の面 | 白、1px の枠、カードの影、内側の余白 16px | `--surface` `--border` `--shadow-card` |
| 角丸 | 12px | `--radius-row` |
| 項目同士の間隔 | 8px | `--space-row` |
| 先頭の印 | 32px の円 | `--radius-pill` |
| 題 | 13px / 500、1行で切る（…） | `--text` |
| 補足・時刻 | 12px | `--dim` |
| 1行型の高さ | 44px 以上 | `--size-tap-target` |

## アクセシビリティ

- 一覧は `<ul>`、カード型は1件を `<button>`（開く先がページなら `<a>`）にする。
- 状態は印の色だけで伝えず、`aria-label` に含める（例:「題（確認待ち）」「題（エージェントが修正中）」）。印は `aria-hidden="true"`。
- 1行型で完了トグルを置くときは、項目を開く操作とトグルを別の要素にする（入れ子のボタンにしない）。
