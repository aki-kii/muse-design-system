# 質問ボックス（Ask Box）

## 概要

解説ページや問題ごとに置く、その場で質問できる欄です。そのページ・問題についての質問と答え（Q&A）を上に並べ、下に入力欄と「聞く」ボタンを置きます。会話の画面に移らずに質問できる点が、[吹き出し](message-bubble.md)を使うチャットと違います。

## 使うとき

- 学習プレイヤーの解説ページの末尾（「このページについて質問する」）
- 問題カードの末尾（「この問題について質問する」）。答え合わせの前でも後でも出す

## 使わないとき

- 話題を変えながら続ける会話 → チャット画面と[吹き出し](message-bubble.md)
- 1画面に2つ以上置かない（どのページ・問題についての質問かが曖昧になる）
- 答えを書かせる欄には使わない（答えは問題の入力欄に書く）

## バリアント

| バリアント | 見出し | 入力欄の例文 |
| --- | --- | --- |
| ページ | このページについて質問する | 例: この図は何を表してるの？ |
| 問題 | この問題について質問する | 例: なぜ受動態だと不自然なの？ |

Q&A はページ・問題ごとに分けて保存します（同じ問題を開き直すと前の Q&A が出る）。

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 空 | 見出し＋入力欄＋無効の「聞く」 | Q&A がなく、入力が空 |
| 入力中 | 「聞く」が押せる | 入力欄に文字がある |
| 送信中 | 「聞く」を押せなくし、ボタンの文を「聞いてる…」に変える | 答えを待つ間 |
| Q&A あり | 見出しの下に「Q. 質問」「A. 答え」の組を古い順に並べる。入力欄は空に戻す | 答えを受け取った後 |

答えを受け取れなかったときは、入力を残して「聞く」を押せる状態に戻します。エラーの文の出し方は未定義です。

## 仕様

構成:

1. 区切り線と見出し
2. Q&A の列（Q は太字、A は本文）
3. 入力欄（複数行）
4. 「聞く」ボタン

| 項目 | 値 | トークン |
| --- | --- | --- |
| 区切り | 上に 1px の罫線、上の余白 12px、カードの中身との間隔 16px | `--border` |
| 見出し | 本文サイズ / 800 | `--text` |
| Q&A | 14px。Q は 700、A は行間 1.6 | `--text` |
| Q&A 同士の間隔 | 8px | `--space-row` |
| 入力欄 | 高さ 92px 以上、[入力欄](input-and-switch.md)と同じ枠と角丸 | `--border` `--radius-row` |
| 「聞く」 | プライマリのボタン、幅いっぱい | [ボタン](button.md) |

入力欄にフォーカスしたとき、画面のキーボードに隠れないよう入力欄の上に 12px の余白を取ってスクロールします。

## アクセシビリティ

- 入力欄にはラベルを付ける。見た目に出さない場合も、見出しと同じ文を視覚的に隠したラベルにする。
- 「聞く」は `aria-label="質問を送る"` を付ける。
- 新しい答えが届いたら、Q&A の列を `aria-live="polite"` にして読み上げで伝える。フォーカスは入力欄に残す。
