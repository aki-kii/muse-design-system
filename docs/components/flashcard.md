# フラッシュカード（Flashcard）

## 概要

表と裏を持つカードを1枚ずつ見せ、裏を開いたあとで本人に「覚えていたか」を判定させる部品です。表で問い、裏で答え、判定で次のカードへ進みます。中身（単語・用語・手順など）には依存しません。

## 使うとき

- 問いと答えの組を、短い間隔で繰り返し思い出させたいとき（語と意味、用語と定義、記号と読み方）
- 正誤を機械で採点せず、本人の自己判定で次に進めてよいとき

## 使わないとき

- 答えを選ばせて採点する → [選択肢ボタン](choice-button.md)
- 解説を読ませる → [セクションカード](section-card.md)（フラッシュカードの裏に長い解説を載せない）
- 1回見れば済む情報 → カードにせず本文に書く

## バリアント

| バリアント | 流れ | 用途 |
| --- | --- | --- |
| 自己判定 | 表 → 「タップして答えを見る」→ 裏を開く → 判定ボタン2つ（例:「もう知ってた」「覚える」）→ 次のカード | 標準 |
| 選んで答える | 表 → 裏の代わりに[選択肢ボタン](choice-button.md)の縦並び → 正誤を出して次のカード | 前に間違えたものの復習 |

## 状態

| 状態 | 見た目 | 条件 |
| --- | --- | --- |
| 裏を隠している | 破線の枠のボタン「タップして答えを見る」と、その下に短いヒント | 表を出した直後 |
| 裏を開いた | 破線の `--accent` の枠に答え。その下に判定ボタン2つ | 隠した部分を押した |
| おしまい | 「今日の分はおしまい」などの文 | 束の最後のカードを判定した |
| フォーカス | フォーカスの輪 | キーボードで選ばれたとき |

## 仕様

構成は次のとおりです。

1. キッカー（束の名前と「n / 全体」）
2. 表の面（問い）
3. 補足（任意。例文など）
4. 裏の面（隠す部分）と判定ボタン

| 項目 | 値 | トークン |
| --- | --- | --- |
| キッカー | 13px / 700、字間 0.05em | `--accent-strong` |
| 表の面 | `--surface` の面、1px の枠、カードの影、内側の余白 28px 16px | `--surface` `--border` `--shadow-card` `--radius-card` |
| 隠す部分 | 破線 2px の枠、内側の余白 28px 16px、高さ 56px 以上、700 | `--border` `--dim` `--radius-card` |
| 裏の面 | 破線 2px の枠、内側の余白 16px、20px / 700 | `--accent` `--radius-card` |
| 判定ボタン | 2列、間 10px。弱い方をセカンダリ、強い方をプライマリ | [ボタン](button.md) |

表の文字の大きさは中身で決めます（単語なら大きく、文なら本文の段）。単語の大きさ（学習ノートの 36〜52px など）は、使う側のパターンの文書に値を書きます（[決定記録 0004](../decisions/0004-scale-and-local-values.md)）。

## アクセシビリティ

- 1枚を `<article>` にする。中身が日本語以外なら `lang` を付ける。
- 隠す部分は `<button>` にし、`aria-label`（例:「答えを見せる」）を付ける。開いたら裏の面にフォーカスを移し、判定ボタンより前に読ませる。
- 自動で次のカードへ進めるときは、結果の文を `role="status"` にし、読み終わる前に進めないよう時間を長めに取る。
- カードが変わったら、画面の先頭へスクロールを戻す。
